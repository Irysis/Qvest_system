## 1. 무엇을 하자는 것인가

현 book의 종목 선별 단계에서 **MAX5(최근 63일 상위 5일 수익 평균) 상위 10%를 후보에서 제외**한다. 랭킹 가중치를 바꾸는 게 아니라 **후보집합을 줄이는 필터**다. 신규 팩터 도입이 아니므로 알파 로직·비중 규칙은 그대로다.

한 줄 요약: **"최근에 며칠 크게 튄 종목은 아예 안 뽑는다."**

## 2. 실측 근거 (전부 `alpha_validation.json` 인용, metric_type=weighted_screen)

### 2-1. 현 book overlay를 얹은 상태 (실배치에 해당하는 조건)

| | 무필터 | 필터 적용 |
|---|---|---|
| PORT_t | 1.886 | **2.458** |
| absSR | 0.874 | **0.962** |
| absMDD | −40.34% | **−33.03%** |

**paired NW lag-3 t = +1.551 / ΔIR = +0.1284** (256개월). 사전등록 닫힘 기준(t<1) 비발동, admission 컨벤션 문턱(ΔIR ≥ +0.05)의 2.6배.

### 2-2. overlay 없는 조건 (참조)

PORT_t 2.879 → **3.620**, absMDD −55.87% → **−44.43%**, ΔIR **+0.1692**, 회전 13.81 → 13.54(증가 없음).
→ overlay 결합 시 편익의 **76%가 보존**된다.

### 2-3. 중복이 아니라는 근거

- 상호작용 paired **t = −1.14** — overlay가 필터 기여를 유의하게 지우지 못한다.
- **MDD 개선 분해: overlay 단독 15.6pp + 필터 추가 7.3pp**(bare 11.4pp의 64%가 잔존).
- 해석: overlay는 노출을 줄이고 필터는 종목을 바꾼다 — **다른 축**이라 부분 독립으로 누적된다.

### 2-4. 필터가 실제로 작동하는가

- **발동률 0.957** (245/256월에서 top-25 구성이 실제로 바뀜).
- base top-25에 복권형이 **월평균 3.34종** 실재했다 → "incumbent가 이미 회피 중"이라는 귀무가설 **기각**.
- 기전 지지: 배제군을 개인이 홀딩월에 유의하게 더 순매수(NW **t +3.90**) = 복권 수요 실재.

## 4. 측정 신뢰도

- **PIT**: `assert_overlay_pit` **256/256 PASS** + **위반 주입 실증**(컷오프를 홀딩월로 옮기면 stop 발화 = 가드 생존).
- **look-ahead 이득 부재**: strict A/B에서 누출 방향 변형이 오히려 **열세**(absSR 0.795 vs 0.874, 인플레 −9.0%).
- **base 재현**: anchor PORT_t 3.0583 = parity 기록과 소수 4자리 일치.
- **사전등록 STOP 1회 발동 후 정직 처리**: book 대비 상관 0.668로 STOP → 진단 2축(정렬 정확·행 수준 배선 cor 0.9996)으로 "기준의 보조가정 오류"임을 확정하고 **silent override 없이 전량 기록**.
- dual-basis: EW top-25 overlay-ON에서도 동방향(2.188 → 2.498).

## 5. 선택지

| 안 | 내용 | 적합 조건 |
|---|---|---|
| **A. 즉시 적용** | 다음 리밸부터 필터 반영 | R1(통계 확증 보통)을 감수하고 MDD 개선(7.3pp)을 우선할 때 |
| **B. 페이퍼 추적 후 결정** | 필터판을 병렬 추적, N개월 라이브 delta 관측 후 판단 | 권장 — R1이 유일한 실질 약점이고 시간이 그걸 해소한다 |
| **C. 보류** | FQ-112(위험-축)·국면조건부 해제 판정까지 대기 | 위기 역효과(R3)를 먼저 없애고 싶을 때 |

**Q-Lead 의견**: **B**. 근거는 편익의 성격이 "수익 증가"보다 **낙폭 감소**(SR 0.874→0.962는 주로 MDD 개선에서 옴)이고, 낙폭 개선은 라이브에서 비교적 빨리 관측되기 때문이다. R2(리밸 지연 불허)는 현 운용이 월간 정시 리밸이면 이미 충족된다.

## 6. 채택 시 함께 걸어야 할 것

1. **라이브 필터-delta 추적 배관** — 필터 유무 차이를 월별로 기록. 지속 음수면 재판정(부활 조건에 등재됨).
2. **리밸 지연 불허 조건 명시** — 운용 사유로 지연이 발생하면 그 달은 편익을 기대하지 말 것(R2).
3. 배제 비율 X=10% **고정**(사후 조정은 sweep — 재판정 대상).
