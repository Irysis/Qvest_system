# SJM 팩터로테이션 구현 감사 사양 v1 (도훈 발행, 2026-08-21)

> 대상 논문: Shu & Mulvey, "Dynamic Factor Allocation Leveraging Regime-Switching Signals",
> *The Journal of Portfolio Management*, 51(3):50–72 (2025). 프리프린트 arXiv:2410.14841.
> 본 파일은 도훈이 발행한 감사 프롬프트의 **원문 보존본**이다. 감사자는 이 사양만을 기준으로 판정한다.
> §4 수치 앵커는 arXiv v1 기준 — 저널판과 차이 발견 시 앵커를 저널판 수치로 교체 후 감사.

## 0. 감사 규칙
**역할.** 너는 감사자다. 구현자가 아니다. **코드를 수정하지 마라.** 판정과 증거 제시만 한다.
**독립성.** 이 코드를 네가 작성했다면 감사를 거부하고 그 사실을 보고하라.
**증거 규칙.** 모든 항목에 (a) `파일경로:라인번호`+코드 3~10줄 인용 (b) 실행 산출물(수치·로그·배열) (c) 판정 등급 — 셋 중 하나라도 없으면 자동 `FAIL`.
**금지.** "구현되어 있음/정상 동작함/논문대로임" 서술만으로 통과 금지.
**등급.** `BLOCK`(구현 전체 무효) / `FAIL`(불일치, 수정 필요) / `WARN`(재량이나 근거 미문서) / `PASS` / `N/A`(범위 밖 근거 제시) / `DIVERGE`(의도적 이탈+자체 사양 문서화 — 기존 코드 감사 모드 전용).
**BLOCK 사유 4종**: ①미래참조(P5 실패) ②절대수익으로 국면 적합 ③점프 페널티 미작동(P2 실패) ④롱온리 제약 위반.

## 0.5 기존 코드 감사 모드 — Phase 0
- **Phase 0-1 자기 사양 확정**: §1 전 SPEC 항목을 `CLAIM`(논문과 같게 하려 함 → 논문 기준 감사) / `DIVERGE`(의도적 이탈+근거 문서 → 자체 사양 기준 동일 유형 검사, 근거 미문서 시 WARN) / `UNKNOWN`(질의 후 재분류, 불가 시 CLAIM 간주)으로 3분류한 표 작성.
- **Phase 0-2 3계층**: (A) 건전성 = S3·O1~O4·C1·C2·C6·C8·R1·B5 / P5·P6·P9·P10·P11 — **이탈 불가, 전부 적용**. (B) 모델 정합 = M1~M8·O6·O7 / P1~P4·P7·P8 — JM 주장 시만(타 엔진이면 N/A, 단 상응 건전성은 (A)로 흡수). (C) 논문 재현 = 수치 사양·S1·S2·S4·S5·B1~B4·B6·§4 앵커 — CLAIM 항목만. P6 지연 기준은 코드 자기 사양 지연값(미문서면 그것부터 WARN). BLOCK ①④는 모드 무관, ②③은 각각 액티브수익 전환·JM CLAIM 코드에만.
- **Phase 0-3 감사 가능성(seam)**: ①합성 수익률·피처 주입 가능? ②시드 고정? ③단일 명령 재실행? 불가 항목은 "통과 못 함"이 아니라 **"감사 불가"**로 보고. P5 실행 불가면 seam 추가를 선행 작업으로 요구(seam 추가는 독립성 침해 아님).
- **Phase 0-4 결과 은폐**: 로직 판정 완료 전까지 기존 백테 성과 수치(수익률·Sharpe·MDD·회전율) 열람 금지. §4 앵커 대조·§4.3 과적합 탐지는 마지막에.
- **Phase 0-5 미검증 영역**: 그리드·피처·윈도우가 전표본 결과를 본 뒤 조정됐을 가능성은 코드 감사로 검출 불가 — 버전 이력에서 변경 시점 vs 결과 열람 시점 선후 확인, 불가 시 미검증 영역에 명시.
- 산출 시 DIVERGE 건수 별도 집계 + Phase 0-1 분류표를 요약 앞에 첨부.

## 1. 사양 (SPEC)
### 1.1 데이터
지수 7개(시장1+스타일6), 일간 총수익률. **국면 적합 입력 = 액티브 수익률(팩터−시장)**. 절대·초과수익(무위험 대비)은 국면 적합에 금지.
### 1.2 피처 (하루 ~20개, 6모델 공통 설계)
팩터특유(팩터별 값 다름): EWMA 액티브수익(8/21/63) · RSI(8/21/63) · 스토캐스틱 %K(8/21/63) · MACD(8-21, 21-63) · log 하방편차(21) · 액티브 마켓베타(21). 시장환경(**6모델 동일 값**): 시장수익 EWMA(21) · VIX 로그차분 EWMA(21) · 2년물 차분 EWMA(21) · 10Y−2Y 차분 EWMA(21).
### 1.3 SJM 목적함수
min over {θ, s}: Σ_t ½·Σ_d w_d·(x_{t,d}−θ_{s_t,d})² + λ·Σ_t 1{s_{t−1}≠s_t}, s.t. ‖w‖₁≤κ, w_d≥0.
K=2(재현 기준. 논문 무근거 선택 — 국내 이식 단계는 §8-2). 전환 페널티 **L0형**(크기 비례 금지). 가중 제곱 L2 거리(우도 아님). 좌표하강(θ,w 고정→s / s 고정→θ,w). s 갱신 = DP 정확해(탐욕 금지). 다중 초기값 재시작 필요.
### 1.4 온라인 추론
θ·w 훈련 고정(온라인 재추정 금지). lookback 내 상태열만 재최적화 → 마지막 상태. **T 종가 판정 → T+1 종가 리밸 → T+2 수익 반영**. 재적합 월 1회, 사이는 온라인.
### 1.5 교차검증
훈련창 확장형 8~12년. 검증창 6년, 6개월 롤. 매 롤 검증창 단일팩터 롱숏 Sharpe 최대 (λ,κ) 선택 → 다음 6개월 적용. **λ·κ 격자 공동 탐색**(순차 금지 — §3.6=P7). **팩터 6개 독립 튜닝**. 테스트 2007~.
### 1.6 국면→기대수익
국면 k 기대 액티브수익 = **훈련구간 내** 상태 k인 날들의 평균. 전표본 평균 = 미래참조.
### 1.7 단일팩터 롱숏 (CV 목적함수)
기대수익 ≥+5% → 팩터 100%롱/시장 100%숏, ≤−5% 반대, 사이 선형 보간, ±5% 캡. **편도 5bps를 이 백테 안에 반영**.
### 1.8 Black-Litterman
사전 비중 7지수 균등+분기 리밸. δ=2.5. Σ=EWMA hl126. 뷰 6개(팩터+100%/시장−100%). 뷰 기대수익=1.6. Ω,τ 대각 = PΣPᵀ 대각의 상수배, 상수는 **목표 TE(1~4%) 역산**. 최종 long-only·Σw=1 MVO.

## 2. 정적 검사
S1 국면 입력=액티브인가(원수익률→BLOCK) · S2 시장환경 4열이 6모델 동일값 · S3 표준화 통계량 훈련구간 한정(전표본→미래참조) · S4 스플라이싱 문서화(미문서 WARN) · S5 결측·정지·재구성 규칙 명시(무언 ffill WARN).
M1 페널티 1{≠}형(제곱·abs→FAIL) · M2 페널티 합 t=1 시작 · M3 w가 거리 계산에 실제 곱해짐(P7로 검출) · M4 ‖w‖₁≤κ 강제 · M5 s 갱신 DP 정확해(그리디→FAIL) · M6 다중 초기값(단일→WARN; 미명시 기본 = 자매논문 2024a **10회 재시작 최저 목적값**) · M7 빈 클러스터 처리 · M8 수렴 기준·최대 반복 명시(미명시 WARN).
O1 filtered vs smoothed(smoothed→**BLOCK**) · O2 온라인 θ,w 고정(재추정→미래참조) · O3 적용 T+2(T+1·T→FAIL) · O4 lookback 상수·미래 미포함(가변·미래→BLOCK) · O5 재적합 달력 사전 결정(데이터 의존→WARN) · O6 온라인 전환수 > 인샘플(적으면 로직 반전 의심) · O7 lookback 길이 명시(미명시 기본 = 2024a **훈련창 동일 길이**; 타 값 근거 미문서→WARN).
C1 검증창-훈련창 무겹침(겹침→FAIL) · C2 (λ,κ) 다음 6개월만 적용(소급→**BLOCK**) · C3 λ·κ 격자 공동(순차→FAIL) · C4 그리드 범위·간격 기록(미기록 WARN) · C5 팩터 간 무참조(P8로 검출) · C6 거래비용 CV 목적함수 내(밖→FAIL, P9) · C7 롤 횟수·선택값 로그(미기록 WARN) · **C8 검증창 성과가 온라인 추론 국면으로 계산되는가**(인샘플 smoothed로 선택→FAIL — 온라인 전환수가 인샘플의 ~2배라 인샘플 기준은 과소평활 λ 선택. 2024a 각주14가 명시 요구).
R1 국면별 평균 훈련구간 한정(전표본→**BLOCK**) · R2 ±5% 임계+선형 보간(이진→FAIL) · R3 캡 ±100%.
B1 사전 비중 균등+분기 · B2 뷰 +1/−1 구조(절대뷰→타 모델) · B3 δ=2.5·hl126 · B4 신뢰도 TE 역산(임의 고정→FAIL) · B5 long-only·Σw=1(미적용→**BLOCK**) · B6 실현 TE가 목표 ±30% 이내.

## 3. 동작 검사 (실행 필수 — 합성 데이터 프로브, 실제 출력 첨부)
P1 λ=0 환원: κ=D·동일 초기값에서 SJM=k-means 라벨 100% 일치. 불일치→첫째 항 오류.
P2 λ→∞ 붕괴: λ=10×(첫째 항 최대 가능값)에서 전환 0회. 전환 발생→**BLOCK**.
P3 손계산 대조: x=[5,4,−1,5,4], D=1, K=2, w=1. λ=6.0→라벨 [0,0,1,0,0]·목적값 12.5 / λ=6.1→[0,0,0,0,0]·12.6. 분기점 λ=6.05 이분탐색 소수 둘째 자리 일치.
P4 시간정보: 시간축 셔플 후 λ>0에서 전환수·라벨 변화(λ=0은 순열 제외 동일). 불변→페널티가 시간 인접성 미사용.
**P5 미래교란 ★최우선**: t 중간 고정, 버전A 원본 vs 버전B(t 이후 난수 치환), **전체 파이프라인 재실행**(피처→표준화→훈련→CV→온라인→포지션). t 이전 라벨·포지션·(λ,κ) 완전 동일해야 통과. 하나라도 불일치→**BLOCK**. t 최소 3개(초·중·후반).
P6 적용 지연: 라벨 1시점 반전 → 포지션 최초 반응 = +2 (ccf 최대 lag 2). +1/+0→FAIL. (기존 코드 모드: 코드 자기 사양 지연값 기준.)
P7 λ/κ 결합: κ 2배(λ 고정)→전환수 증가, 이어 λ 2배→원 수준 복원. κ 불변→M3 위반(실효 페널티 ≈ λ/κ).
P8 팩터 독립성: value 입력만 난수 교란 → 나머지 5팩터 국면열·(λ,κ)·롱숏 성과 완전 불변. 변화→C5 위반.
P9 비용 반응: CV 내부 5bps→50bps 재튜닝 → λ 증가 또는 전환수 감소. 불변→C6 위반.
P10 롱온리: 전 팩터 −50% 뷰 강제 → 음수 0·합 1.0·시장 비중 증가. 음수→**BLOCK**.
P11 지연 민감도: 지연 1→5→10일, **검증 CV에도 동일 지연 적용 재튜닝**. 완만 감소면 통과(2024a: 2주 지연에도 벤치 이상 유지). 급락→노이즈 포착 / 유의 개선→지연 로직 오류·미래참조, P5·P6 재실행.

## 4. 수치 앵커 (수준 아닌 부호·순서)
4.1 연 전환수 순서(온라인): quality 0.64 < growth 1.31 < low vol 1.78 < size 2.57 < value 3.16 < momentum 3.66 — 켄달 타우 ≥0.6 통과, quality 최소·momentum 최대 아니면 WARN. 단일팩터 L/S Sharpe 전부 양수(논문 value .39/growth .37/lowvol .30/quality .21/size .20/momentum .16). 여섯 롱숏 최대 상관 <0.5(논문 최대 value-growth 0.48).
4.2 단조성 (TE 1→4%): 회전율 단조 증가(237→628) · 절대 Sharpe 단조 증가(0.57→0.65) · 시장 IR 증가 후 포화(0.24→0.44) · EW IR 중간 최대(0.40→0.49→0.49→0.47).
4.3 과적합 탐지: 절대 Sharpe>0.80(미래참조) · MDD 개선>10%p(익스포저 축소 유입/미래참조) · 단일팩터 L/S Sharpe>0.60(smoothed) · 시장 IR>0.70(CV 소급) · 온라인 전환수 ≤ 인샘플(반전) — 해당 시 P5 재실행+WARN 이상. 논문 MDD 개선 4.4%p는 설계(100% 투자 유지). 단서: 2024a 익스포저 축소 층 의도적 결합 시 N/A 처리+결합 사실·단독 기여 별도 기록(2024a MDD 개선 28~34%p 초과 시 재의심).

## 5. 산출 포맷
요약(BLOCK/FAIL/WARN n건·PASS n/전체·종합판정[구현무효/수정필요/조건부수용/수용]) → BLOCK 항목(증거 3종) → 정적 결과표(#·항목·등급·근거 위치·관측값) → P1~P11(실행 명령·실제 출력·기대값·판정) → 수치 앵커 대조표 → 미검증 영역 → 재현 정보(커밋 해시·시드·환경·소요).

## 6. 감사자에게
①미래참조는 성과를 좋게 만들지 이상하게 만들지 않는다 — P5 미통과 구현은 전 항목 완벽해도 무효. ②정적만으로 판정 금지 — w가 전부 1이면 sparse 층은 없는 것(P7이 잡음). ③논문 미명시 자유값(그리드·초기값 수·결측 처리·lookback)은 WARN + 목록화. 금지: 코드 수정·성능 개선 제안·논문 비평.

8-1 **익스포저 층 우선 검증**: 2024a는 회전율 44~170%로 MDD 28~34%p 개선, 본 논문 배분층은 237~628%로 4.4%p — 국면 신호 가치는 스케일링층이 훨씬 쌈. 로테이션 증분 가치는 익스포저-단독 기준선 대비로만 판정. **편도 15bps 손익분기 회전율(목표 액티브수익 ÷ 왕복비용) 선계산 의무**.
8-2 K 선택을 OOS 루프 안으로 (GIC 또는 검증 성과, K∈{2,3,4}; K-λ 결합 문제 유의).
8-3 시장환경 피처 상태조건부 재시험 (전역 가중 구조 제약 검증 → 죽으면 제거해 차원 축소).
8-4 하드 라벨→국면 확률 (BL 신뢰도=f(국면확률) A/B — 배분층 연속일 때만 이득 기대).
8-5 BL→MPC (회전율×비용이 목표 위협 확인 후에만, 구조만 차용).
8-6 **무국면 벤치마크 게이트 — 본 논문 최대 공백**: 학습된 국면 ≈ 팩터별 시계열 모멘텀인데 factor momentum 대비 증분 비교 부재. 게이트 2종 = (a) 팩터 과거수익 기반 factor momentum 배분 (b) EW. **(a)를 못 이기면 국면 층 전체 기각.** EW만 이기는 것은 통과 아님.
8-7 국내 이식 정합: 팩터군 실체화 중간층 필요 / 뷰(+100/−100)를 롱온리 틸트로 번역하는 지점이 소멸 병목 / **CV 내부 비용을 편도 15bps로 교체 — 논문 TE3%는 15bps에서 액티브 전량 소진, 이식 1차 관문은 신호가 아니라 회전율**.
