# 헌장 · 목표 · 규칙 — 처방 루프 v0

## 1. 투자철학 (도훈)
- 남들 다 깨질 때 방어해 복리를 극대화한다 — **위기 하락 포착률을 낮추되 강세 상승 포착률 ≥ 0.55** 를 지킨다(비대칭). 정적 노출 축소(현금 비중만 늘리기)로는 비대칭이 생기지 않는다.
- 꾸준한 우상향 — 장기 정체(수년 수중)를 싫어한다. 성과보다 PIT(미래참조 없음)가 우선이다.

## 2. 등급 v3 (권위 · essence) — 이 처방이 겨냥하는 수치 산식
- 종합점수 S = (Calmar / 0.64)^0.6 × (PORT_t / 2.95)^0.4 · A = S ≥ 1 + 하한(PORT_t ≥ 2 · CAGR ≥ 0.16 · Sharpe ≥ 0.8 · Calmar ≥ 같은 창 벤치 Calmar) + 위기 복원력(CR) 노치 + OOS 관문.
- PORT_t = 일별 (전략 순수익 − KOSPI200) 평균의 Newey-West t(lag 3). 위험 축 = Calmar(최대낙폭은 직접 걸리지 않는다).
- **보는 창 기준 산술(참고 · R 계산)**: 보는 창 PORT_t = 3.938 이면 S ≥ 1 에 필요한 Calmar = 0.64 × (3.938/2.95)^(−0.4/0.6) = 0.528 → 보는 창 CAGR 0.202 를 유지하면 최대낙폭 ≤ 0.383 가 필요하다. PORT_t 가 떨어지면 필요한 Calmar 는 올라간다(교환).

## 3. 정보 경계 τ_D = 2022-12-31 (절대)
- 당신이 보는 수치는 전부 2005-02-02 ~ 2022-12-29 구간에서 R 계약이 계산한 것이다. 그 뒤(시험 창)는 등급 · 사람 쪽 판정에만 쓴다.
- 2023년 이후의 시장 사건 · 성과는 사전학습으로 알고 있더라도 **근거로 쓰지 마라**(처방이 시험 창에 맞춰지면 시험이 무효가 된다).

## 4. 리서치 규칙 (설계 §3.4 — 증거로 인정되는 것)
- R2 사전등록: 처방전(가설 · 기대 방향 · 반증 조건 · 최종 후보 선택 규칙)은 측정 **전에** 파일로 고정된다. 결과를 본 뒤 고쳐 쓸 수 없다.
- R3 시행 회계: 측정한 변형은 전부 계보 시행 수에 더해져 등급 DSR 에 반영된다 — 같은 기전의 파라미터 변형을 여럿 내지 마라(서로 다른 기전 1~3건).
- R5 노출 짝 · MC8 크기 짝: 방어 처방은 '같은 평균 노출의 벤치' 와 '같은 크기 분포 · 평균 노출의 무작위 포트폴리오' 보다 덜 빠져야 실력(선택·기전 방어)이다. 크기 방어 · 노출 방어는 기록하되 실력으로 세지 않는다.
- R6 지속성: 방어 개선은 여러 위기에 걸쳐 나타나야 한다(한 위기 맞춤 금지).
- AX-008: 수치는 R 계약 산출만 인용한다 — 새로 계산 · 추정하지 마라. 숫자가 필요하면 '측정 필요'라고 적어라.
- PIT C1~C15: 처방 규칙의 모든 입력은 결정 시점 이전 데이터여야 한다(오버레이 신호 = 보유 시작 전 · 재무 = 공시 지연 · 팩터 선정 통계 = as-of).
