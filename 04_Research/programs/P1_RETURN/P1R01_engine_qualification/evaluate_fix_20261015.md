# P1R01 evaluate.R 수리 기록 (2026-10-15)

- **증상**: 재시작 파이프라인 v2 의 P1R01 평가가 `Object 'status' not found amongst []` 로 멈췄다(rc=1 · `evaluation.json` 없음).
- **원인**: 사전등록 `data.cells` 는 이름 없는 배열(`["P0R01_E1_C0", "P0R01_E2_C0", "P0R01_E3_C0"]`)인데, evaluate.R 은 `names(pre$data$cells)`(엔진 → 코드 맵)로 순회했다 → 0행 → 빈 표의 `status` 열 참조에서 멈춤. 이 라운드의 평가는 이 수리 전까지 한 번도 끝난 적이 없다.
- **수리**: 셀 목록을 배열로 읽고 엔진을 코드의 E 자리(`P0R01_(E\d+)_C0`)에서 얻는다(이름 있는 맵이면 그 이름). 엔진을 못 읽으면 멈춘다.
- **불변**: 판정 규칙(t(α) ≥ t_alpha_min ∧ 상승 포착 ≥ uc_floor → 자격 · 시험 창 α > 0 → 유지) · 문턱 · 데이터(P0R01 C0 셀) — 사전등록 그대로. 구현이 사전등록 형식을 못 읽던 결함만 고쳤다(P3R01 `evaluate_fix_20261015.md` 와 같은 성격).
- **R2 기록**: 수리 시점에 P0R01 종합 판정 미리보기(라운드 보고 dry run)를 본 뒤였다 — 수리는 셀 목록 읽기뿐이며 결과에 따라 달라질 선택이 없다.
