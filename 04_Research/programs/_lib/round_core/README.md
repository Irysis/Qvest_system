# round_core — 1계층 공통 판정 코어

도훈 10-20 결정 `L1-SPEED-PLAN-20261020`(1계층 리서치 속도 극대화)의 WP1 이다.

**목적**: 라운드마다 판정 코드를 복사·확장하지 않는다. 공통 코어에 라운드 사양(`round_spec.json`)과 꼭 필요한 고유 규칙(`round_ext.R`)만 얹는다.

**배경**: P2R04 의 판정 코드는 약 570KB, P2R05 는 약 1MB 였다. 교차 점검 필수 지적의 3분의 2 가 같은 규칙이 여러 곳에 적혀 생긴 문구 표류였다.

## 원칙

- **보증 불변.** PIT · 사전등록 → 커밋 → 측정 · τ_D · β 짝 · MC8 · 격리 교차 점검 · Superfan 은 그대로다. 판정 규칙의 내용 · 수 · 설계 재량도 현행대로다.
- **규칙은 한 번만 선언한다**(`v1/rules.R`). 같은 선언에서 사전등록 문장 · 판정 실행 · DESIGN 표를 생성한다.
  - 수치 문턱은 근거(`basis`)나 정본 참조(`value_ref`)가 없으면 거부한다.
  - 미측정(NA)은 통과로 접지 않는다(Kleene 논리 · `na = fail | untested`).
- **수치는 R 계약 산출만 쓴다**(AX-008). 계약 파일은 읽기만 한다. 진행 중 라운드(P2R05)의 핀 51개 파일은 그 라운드 종료까지 수정하지 않는다.
- **판은 불변이다.** 출시된 판(`v1/` …)의 파일은 고치지 않고, 바꿀 일이 생기면 새 판을 만든다.
  - 라운드는 판 이름과 매니페스트 md5(`RELEASES.json`)를 사전등록에 핀으로 건다.
  - *v1 은 아직 개발 중이다.* 출시 전에는 라운드가 핀으로 걸 수 없다.
- **속도 조치는 결과 동일 실증이 채택 조건이다.** 실행 시간은 `.cache/round_core/perf/<round>.jsonl` 에 남는다. 성능 규칙은 `PERFORMANCE.md` 를 따른다.

## 모듈 (v1)

| 파일 | 내용 |
|---|---|
| `v1/load.R` | 단일 진입(`source("04_Research/programs/_lib/round_core/v1/load.R")`) |
| `v1/util.R` | 경로 · md5 · 원자적 JSON · 과반 · 안전 호출 · τ_D 가림/누출 검사 · 참조 해석 · 실행 시간 기록 |
| `v1/rules.R` | 규칙 선언(threshold · all_of · any_of · report) — 검사 · 해석 · 판정 · 문장 · 표 |
| `v1/metrics.R` | 지표 공급자(β-통제 알파 · 증분 알파 · 집중 · S) — 계약 호출 |
| `v1/spec.R` | 라운드 사양 검사 |
| `v1/p1.R` | P1 엔진 자격 판정 틀 |
