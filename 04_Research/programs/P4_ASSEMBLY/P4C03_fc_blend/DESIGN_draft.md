# P4C03 설계 초안 — 블렌딩 사슬 판 3(재빌드 뒤 · 코어 v5)

> 사고 기록이다. P4C02 설계 초안(`../P4C02_fc_blend/DESIGN_draft.md`)을 승계한다 — 질문 · 가설 · 반증 · 채택 규칙 · 예산 구조 · 걸음 정책(`step_policy`) · 닫기 판독 ①~⑦ · 감독 반영은 그대로이고, 여기에는 **판 3 에서 달라진 것**만 적는다.
> 상태 = **초안**(11-16). 사슬 판 사양(`chain_spec.json` · `base_cell_spec.json` · `base_selection.json`)은 아직 만들지 않는다 — 기저 풀이 재빌드 뒤 재측정분으로 다시 채워진 다음에 만든다(아래 §4).

## 1. 왜 판 3

- P4C02 는 걸음 1~3 을 기각으로 닫은 뒤 11-15 20:30 `tick_hold` 로 멈췄다(J-20261115-011). 사유 = 기저의 재무 입력이 PIT 상 인증되지 않음 → 도훈 지시로 재무 쓸 수 있는 첫날을 바꾸고 팩터 DB 를 전체 재빌드한다.
- 11-16 에 입력이 세 번 바뀌었다(판 표식 원장 `06_Registry/factor_db_vintage.json` 세 줄 — 모두 다음 전체 재빌드가 채운다):
  1. `FUNDAMENTAL-AVAIL-DEADLINE45-20261116` — 재무 쓸 수 있는 첫날 = max(법정 제출기한 + 45일 뒤 첫 거래일, 공개일 뒤 첫 거래일) · '공개일 + 1개월' 규칙 삭제(`FUNDAMENTAL-AVAIL-LAG-1M-20261116` 을 대체).
  2. `RAWDATA-PRELISTING-EXCLUDE-20261116` — 유가증권 · 코스닥 첫 상장 전 이력을 유니버스에서 뺀다(PIT C6).
  3. 레인 엔진 4개의 재무 시차를 원천 `Factor_Date` 로 늦춘다(0b0d2a237 · C4 소비 규약).
- P4C02 의 기저 측정 · 걸음 측정은 모두 수리 전 판본이다 → 재측정 전 기저 자격이 없다(lean-loop ⑦). 같은 사슬에 걸음을 더 붙이지 않고 새 판으로 연다.

## 2. 기저 선택 — J-20261116-003 의 거르기를 되돌린다

| 무엇 | J-20261116-003(11-16 아침) | P4C03 |
|---|---|---|
| 규칙 | IS S 최대 + 구성원 data_source 에 재무 없음 거르기 | **IS S 최대만**(P4C01 · P4C02 와 같은 기계 규칙 — 후보 = 기저 풀 eligible ∧ T0 동일가중 자체 사양 엔진 · 선택 = S_vis → port_t_vis → key) |
| 거르기 사유 | 재무 의존 전략 = Judge 인증 불가 · 원 공시본 결정 뒤 재빌드 한 번 더 | 둘 다 사라짐 — 원 공시본 = C(수집 안 함 · `FUNDAMENTAL-ORIGINAL-FILINGS-PIPELINE-20261116`) · 정정 덮어쓰기 = 법정기한 + 45일 규칙으로 대응(pit.md C4 · '인증 불가' 문장 삭제) · 다음 재빌드가 마지막 재무 시차 변경 |
| 결과 | 컨센서스 · 쏠림 · 유동성 중 하나 | 재측정 뒤 기계가 고른다 — **미리 정하지 않는다**(재빌드 전 순위는 수리 전 판본) |

- 고른 기저가 P4C02 기저와 같으면 판 3 = 같은 기저의 새 판본 사슬이고, 다르면 새 계보의 첫 사슬이다. 어느 쪽이든 init 은 멈추지 않는다(P4C02 의 '다르면 멈춤' 검사는 판 2 전용 — 판 3 은 판본이 달라 비교 대상이 아니다).
- 거르기를 되돌리는 것은 성과를 본 판단이 아니다 — 거르기의 근거(인증 가능성)가 결정으로 사라졌다는 사실만 쓴다.

## 4. 절차(재빌드가 끝난 뒤)

1. 선행: 이음매 세션의 RAWDATA 상장 전 행 삭제 → 팩터 DB 전체 재빌드 → 결합용 뷰 `--full` → FF 요인 — 세 판 표식 `completed_at` 채움.
2. P1S03 30칸 재측정(상설 판) → `round.sh - p4-pool`.
3. `tools/init_p4c03.R`(P4C02 init 복사 · 판 2 검사 줄 제거 · 시행 집합 원천 교체) → 사양 셋.
4. 철학 P1 · 판단 T1(사양 변경분 위주 · 이 초안에 대한 의견은 지금 받아 둔다) → `p4-check` → `p4-register --p1 --t1`.
5. `p4-base-measure` → 닫기 판독 ⑥ 기준 칸 사이드카 → `p4-workdir` 확인 → `tick_hold` 없이 무인 틱.
6. P4C02 = 닫지 않는다(P4C01 처리와 같다 · `tick_hold` 고정).
- 새 검사는 더하지 않는다(도훈 11-16) — P4C02 절차의 걸음 열기 양성 대조 다섯은 코어 v5 그대로라 다시 돌리지 않는다.

## 5. 알려진 한계

- 기저를 재빌드 뒤 기계가 고르므로 이 초안의 철학 정렬 검토는 '어느 기저든 같은 걸음 정책'에 대한 것이다 — 기저가 저β 표기 엔진이면 철학 P1 을 사양 변경분으로 한 번 더 받는다.
- 원 공시본이 없으므로 법정기한 + 45일 뒤에 나온 정정은 PIT 경계로 남는다(pit.md C4 · 기록).
- 상장 첫날 수익은 퀀티 값 그대로다(도훈 11-16).
