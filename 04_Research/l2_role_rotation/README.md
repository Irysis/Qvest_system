## 0. 무엇·왜

1계층 역할 등급(`06_Registry/strategy_roles.json`)은 **전기간** 통계이고 방어·공격 국면은 **사후** Pagan-Sossounov(PS) 연대기다
(`strategy_role.json` 스스로 "2계층 as-of 소비 금지"). 2계층이 시점 t 의 슬리브 소속을 정할 때는 C1·C14(선정 통계 = `Usable_Date ≤ 결정 시점`)
때문에 **t 이전 자료만으로 같은 통계를 다시 재야** 한다. 이 산출물이 그 라벨이다.

## 2. as-of 규칙

### 2.1 통계는 그대로, 입력만 자른다
- 역할 통계 = 정본 `sr_card()`(strategy_role.R) **그대로 호출** — β·잔차 `e = r − β·b`(α 포함)·국면 내 평균 t·OOS 분할·2요인 NW(3) α·
  문턱(t_A 2.95 · t_B 1.96 · OOS 2/3 · 최소 60개월)이 모두 잘린 표본(확장 창) 위에서 다시 계산된다. 재구현 없음.
- 원자료(전략 일간·월간 행 · 벤치 일간 · 사이즈 지수)를 **`date < t` 로 자른 뒤** 정본 월간화 규칙(벤치 거래일 결합 · 양 끝 캘린더 달 제거)에 넣는다.
  → 잘린 자료의 끝 달 T−1 도 '부분월 가능'으로 빠져 **일간 계열은 T−2, 월간 계열(BOOK_0001)은 T−3 까지** 쓴다(실측 80/1).
  보수적 1개월이지만, 이렇게 해야 t 의 라벨이 t 이후 자료의 **값과 존재 모두**에 의존하지 않는다(대조 i 양성 대조가 반례를 실측).
- 월간화는 정본 `rfd_monthly` 와 같은 규칙의 빠른 판(`sra_monthly_asof` — `format()` 1회)을 쓰고, 8 시점 × 81 구성원에서 정본 판과
  **월간 수익 비트 동일 81/81 · 라벨 표 전체 동일**을 매 실행 대조한다(`asof_controls/fast_vs_canonical.csv` · 불일치 = 생성 중단).
- 전기간 재현 확인: 같은 파이프라인을 전기간에 돌리면 레지스트리 카드 324/324 등급 일치 · 최대 |Δt| 5e-7(JSON 6자리 반올림).

### 2.2 PS 국면 — 잘린 벤치로 다시 판정하고 확정 구간만
- 모수 = `bbdetection::setpar_dating_alg()` 기본값(정본 `sr_regimes` 와 같은 호출: t_window 8 · t_censor 6 · t_phase 4 · t_cycle 16 · max_chng 20) —
  `strategy_role.json regimes.ps_bear.impl` 서술과 기동 시 대조(드리프트 = 중단).
- bbdetection 1.0 소스(`src/filter.cpp`) 판독: 극값 후보 = i ∈ [t_window, n − t_window) → **마지막 8개월에는 전환점이 생길 수 없다**
  (검열 6개월은 이 창 조건에 포함됨) · 고점 달 = 강세, 저점 달 = 약세 · 마지막 극값 뒤는 그 상태를 연장.
- 실측(`ps_phases_asof.csv`): 2005~ 결정 구간의 전환점 15개가 **전부 정확히 9개월 뒤** 처음 확정 · 확정 뒤 사라진 전환점 0 ·
  일시 소멸 3(고점 2004-03 → 2005-02~03, 2013-02 → 2013-12, 2024-06 → 2025-07~08 — 다음 저점 확정 전 지수가 고점을 넘어 끝단 검열이 지웠다가 저점 확정 때 복귀).
- **주판 `phase`**: 두 확정 전환점 사이의 **완결 국면**만 라벨 — 진행 중 국면(마지막 전환점 이후)·첫 전환점 이전 = NA → 방어·공격 어디에도 안 들어간다.
  근거 = 설계 §2.1 "시점 t 에 확정된 국면만(검열 창 지난 고·저점)" + 지시 "검열 창 안에서 끝나는 국면 = 미확정 → 미사용".
- 민감도 `state`: 진행 국면도 마지막 max(t_window, t_censor) − 1 = **7개월**(미검출 전환점이 상태를 바꿀 수 있는 꼬리)만 빼고 라벨.
- 둘 다 PIT 다(잘린 벤치만 본다) — 차이는 '라벨 개정 위험을 얼마나 받아들이나'뿐이다.
- `cgh36`(직전 36개월 벤치 누적 < 0)은 월초 기지 — 잘린 벤치로 같은 식. `lt_bear`(LT 강건성 기록)는 등급 입력이 아니라 NA(미산출).

### 2.3 diversifier — as-of 라벨 미산출(제외)
- 정의 = "기존 essence B+ 풀 대비 생성 회귀 α t". 비교 풀이 **현재** essence 권위 등급(1,300 구성원 · 전기간 · 2026 측정)으로 정해진다 —
  시점 t 의 B+ 풀을 재는 as-of essence 가 없다(이것이 구속). 2요인 잔차 e2(전기간 β)·계보 대표(전기간 상관 최대)·BIC 선택도 전기간이다.
- 비교 풀 통계만 as-of 로 바꾸고 풀 구성을 사후로 두면 C1 위반이 남는다 → 내지 않는다.
- 영향: 81 중 **11 개는 전기간 대표 역할이 diversifier 뿐** — 이들은 4역할 as-of 라벨로만 슬리브에 들어간다.
- 대안(결정 필요 — §6-3): (a) 비교 풀 = 같은 유니버스의 as-of 4역할 B+(정의 변경) · (b) as-of essence 계약 신설.

## 5. 2계층 소비 규칙
- 시점 t 의 슬리브 r = `asof_roles.parquet[decision_date == t & role == r & is_member]`. 주판 = `phase`, `state` 는 민감도.
  ⚠ 열 이름 `t` = t 통계다 — data.table 식 안에서 결정 시점 변수를 `t` 로 부르면 열이 가린다(이 작업 검산에서 실제로 걸림 · 변수명을 바꿀 것).
- **전기간 `pool_rep_roles` 와 교집합하지 말 것**(사후 선택 재도입). `member_meta.csv` 의 전기간 열은 기록용.
- 개시: 확정 약세 2회 = 2012-06 · 전 슬리브 ≥2 = 2015-10 — 그 전 구간은 빈/1개 슬리브 처리 규칙이 사전등록돼야 한다.
- diversifier 슬리브 없음(§2.3).
