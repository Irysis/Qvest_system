# Paper Note: P191 — 경기국면에 따른 리스크 팩터 배분 전략 (2022)

**Authors:** Samsung Securities Quantitative Strategy Team
**Source:** QUANTITATIVE ISSUE, Samsung Securities (2022년 5월 26일)
**Category:** Asset_Allocation
**Priority:** 1

## Core Thesis

Korean equity factors (Value, Earnings Momentum, Growth, Price Momentum, Inverse Size, Quality) have dramatically different performance across economic regimes. By identifying the current macro regime using two dimensions — 경기(business cycle) and 물가(inflation) — and allocating to factor portfolios accordingly, investors can substantially improve risk-adjusted returns over equal-weight factor allocation. The 4-regime framework (Recovery, Boom, Stagflation, Recession) drives factor selection.

## Strategy Description

**Regime Classification (2x2 matrix):**
- Dimension 1: 경기 (Business Cycle) = Export YoY z-score (수출 YoY)
  - Up: positive z-score (경기 상승)
  - Down: negative z-score (경기 하강)
- Dimension 2: 물가 (Inflation) = CPI YoY z-score
  - Up: positive z-score (물가 상승)
  - Down: negative z-score (물가 하강)

**4 Regimes:**
1. **Recovery (회복)**: 경기Up + 물가Down — best for Value, Growth
2. **Boom (확장)**: 경기Up + 물가Up — best for Price Momentum, Inverse Size
3. **Stagflation (스태그플레이션)**: 경기Down + 물가Up — best for Quality, Value
4. **Recession (침체)**: 경기Down + 물가Down — best for Quality, Inverse Size

**6 Factors:**
- Value: PBR, PER low quintile
- Earnings Momentum: Earnings revision direction
- Growth: Sales/earnings growth rate
- Price Momentum: 12-1 month return
- Inverse Size: Small-cap tilt (market cap inverse)
- Quality: ROE, gross profitability

**Strategy Construction:**
- Identify current regime using monthly data
- Allocate 100% to top 2 factors for that regime (or equal weight to all when regime unclear)
- Long-only, top quintile per factor, KOSPI/KOSDAQ200 universe
- Monthly rebalancing

**Performance (Backtest 2005-2022):**
- Regime-conditional factor allocation: CAGR ~15-18% vs KOSPI ~8%
- Sharpe ratio improvement: ~0.7-0.9 vs benchmark ~0.3
- Max DD: ~-25% vs KOSPI ~-50%
- Best regime-factor match dramatically outperforms naive factor allocation

## Key Results

- Factor performance is strongly regime-dependent in Korean market
- Quality factor most defensive across regimes (useful as baseline)
- Price Momentum works in Boom but severely hurts in Recession → regime conditioning critical
- Export YoY + CPI YoY is sufficient 2-variable regime classification for Korean market
- Equal-weight factor blending ignores >50% of available signal
- Regime transitions are the highest-alpha periods (lag 1-2 months)

## Implementation in Korean Market

**Direct implementation:**
- `macro_fred.parquet`: Korea CPI YoY series already available via FRED
- `fundamental_dart.parquet`: GPA (≈Quality), ROE (≈Quality), ICR for factor construction
- `RAWDATA.parquet`: Price momentum, inverse size directly computable from existing data
- Export YoY: Available from Bank of Korea/KOSIS API (not in current FRED 13-series set; **add this series**)

**Connection to existing infrastructure:**
- `macro_regime.parquet` already has YC_regime + VIX_regime; extend with 경기/물가 regime axis
- Factor construction already partially done via `data_collector_dart.R`
- Combine with existing Maxwell Protocol Step 2 (Factor)

**Key gap:** Export YoY data source needed — suggest adding KOSIS Export data via API

**Feasibility: HIGH** — aligns perfectly with user's regime-conditional approach
