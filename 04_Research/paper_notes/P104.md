# P104 — Liu (2006): A Liquidity-Augmented Capital Asset Pricing Model

**Citation:** Liu, W. (2006). A liquidity-augmented capital asset pricing model. *Journal of Financial Economics*, 82(3), 631–671.

---

## Core Thesis

Introduces a new liquidity measure **LMx** that captures **trading speed** — the ability to execute a desired trade quickly. Unlike Amihud ILLIQ (which captures price impact per dollar) or bid-ask spread (which captures trade cost), LMx focuses on the continuity of trading. Proposes a **two-factor model** (market + liquidity factor) that outperforms Fama-French 3-factor model in cross-sectional pricing.

Key insight: zero-volume days indicate trading paralysis — they measure liquidity in a fundamentally different way than price impact measures.

---

## Factor Construction

**LMx measure** (primary: LM12, 12-month lookback):

    LMx_i = [ #ZeroVol_i + (1 / x-month_turnover_i) / Deflator ] × (21x / NoTD_i)

where:
- #ZeroVol_i = number of zero-daily-volume days in past x months
- x-month_turnover_i = sum of daily turnover (vol/shares_out) over x months
- Deflator = 11,000 (ensures fraction in 0-1 range)
- 21x = maximum possible trading days in x months
- NoTD_i = actual number of trading days

**Interpretation:** Higher LMx = less liquid (more zero-volume days AND lower turnover). The dual component ensures both trading gaps AND trading volume are captured.

**Portfolio construction:**
- NYSE/AMEX stocks 1963–2003, monthly rebalancing
- Sort into deciles by LM12; D1 = least liquid, D10 = most liquid
- Long D1 – Short D10 = liquidity factor LMIF

**Key tests:**
- Fama-MacBeth regressions with LM12, size, B/M, momentum, earnings yield
- Two-factor model: R_i = α + β_MKT * MKT + β_LM * LMIF + ε

## Key Results

| Decile | Avg LM12 | Monthly Return |
|---|---|---|
| D1 (least liquid) | 68.9 | 1.58% |
| D5 | 8.3 | 1.18% |
| D10 (most liquid) | 0.9 | 0.90% |

- D1 minus D10 spread: **0.682%/month** after 12-month holding (t = 4.77)
- LM12 factor alpha vs. FF3: 0.82%/month (t = 5.30)
- **Two-factor (MKT + LMIF) model** explains cross-section better than FF3:
  - Explains book-to-market anomaly: high B/M stocks have high LM12 → captured by liquidity factor
  - Explains size: small stocks have high LM12 → captured by liquidity factor
  - Explains long-term contrarian (DeBondt-Thaler): past losers are illiquid → LM12 subsumes the reversal
  - Explains fundamental ratios (E/P, CF/P)
- LM12 contains information beyond Amihud ILLIQ — zero-volume days matter separately from price impact

## Korea-Specific Implications

- Zero-volume days are more common in Korean KOSDAQ than US markets — LMx may be **especially powerful** for KOSDAQ150 universe
- Korean small-caps often have extended no-trade periods due to price limits and thin float
- KOSDAQ stocks with frequent zero-volume days are precisely the stocks that should have higher expected returns
- LM12 is directly computable from RAWDATA.parquet (has daily volume and shares outstanding equivalent)
- The two-factor model (market + LM) is actually simpler to implement than FF3 and may be more appropriate for Korean universe where HML/SMB factors are less well-calibrated

## Actionable Implementation

**Directly implementable from RAWDATA.parquet:**

```r
# LM12 computation for Korean stocks
compute_lm12 <- function(df_stock) {
  # df_stock: daily data for one stock, sorted by date
  # Requires: volume, shares_outstanding (or turnover)

  df_stock %>%
    arrange(date) %>%
    mutate(
      zero_vol = as.integer(volume == 0 | is.na(volume)),
      turnover_d = volume / shares_outstanding  # daily turnover
    ) %>%
    group_by(ym = format(date, "%Y-%m")) %>%
    summarise(
      # Rolling 12-month: compute for each month end
      n_trading = n(),
      .groups = "drop"
    )
}

# Full LM12 with 12-month rolling window
compute_lm12_monthly <- function(daily_data) {
  daily_data %>%
    arrange(ticker, date) %>%
    group_by(ticker) %>%
    mutate(
      zero_vol = as.integer(volume == 0 | is.na(volume))
    ) %>%
    # Use slider package for rolling 252-day window
    mutate(
      zero_12m = slider::slide_dbl(zero_vol, sum, .before = 251, .complete = FALSE),
      turnover_12m = slider::slide_dbl(volume / shares_out, sum, .before = 251, .complete = FALSE),
      deflator = 11000,
      lm12 = (zero_12m + (1 / (turnover_12m + 1e-10)) / deflator) * (252 / n())
    )
}
```

**Signal:** ILLIQ is the best price-impact measure; LM12 is the best trading-continuity measure. Use both as separate columns in factor ensemble.
