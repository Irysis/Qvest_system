## Core Thesis
Constructs covariance matrices for portfolio optimization using machine learning (k-means clustering), bypassing the traditional factor model framework. The core problem: sample covariance matrices C_ij are singular when N (stocks) >> T (time observations), making them uninvertible and unusable for mean-variance optimization. Traditional solution (statistical or fundamental factor models) requires choosing factors. ML solution: cluster N stocks into K groups via k-means, construct a "heterotic" risk model from each clustering, then average M clusterings to produce a regularized, positive-definite covariance matrix.

**Key innovation:** The averaged model matrix Γ_ij is NOT a factor model — it is a weighted average of M semi-positive-definite "samplings." It outperforms statistical risk models and matches the performance of heterotic risk models based on statistical industry classifications, while remaining competitive with (though slightly below) fundamental industry classification risk models.

## Key Quantitative Results
Backtest results (N ~2000 US stocks, daily returns, intraday strategy):
- **Statistical risk model (PCA-based):** ROC ~40%, SR ~14, CPS ~2.0
- **ML risk model (K=40, M=100 samplings):** ROC = 42.53%, SR = 15.76, CPS = 2.09
- **Single sampling (K=40, M=1):** ROC = 42.43%, SR = 15.48, CPS = 2.04
- **Multilevel heterotic (statistical classification):** Similar to ML model
- **Fundamental industry classification:** Best — ML and multilevel statistical models underperform fundamental by a small but consistent margin

Key algorithmic parameters:
- N = number of stocks, T = lookback days (T << N in practice)
- K = number of clusters (hyperparameter; tested K=40 to K=150)
- M = number of k-means samplings (M=100 recommended; M=1 already substantial improvement)
- Inputs to cluster: **variance-normalized returns** R̂_is = R_is / (σ_i · u_i) where u_i = σ_i / v, v = exp(Median(ln(σ_i)) - 3·MAD(ln(σ_i)))

Effective rank (eRank) used to detect degenerate eigenvalues:
```
eRank(S) = exp(H),  H = -Σ_a p_a · ln(p_a),  p_a = λ^(a) / Σ λ^(b)
```
(spectral entropy of eigenvalue distribution)

R source code for the full algorithm is provided in Appendix A: `qrm.calc.ml.cor.mat()` function.

## Application to Korean Market
**Can we apply this to Korean market? Yes, with modifications.**

Korean market structure: N ≈ 350-804 tickers, T ≈ 252 daily observations per year. The N/T ratio is ~1.4-3.2, meaning sample covariance is badly singular. This is the exact problem the ML risk model solves.

**Required inputs (all available in our pipeline):**
1. Daily return matrix R_is from `RAWDATA.parquet` (804 tickers, 6,300+ daily obs)

**Korean-specific considerations:**
1. **K selection**: For N~350 Korean stocks, K=20-40 clusters is appropriate (K << N but K should capture GICS sub-industry structure)
2. **Lookback window**: Use 63 trading days (~3 months) to capture current regime; avoid stale covariance during market transitions
3. **Sector structure**: Korean market has strong GICS clustering (tech/semiconductor, financials, chemicals/materials); k-means on variance-normalized returns should naturally recover these clusters
4. **Chaebol cross-holdings**: Samsung group stocks (Samsung Electronics, Samsung SDI, Samsung Life) have elevated cross-correlations from business group ties — ML clustering will correctly group these, improving risk model accuracy vs. generic PCA

**Advantage over current approach**: Our current `backtest_harness.R` uses sample covariance or equal-weighting — neither is well-conditioned for Korean concentrated portfolios. The ML risk model provides an invertible, stable covariance matrix for 20-30 stock optimization without requiring explicit factor model assumptions.
