## 1. Core Thesis

가치 팩터(Value Factor)와 성장 팩터(Growth Factor)의 역사적 성과를 재검토하고, 2007-2017년의 가치 팩터 부진(이른바 "Value is Dead" 논쟁) 원인을 분석한다. P/B(장부가/시장가)만이 아닌 다차원 가치 지표의 성과를 비교하고, 가치 팩터가 여전히 유효한지 이론적·실증적으로 점검한다.

## 5. Why Did P/B-Based Value Underperform 2007-2017?

### 원인 1: 무형자산의 증가 (Intangible Asset Growth)
```
B (장부가치) = 유형자산 중심
실제 기업가치 = 유형 + 무형 (브랜드, 특허, 소프트웨어, 인적자본)
```
- IT/헬스케어 기업: 무형자산 비중 증가 → P/B 높아도 "진짜 저평가" 아님
- 전통 산업: P/B 낮아도 무형자산 없어서 "저평가" 아님
- 해결: 무형자산 조정 P/B → R&D 자본화, 광고비 자본화

### 원인 2: 저금리 환경의 성장주 프리미엄
- 2008-2021 제로금리 → 장기 현금흐름의 현재가치 증가
- 성장주: 미래 현금흐름 비중 높음 → 저금리에서 유리
- 가치주: 현재 현금흐름 비중 높음 → 금리 변화 덜 민감

### 원인 3: 기술주 생산성 프리미엄
- 닷컴 버블 이후 IT 기업들의 실제 높은 수익성 실현
- 단순 P/B로는 "과대평가"로 보이지만 실제 ROIC 높음
- 가치 함정(value trap)이 아닌 진정한 성장 기업

### 원인 4: 저품질 가치주 문제
- 단순 P/B 낮음 = 재무 어려움 기업 포함
- Distressed value (부실 가치주) → 퀄리티 필터 없는 순수 P/B의 약점

## 6. Solutions and Improvements

### 개선 방향 1: 무형자산 조정
```
Adjusted B = 장부가치 + 자본화된 R&D + 자본화된 광고비
  - R&D 자본화: 과거 N년 R&D 비용을 감가상각률 적용 자산화
  - 광고비 자본화: 과거 N년 광고비를 자산화
Adjusted P/B = P / Adjusted B
```

### 개선 방향 2: 복합 가치 지표
- P/E + P/CF + EV/EBITDA + P/S 복합
- 단일 지표 대비 강건성 향상
- P/B 의존도 축소

### 개선 방향 3: Quality Filter 추가 (QARP)
- 가치 + 퀄리티 결합 (P183과 연계)
- 부실 가치주 제거 → "가격 합리적인 퀄리티 주식"
- 가치 팩터 Sharpe Ratio 향상

### 개선 방향 4: Valuation Spread 모니터링
- 가치-성장 밸류에이션 스프레드 확장 → 리밸런싱 기회
- 스프레드 극단적 확장 시기 = 가치 팩터 강화 시점

## 8. Value vs Growth: Cyclicality

### 가치 팩터 사이클 패턴
- 경기 확장기 초반: 가치주 강세
- 경기 후퇴기 말: 성장주 강세
- 금리 상승기: 가치주 상대 강세
- 금리 하락기: 성장주 상대 강세

### 레짐 조건부 가치 투자
```
매크로 레짐별 가치 팩터 활성화 기준:
- YC slope > 0 (yield curve 정상화) → 가치 팩터 ON
- Credit spread 정상 수준 → 가치 팩터 ON
- 금리 상승 레짐 → 가치 팩터 강화
```

---

## 9. Valuation Spread Analysis

### 가치-성장 스프레드 측정
```
Valuation Spread = 가치주 평균 P/B^(-1) - 성장주 평균 P/B^(-1)
= 가치주 평균 BE/ME - 성장주 평균 BE/ME
```

- 스프레드 역사적 고점 수준 (2017-2019, 2022-현재)
- 극단적 스프레드 = 향후 가치 팩터 복귀 기대 신호

## 10. Strategy Ideas Derived

### Idea 1: Composite Value Factor for Korea
P/B(=BE/ME, P178-P179) + P/E + P/CF 복합 가치 → 단순 HML 개선
- `fundamental_dart.parquet`의 EPS, EBITDA, 영업현금흐름 활용

### Idea 2: Intangible-Adjusted P/B
R&D 집약 섹터(IT, 헬스케어)에서 R&D 자본화 조정 P/B 계산
- 한국 DART의 연구개발비 데이터 활용

### Idea 3: Value-Quality Regime Strategy
가치 팩터 + 퀄리티 필터(P183) + 레짐 신호(P182 implied ERP) 삼중 레이어
- 가치 스프레드 극단 + 금리 상승 레짐 + 높은 ERP = 가치 팩터 최대 ON
