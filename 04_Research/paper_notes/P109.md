# P109 — Ibbotson, Chen, Kim & Hu (2013): Liquidity as an Investment Style

**Citation:** Ibbotson, R., Chen, Z., Kim, D.Y.J., & Hu, W.Y. (2013). Liquidity as an investment style. *Financial Analysts Journal*, 69(3), 30–44.

---

## Core Thesis

Positions **liquidity as a standalone investment style** equivalent to size, value, and momentum. Uses annual share turnover as the liquidity measure and demonstrates that low-liquidity stocks have dramatically higher returns than high-liquidity stocks — a 7.26% annual spread — even after controlling for size, value, and momentum. The key claim: liquidity is an independent dimension of the cross-section, not subsumed by other factors.

---

## Factor Construction

**Liquidity measure:** Annual turnover = annual share volume / average shares outstanding

- Annual lookback (not monthly) to reduce noise
- Higher turnover = MORE liquid = LOWER expected return
- Lower turnover = LESS liquid = HIGHER expected return

**Portfolio construction:**
- Universe: Top 3,500 US stocks by market cap (value-weighted universe similar to Russell 3000)
- Annual sort at December 31 into 4 quartiles (Q1 = lowest turnover = least liquid, Q4 = highest)
- Annual rebalancing
- Period: 1972–2011 (39 years)

**Liquidity factor construction:**
- Long Q1 (low turnover) – Short Q4 (high turnover)
- Dollar-neutral, monthly rebalanced for factor returns

---

## Key Results

| Quartile | Avg Annual Turnover | Geometric Mean Return |
|---|---|---|
| Q1 (least liquid) | 34% | **14.50%** |
| Q2 | 73% | 12.04% |
| Q3 | 125% | 11.39% |
| Q4 (most liquid) | 269% | **7.24%** |

- Q1 minus Q4 spread: **7.26% per year** (geometric)
- Q1 has **LOWER standard deviation** than Q4 (19.5% vs 21.8%) — so risk-adjusted premium is even larger!
- Liquidity factor monthly alpha vs. CAPM: 0.66%/month (t = 4.52)
- Liquidity factor monthly alpha vs. FF3: 0.44%/month (t = 3.93)
- Double-sort tests: within each size quartile, low-liquidity stocks outperform
- Within each value quartile: low-liquidity stocks outperform
- Within each momentum quartile: low-liquidity stocks outperform
- **Independence confirmed**: liquidity effect is additive to size, value, momentum

Return contribution breakdown across styles:
- 4-style model explains virtually all of the liquidity factor alpha as distinct from other styles

## Actionable Implementation

```r
# Annual turnover-based liquidity measure
# Directly computable from RAWDATA.parquet

compute_annual_turnover <- function(daily_data, year) {
  daily_data %>%
    filter(format(date, "%Y") == as.character(year)) %>%
    group_by(ticker) %>%
    summarise(
      annual_volume = sum(volume, na.rm = TRUE),
      avg_shares_out = mean(shares_outstanding, na.rm = TRUE),
      n_days = n(),
      .groups = "drop"
    ) %>%
    mutate(
      annual_turnover = annual_volume / avg_shares_out,
      # Normalize: lower turnover = less liquid = higher expected return
      liquidity_rank = percent_rank(annual_turnover)  # 0 = least liquid
    )
}

# Factor construction: Q1 (low turnover) minus Q4 (high turnover)
# Annual rebalance, monthly return measurement

liquidity_factor <- function(returns_data, turnover_data) {
  # Join turnover (lagged 1 year) with next-year returns
  # Long bottom quartile (turnover < 25th pctile)
  # Short top quartile (turnover > 75th pctile)
  returns_data %>%
    left_join(turnover_data, by = c("ticker", "formation_year")) %>%
    mutate(
      side = case_when(
        turnover_pctile <= 0.25 ~ "long",   # Q1: low turnover, high premium
        turnover_pctile >= 0.75 ~ "short",  # Q4: high turnover, low premium
        TRUE ~ "neutral"
      )
    )
}
```

**Key takeaway for STR_016:** Annual turnover is the simplest and most powerful liquidity signal. In Korea, the 7% annual spread (if it holds) is comparable to value and momentum premiums. Should be included in any multi-factor composite.
