# P076: Transaction Costs and Crowding (Chincarini 2018)
**Category:** Factor_Return / Crowding
**Feasibility:** medium (transaction cost model complexity; core insight directly applicable)
**Novelty:** medium (sequel to P075; extends crowding analysis to include transaction costs)

## Core Claim
Transaction costs, when properly incorporated into portfolio optimization, reduce rather than increase portfolio crowding for portfolio sizes up to $5 billion AUM. Crowding in long-only portfolios declines monotonically as portfolio size grows from $500M to $5B because larger market impact costs force the optimizer to diversify into more stocks (spreading trades over more names to minimize impact). Crowding only starts to increase again above $20B AUM.

## Crowding Detection Method (exact metrics if available)
Uses the same cosine similarity framework as P075 (Bruno et al. 2018):
```
C = (Σ_{i=1}^M Σ_{j=1}^M S_{i,j} - M) / (M² - M)
Ω = C_portfolio / C_alpha
```

**Transaction cost models:**
- Model 1 (Almgren et al. 2005): `c_{it} = (I/2) + sgn(n_{it}) × η × σ_{it} × |n_{it}/V_{it}|^(3/5)`
  where I = γ × σ_{it} × (N_{it}/V_{it})^(1/4), γ=0.314, η=0.142
- Model 2 (Northfield 2015): `c_{it} = B_{it}|n_{it}| + C_{it}|n_{it}|^(0.5)` (parameters estimated monthly)
- Spread cost added to both: `tc_{it} = C_{it} + |100s_{it}/2p_{it}| + |c_{it}|`

**After-transaction-cost alpha:** `ã_{it} = Z̃_{it}w_{it} - tc̃_{it}`
where tc̃ is approximated by quadratic: `tc̃_{it} = a_{it}w_{it} + b_{it}w_{it}²`

**Empirical results (US S&P 500 universe, 2006–2013):**
- Long-only, no TC: C = 0.58 ($500M), declining to C = 0.42 ($5B), rising to C = 0.50 ($20B)
- Long-only, with TC1: C = 0.49 ($500M), declining to C = 0.38 ($5B), rising to C = 0.50 ($20B)
- TC reduces crowding by ~14–18% for $500M–$5B portfolios
- Market neutral portfolios: C ≈ 0.00 regardless of TC or portfolio size

## Key Results
- Transaction costs create a natural de-crowding mechanism for mid-sized portfolios
- Small portfolios ($500M) → TC is small → optimizer ignores liquidity → more crowded
- Large portfolios ($5B) → TC is significant → optimizer diversifies across more liquid stocks → less crowded
- Very large portfolios ($20B) → TC forces concentration in only the most liquid mega-caps → crowded again
- Factor portfolios (value, momentum, low-beta) show same qualitative patterns as random alpha portfolios
- The quant crisis of 2007 was more likely caused by crowded alpha models than crowded transaction cost models (contra Chincarini 2012)

## Korea Applicability
- **Portfolio size**: Korean quant strategy funds are typically $100M–$500M AUM (smaller than US benchmarks used in paper)
- At $100M–$500M range, TC is relatively small → optimizer stays crowded → TC does NOT de-crowd
- This means Korean LowVol strategies are likely MORE crowded than US equivalents at the same strategy type because smaller portfolio size = smaller TC friction = more correlated optimization
- **Practical implication**: Cannot rely on transaction costs to naturally reduce crowding. Must actively implement crowding controls (RMPC, MPA, etc.)
- **Transaction cost proxy for Korea**: Korean stock exchange provides ADTV data. Market impact can be estimated using Almgren model with Korean parameters (σ from RAWDATA, V from volume data).
