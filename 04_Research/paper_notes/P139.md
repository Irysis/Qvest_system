## Core Thesis

**Gross profitability (GP/A)** — revenues minus cost of goods sold, scaled by total assets — is the "cleanest" accounting-based profitability measure. It is as powerful as book-to-market in predicting cross-sectional returns, but **negatively correlated with value** (-18%), making it the ideal complementary factor.

GP/A is grounded in economic theory: it is closest to the theoretical construct of "true economic profitability" before accounting manipulations, accruals, and allocation decisions distort the signal.

---

## Factor Definition

```
GP/A = (REVT - COGS) / AT
```

Where:
- REVT = total revenues
- COGS = cost of goods sold
- AT = total assets

**Decomposition:**
```
GP/A = Asset Turnover × Gross Margin
     = (REVT/AT) × (GP/REVT)
```

Both components independently predict returns, but the combined GP/A is simpler and more powerful.

## Economic Interpretation

1. **Why gross vs. net profitability?** Net income is polluted by: depreciation choices, R&D capitalization, accruals, tax optimization, interest deductions. Gross profit strips these away to reveal underlying competitive advantage.

2. **Why GP/Assets, not GP/Revenue (margin)?** Asset turnover varies enormously across industries. GP/A is comparable across sectors — a tech firm and a grocery chain both face the same assets constraint.

3. **Persistence justification**: Firms with high GP/A are not mean-reverting; they have structural cost advantages that persist 10+ years (slope = 1.60 at 10-year horizon). Market undervalues this persistence.

4. **Value vs. Profitability interaction**: Value (B/M) identifies *cheap* stocks; profitability identifies *good* stocks. Best returns come from stocks that are both cheap AND good — "value-quality" combo.

## Korean Implementation

**DART mapping:**
```
GP/A = (매출액 - 매출원가) / 자산총계
```

**Korean-specific considerations:**

1. **Gross profit definition**: Some Korean companies (especially service/IT firms) may report only 영업이익 without separating 매출원가. For these, fall back to: GP_proxy = 영업이익 + 판매관리비

2. **Industry adjustment is CRITICAL for Korea**: KOSPI200 contains heavy industry concentration (Samsung Electronics alone = ~30% of index). Industry-adjust GP/A within KOSPI/KOSDAQ and within industry SIC equivalents.

3. **Annual rebalancing suffices**: GP/A persistence (10-year slope = 1.60) means monthly rebalancing is not worth transaction costs for Korean market (higher bid-ask spreads than US).

4. **Formation date**: April 1 (after 사업보고서 filing March 31) — NOT June

5. **Consolidated financials only**: 연결재무제표 — standalone 별도 financials distorted by chaebol subsidiaries

6. **KOSDAQ IT firms**: If COGS unavailable, use 매출총이익 reported directly in 포괄손익계산서

**Implementation code (R):**
```r
# GP/A computation from DART data
gpa_dt <- dart_fund %>%
  filter(account_nm %in% c("매출액", "매출원가", "자산총계")) %>%
  pivot_wider(names_from = account_nm, values_from = thstrm_amount) %>%
  mutate(
    gross_profit = 매출액 - 매출원가,
    gpa = gross_profit / 자산총계
  )

# Industry-adjusted GP/A (critical for Korea)
gpa_dt <- gpa_dt %>%
  group_by(fiscal_year, industry) %>%
  mutate(gpa_ind_adj = gpa - mean(gpa, na.rm=TRUE)) %>%
  ungroup()

# Portfolio sort (30/70 breakpoints within KOSPI200 + KOSDAQ150)
gpa_dt <- gpa_dt %>%
  group_by(fiscal_year, index_type) %>%
  mutate(
    gpa_rank = percent_rank(gpa_ind_adj),
    pmu_group = case_when(
      gpa_rank >= 0.70 ~ "High",
      gpa_rank <= 0.30 ~ "Low",
      TRUE ~ "Mid"
    )
  )
```

**Regime conditioning:**
- GP/A premium is most stable across regimes (persistent fundamental advantage)
- Slight outperformance in RECOVERY phase as markets reprice fundamental quality
- No dramatic regime-dependency vs QMJ Safety
