## Core Claim
Portfolio crowding arises structurally from the MVO optimization process and standard industry risk models, independently of whether managers have similar or unrelated alpha models. Long-only portfolios are intrinsically crowded (C ≈ 0.85–0.86) due to the weights-sum-to-1 constraint. Applying Marchenko-Pastur (MP) random matrix theory adjustment to the covariance matrix reduces crowding by 14% while maintaining portfolio efficiency. Diversifying risk model usage in the financial system would reduce systemic crowding by up to 40%.

## Crowding Detection Method (exact metrics if available)

**Cosine Similarity Crowding Measure:**
For portfolio weight vectors w_i and w_j of portfolios i and j:
```
s_{ij} = (w_i' w_j) / (|w_i| × |w_j|)
```
For M portfolios, the N-by-M holdings matrix H:
```
S = (H'H) ∘ H_hat   where H_hat normalizes each column by its Euclidean norm
C = (Σ_{i=1}^M Σ_{j=1}^M S_{i,j} - M) / (M² - M)
```
C ∈ [0,1] for long-only; C ∈ [-1,1] for long-short.

**Omega ratio (Ω):** measures how much portfolio construction adds crowding:
```
Ω = C_portfolio / C_alpha
```
Ω > 1 → optimization process creates more crowding than alpha signals alone.

**MPA (Marchenko-Pastur Adjusted) covariance matrix:**
1. PCA decompose: Σ_r = U Λ U' (eigendecomposition)
2. Compute MP upper bound: λ+ = σ² (1 + sqrt(N/T))² where T = trading days, N = stocks
3. Keep only K eigenvalues with λ_k > λ+ (statistically significant)
4. Reconstruct: Σ_r^MPA = U* Λ* U*' (using only K significant eigenvectors/values)
5. Use Σ_r^MPA in MVO instead of Σ_r

**Empirical parameters (US S&P 500 universe, 2006–2013):**
- Long-only Regular: C = 0.85–0.86 (2006–2009) and C = 0.70–0.71 (2010–2013)
- Long-only MPA: C = 0.72–0.73 (2006–2009) and C = 0.56–0.57 (2010–2013)
- 14% reduction in C from MPA, statistically significant at 99% level
- Market neutral: C ≈ 0.00 (structural crowding from weights constraint absent)

**Source of crowding by constraint type (Scenario analysis):**
- No constraints: C ≈ 0.03 (near zero)
- Weights sum to 1 only: C ≈ 0.91 (most crowding from this constraint alone)
- + Sector constraints: C ≈ 0.89 (sector constraints slightly increase crowding)
- + Max weight per stock: C ≈ 0.89 (max weight adds little)

**Risk model diversification effect (Table 4):**
- 100% one model: C = 0.85–0.86
- Equal split across 3 models (33-33-34): C = 0.51 (40% reduction)

## Key Results
- Most crowding in long-only portfolios is structural, arising from weights-sum-to-1
- MVO converges toward the lowest-variance eigenvector → all managers holding similar low-risk portfolios
- Crowding peaked around Aug 2007 and continued rising through 2009 (Fig 2, Fig 3)
- Crowding at the financial system level is reduced when risk model usage is diversified
- Random alpha models produce C = 0.85–0.86; factor alpha models produce similar levels
- MPA reduces crowding primarily by ignoring random (noise) eigenvectors that create spurious similarity
