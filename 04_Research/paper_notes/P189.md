# Paper Note: P189 — Advancing Markowitz: Asset Allocation Forest (2024)

**Authors:** Yin, Shi, et al.
**Source:** SSRN Working Paper (2024)
**Category:** Asset_Allocation
**Priority:** 2

## Core Thesis

Asset Allocation Forest (AAF) is a non-parametric tree-based method for dynamic asset allocation that replaces Markowitz mean-variance optimization with a random forest framework. Instead of estimating expected returns and covariance matrices (which suffer from estimation error), AAF directly maps economic/market state variables to optimal portfolio weights. It learns allocation rules from historical data non-parametrically, avoiding the well-known instability of classical MVO.

## Strategy Description

**Framework:**
- Random Forest variant where each tree maps state variables → portfolio weights
- State variables include: VIX level, yield curve slope, credit spreads, momentum signals, macro indicators
- Splits in each tree are based on portfolio Sharpe ratio improvement (not simple return prediction)
- Ensemble of trees averages the weight recommendations
- Portfolio weights are directly output (not return forecasts + separate optimization step)

**Key Innovations over Classical MVO:**
1. No covariance matrix inversion (avoids estimation error amplification)
2. Non-linear interactions between state variables captured
3. Regime-adaptive: tree splits naturally identify regime boundaries
4. Robust to outliers vs. Gaussian assumptions in MVO

**Asset Universe:** Global multi-asset (equities, bonds, commodities, real estate)
**Rebalancing:** Monthly
**State Variables Used:** ~15-20 macro + technical variables

**Performance:**
- Out-of-sample SR: ~0.9-1.1 vs. 60/40 SR ~0.5
- Maximum drawdown reduction vs. MVO: ~30-40%
- Consistent across sub-periods (1990-2023)
- Robust to different hyperparameters (number of trees, depth)

## Key Results

- AAF significantly outperforms classical MVO and 1/N equal-weight in OOS tests
- Most important state variables: VIX, yield curve slope, 12-month equity momentum
- AAF naturally avoids extreme positions that plague MVO
- Performance advantage largest in crisis periods (2000-02, 2008-09, 2020)
- Interpretable: can extract partial dependence plots showing how each state variable affects allocations
- Regularization via ensemble averaging prevents overfitting to historical data

## Implementation in Korean Market

**Relevance to existing infrastructure:**
- `macro_regime.parquet` provides 4 regime signals (VIX, YC, Credit, Buddha) that could be AAF state variables
- `RAWDATA.parquet`: Korean equity returns for training
- `fundamental_dart.parquet`: Fundamental state variables for each stock

**Korean adaptation:**
- State variables: VIX_regime, YC_regime, Credit_regime, Korea Export YoY, KOSPI 12M momentum
- Target: optimal allocation across KOSPI, Korean bonds (KTB), gold (GLD)
- Train on 2001-2018, test on 2019-2026
- R implementation: `ranger` package (fast random forest) with custom split criterion

**Feasibility: MEDIUM** — requires custom split criterion implementation; ranger package is available
