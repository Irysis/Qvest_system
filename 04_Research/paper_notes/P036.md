# P036: Crowding: Evidence from Fund Managerial Structure (Factor Investing & Crowding)
**Year:** 2019-2020 | **Authors:** Campbell R. Harvey, Yan Liu, Eric K.M. Tan, Min Zhu | **Category:** Data_Mining / Risk_Management

---

## Core Finding

Harvey and colleagues argue that factor crowding is a first-order risk for systematic investors that is structurally underappreciated. As the AUM chasing factor strategies grows — 145 new factor-investing products launched in 2018 alone — more capital competes for the same return sources, eroding alpha and increasing crash risk. The paper documents that the **shift from single-manager to team-managed funds is itself a response to crowding**: adding new managers diversifies idea generation and reduces any single idea's crowding. Crowded trades exhibit a **dangerous feedback loop**: as profitability declines, managers use more leverage to maintain target returns, which amplifies unwind severity when positions are liquidated. The paper provides both conceptual frameworks and empirical evidence that crowding produces a characteristic pattern: **factor returns deteriorate, correlations within the factor increase, and drawdowns become sharper and more correlated across strategies** holding the same exposures.

## Methodology

- **Crowding Metrics (from related literature synthesized in this work):**
  1. **Factor-model vs. PCA volatility divergence**: If the gap between factor-model-implied portfolio volatility and PCA-derived empirical volatility widens, the factor model is missing a crowding risk component — a warning signal.
  2. **CoMetric (Lou & Polk 2014)**: Measures correlation in returns among stocks held by the same strategies. High CoMetric = stocks that are moving together beyond fundamentals — a crowding footprint.
  3. **Return Correlation Among Factor Portfolios**: When previously uncorrelated factor portfolios begin showing elevated return correlation, crowding is causing co-movement.
  4. **Manager Portfolio Overlap**: Track the Jaccard similarity (or overlap coefficient) of holdings across systematic funds.
  5. **Flow-Performance Feedback**: Track AUM flows into factor strategies; rapid inflows signal increasing crowding.
- **Divergence vs. Convergence Premia** (Baltas 2019 framework, cited):
  - Divergence premia (Momentum, Trend-Following): no fundamental anchor, self-reinforcing, **most susceptible to crowding crashes**.
  - Convergence premia (Value, Quality): mean-revert to fundamental anchor, **self-correcting**, more resilient to crowding.
- **Empirical evidence**: Team-managed funds have less concentrated portfolios (lower HHI of holdings), lower returns to scale sensitivity — consistent with idea-crowding mitigation.

## Korean Market Application

**Crowding risk in the Korean factor landscape:**

1. **Korea-specific amplifiers:**
   - KOSPI200 + KOSDAQ150 is a concentrated universe (~800 stocks), making crowding worse than in the US (~5,000 stocks).
   - Domestic quant fund AUM has grown rapidly post-2015; Korean quant hedge funds (long-short PEF structures) now run similar factor signals.
   - Short-selling is episodically banned in Korea (e.g., Nov 2023 - March 2024 ban), forcing long-only implementations and creating asymmetric crowding: only long-side crowding can build.

2. **Most crowded factors in Korea (qualitative assessment):**
   | Factor | Crowding Risk | Reason |
   |--------|--------------|--------|
   | Low Volatility (STR_011) | **MEDIUM** | Well-known globally; domestic quant funds use it; BUT Korean retail investors prefer high-volatility stocks → contrarian flow may protect |
   | Momentum | **HIGH** | Domestic retail herding amplifies momentum → crowding risk elevated; crash risk significant |
   | Value (HML) | **LOW-MEDIUM** | Less systematically exploited by domestic quant funds; foreign institutional value investors exist but not dominant |
   | Quality/QMJ | **LOW** | Less well-known domestically; DART-based implementation is new → early-mover advantage |
   | MAX/Anti-Lottery | **VERY LOW** | No documented Korean quant fund running this explicitly |

3. **STR_011 (Macro-Gated LowVol) crowding risk assessment:**
   - The global low-volatility ETF industry holds billions in low-beta Korean stocks; this creates structural crowding in the most defensive names.
   - The LowVol factor's MDD of 42.2% in our backtest may partly reflect crowding-driven crashes (e.g., March 2020 COVID unwind, 2022 growth-rotation).
   - **Monitoring signal for STR_011**: Track the within-sector return correlation of the low-volatility portfolio. If stocks in the portfolio suddenly show elevated cross-correlation beyond sector effects, it signals crowding.
   - **Mitigation**: STR_011's macro-gating (shift to cash during crisis) already partially addresses crowding unwind risk by exiting during the high-correlation period.

**Feasibility:** HIGH (for monitoring signals and risk management application)

## Strategy Ideas

### IDEA-MONITORING: Crowding Score for Existing Strategies

**Purpose:** Add a crowding monitoring layer to STR_011, STR_017, and planned DART-based strategies.

**Implementation in R (OHLCVS-based):**
```r
# Monthly crowding monitoring signal
# 1. Compute rolling correlation matrix of returns within the long portfolio
compute_crowding_score <- function(port_returns_matrix, window = 12) {
  # port_returns_matrix: T x N matrix of monthly returns for held stocks
  cor_mat <- cor(port_returns_matrix[max(1, nrow(port_returns_matrix)-window+1):nrow(port_returns_matrix), ])
  # Average pairwise correlation (upper triangle, excluding diagonal)
  n <- ncol(cor_mat)
  avg_corr <- mean(cor_mat[upper.tri(cor_mat)])
  return(avg_corr)
}

# Threshold: if avg_corr > 0.5 (stocks moving together beyond factor), crowding alert
# Action: reduce position sizing, increase diversification, or exit to cash (consistent with STR_011 gating)
```

**Signal interpretation:**
- avg_corr < 0.3: Normal, factor working independently
- avg_corr 0.3-0.5: Elevated, monitor
- avg_corr > 0.5: Crowding alert, consider position reduction
- avg_corr > 0.7: Severe crowding, crisis-exit protocol (same as STR_011 VIX gate)

**Cost:** Pure OHLCVS computation, no additional data needed.

### IDEA-STRUCTURAL: Barrier-to-Entry Factor Selection

**Thesis (from Harvey's crowding framework):** Factors with higher implementation barriers are less susceptible to crowding. DART-based factors (Accrual, QMJ, Asset Growth) have higher barriers than price-based factors (Momentum, LowVol). Our planned DART strategies (STR_012-017) may thus have longer half-lives of alpha decay than LowVol.

**Implication for strategy prioritization:**
```
Priority order (crowding-adjusted expected half-life):
1. DART-based quality (STR_013 QMJ) — high barrier, low crowding risk
2. DART-based accruals (STR_012) — high barrier, moderate crowding risk
3. OHLCVS-based Anti-Lottery (STR_019) — moderate barrier, low crowding (novel in Korea)
4. LowVol (STR_011) — low barrier, moderate crowding risk (already pass)
5. Momentum — low barrier, HIGH crowding risk (do not prioritize)
```

### IDEA-PORTFOLIO: Crowding-Diversified Ensemble

**Thesis:** Blend strategies that have LOW pairwise crowding correlation. DART-based fundamental factors (convergence premia) + LowVol (convergence premium) + Anti-Lottery (orthogonal to both) should form a crowding-diversified ensemble.

**Proposed blending:**
- STR_011 (LowVol, convergence) = 40%
- STR_013 (QMJ, convergence) = 30%
- STR_019 (Anti-Lottery, orthogonal) = 30%

Expected: lower co-crash risk than LowVol alone. The ensemble captures three distinct behavioral inefficiencies (risk-based defensiveness + quality mispricing + lottery overpricing) that are unlikely to unwind simultaneously.

## Crowding Monitoring Dashboard (Practical Implementation)

Add to monthly monitoring script alongside STR_011:

```r
# Monthly crowding dashboard — run after backtest_harness load_rawdata()
monitor_crowding <- function(port_holdings, ret_data, window_months = 12) {

  # 1. Intra-portfolio return correlation
  port_ret <- ret_data[ticker %in% port_holdings, .(ret = mean(Ret)), by = .(date, ticker)]
  ret_wide <- dcast(port_ret, date ~ ticker, value.var = "ret")
  ret_mat <- as.matrix(ret_wide[, -1, with = FALSE])
  avg_corr <- mean(cor(ret_mat, use = "pairwise.complete.obs")[upper.tri(diag(ncol(ret_mat)))], na.rm = TRUE)

  # 2. HHI of portfolio weights (concentration)
  wt <- rep(1/length(port_holdings), length(port_holdings))
  hhi <- sum(wt^2)

  # 3. Factor-model vs empirical vol gap
  # (simplified: compare rolling SD of equal-weight portfolio vs. average individual stock SD)
  port_ew_ret <- ret_data[ticker %in% port_holdings, .(ew_ret = mean(Ret)), by = date]
  port_vol <- sd(port_ew_ret$ew_ret, na.rm = TRUE)
  avg_stock_vol <- ret_data[ticker %in% port_holdings, .(vol = sd(Ret, na.rm = TRUE)), by = ticker][, mean(vol)]
  diversification_ratio <- avg_stock_vol / port_vol

  list(
    avg_pairwise_correlation = avg_corr,
    hhi_concentration = hhi,
    diversification_ratio = diversification_ratio,
    crowding_alert = avg_corr > 0.5
  )
}
```
