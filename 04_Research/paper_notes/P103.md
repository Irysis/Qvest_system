# P103 — Brennan & Subrahmanyam (1996): Market Microstructure and Asset Pricing

**Citation:** Brennan, M.J., & Subrahmanyam, A. (1996). Market microstructure and asset pricing: On the compensation for illiquidity in stock returns. *Journal of Financial Economics*, 41(3), 441–464.

---

## Core Thesis

Uses the Glosten-Harris (1988) structural model to estimate **Kyle's lambda (λ)** from intraday trade data — the first paper to directly link microstructure-estimated price impact to expected returns in the cross-section. Two distinct components of illiquidity are priced:
- **Variable cost** (λ): price impact per share (inventory/information cost) — proportional to trade size
- **Fixed cost** (ψ): per-transaction cost independent of size (order processing)

Both components independently and significantly predict expected stock returns after Fama-French 3-factor adjustment.

---

## Factor Construction

**Glosten-Harris model:**
    Δp_t = λ * q_t + ψ * [D_t - D_{t-1}] + y_t

where:
- q_t = signed trade size in shares
- D_t = trade direction indicator (+1 buy, -1 sell)
- λ = variable (proportional) transaction cost = Kyle's lambda
- ψ = fixed cost component (half of effective bid-ask spread)
- y_t = efficient price innovation

From estimated λ and ψ, compute proportional costs:
- C_q = λ * q̄ / P (variable cost per unit trade)
- C_n = λ * N̄ / P (variable cost scaled by average shares)

**Data:** NYSE stocks 1984–1991; intraday TORQ transactions database; 1,380 stocks with sufficient data; portfolios formed as 5×5 sort (size quintile × λ quintile).

**Return test:** Fama-MacBeth regression of monthly excess returns on C_q, C_n, size, beta, B/M.

---

## Key Results

- Returns increase monotonically with λ within each size quintile
- C_q coefficient: ~0.08 (t ≈ 2.8) in Fama-MacBeth regression (after FF3 controls)
- C_n coefficient: significant and positive
- Fixed cost ψ also significantly priced but smaller effect than λ
- Variable cost premium survives size and B/M controls — distinct from Fama-French factors
- Economic magnitude: moving from lowest to highest λ quintile adds ~2% annual return (within same size bucket)

---

## Korea-Specific Implications

- Direct estimation of λ via GH model requires tick-level transaction data (unavailable in RAWDATA.parquet with daily OHLCVS)
- **Proxy approach**: Amihud ILLIQ approximates λ conceptually (both measure price impact per dollar traded)
- The finding that variable cost AND fixed cost are separately priced suggests using BOTH a volume-scaled measure (ILLIQ) and a zero-day measure (Liu LM12) as complementary signals
- Korean market: high retail participation → larger fixed costs (bid-ask bounce); institutional block trades → larger variable costs (price impact)
- KOSDAQ stocks likely have 3-5x higher C_q than KOSPI200 stocks

## Actionable Implementation

Cannot directly compute GH lambda from daily OHLCV data. Best proxies available in RAWDATA.parquet:

```r
# GH-lambda proxy using daily data (Roll's measure variant)
# Roll (1984): effective spread ≈ 2 * sqrt(-Cov(ΔP_t, ΔP_{t-1}))
# Requires consecutive daily price changes

compute_roll_spread <- function(ret_daily) {
  n <- length(ret_daily)
  if (n < 10) return(NA_real_)
  cov_ret <- cov(ret_daily[-1], ret_daily[-n])
  if (cov_ret >= 0) return(NA_real_)
  2 * sqrt(-cov_ret)
}

# Per stock, per month: use daily returns within month
roll_spread_monthly <- rawdata %>%
  group_by(ticker, ym) %>%
  summarise(
    roll_spread = compute_roll_spread(ret),
    .groups = "drop"
  )
```

**Strategic use:** Roll spread as a proxy for the GH fixed cost component ψ; Amihud ILLIQ as proxy for variable cost λ. Combine both in factor construction.
