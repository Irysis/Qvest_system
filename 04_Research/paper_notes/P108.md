# P108 — Li, Novy-Marx & Velikov (2019): Liquidity Risk and Asset Pricing

**Citation:** Li, H., Novy-Marx, R., & Velikov, M. (2019). Liquidity risk and asset pricing. *Critical Finance Review*, 8(1-2), 187–199. (Originally 2017 working paper)

---

## Core Thesis

Successful replication of Pastor-Stambaugh (2003) aggregate liquidity measure and the liquidity risk premium. The PS factor performs **even stronger out-of-sample** (post-1999) than in-sample (1968-1999) — an unusual finding given the typical post-publication decay of ~26% documented by Pontiff-McLean. However, the paper also shows the PS factor is **extremely sensitive to construction details**:
- Annual December rebalancing is crucial (monthly rebalancing yields insignificant results)
- Decile sorts (equal-number breakpoints) are crucial
- Excluding zero-volume days from gamma estimation is crucial (though this was inadvertently omitted from the original paper's documentation)

---

## Factor Construction

**Pastor-Stambaugh gamma estimation (PS 2003 original equation):**

    r^e_{i,d+1,t} = θ_{i,t} + φ_{i,t} * r_{i,d,t} + γ_{i,t} * sign(r^e_{i,d,t}) * v_{i,d,t} + ε_{i,d+1,t}

where:
- r^e_{i,d+1,t} = excess return over market for stock i on day d+1 in month t
- r_{i,d,t} = stock return on day d
- sign(r^e_{i,d,t}) = direction of excess return on day d
- v_{i,d,t} = dollar volume on day d
- γ_{i,t} = stock i's individual liquidity measure (expected to be negative)

**Aggregate liquidity index:** γ̄_t = (1/N_t) * Σ_i γ̂_{i,t}

**Liquidity innovation:** Δγ̄_t estimated via AR model (PS eq. 7):
    Δγ̄_t = a + b * Δγ̄_{t-1} + c * (m_{t-1}/m_t) * γ̄_{t-1} + μ_t

**Traded liquidity factor (PS factor):** Long/short portfolio of stocks sorted by predicted liquidity beta (β_L), estimated from 60-month rolling regression on liquidity innovations and FF3 factors.

**Replication success:** 0.99 correlation with PS's original aggregate measure (in-sample). 0.95 correlation for traded factor.

**In-sample vs. out-of-sample:**
| Period | Carhart 4-factor alpha | t-stat |
|---|---|---|
| 1968-1999 (in-sample) | 0.37%/month | 2.14 |
| 2000-2015 (out-of-sample) | 0.68%/month | 2.31 |

---

## Key Results

- PS factor is successfully replicated (correlation 0.99 with original)
- **Out-of-sample alpha is HIGHER than in-sample** — counter to typical post-publication decay
- Key construction details matter enormously:
  1. **Annual rebalancing in December**: monthly rebalancing → 0.10%/month (t=1.28); annual Dec → 0.37%/month (t=2.14)
  2. **Decile equal-number sorts**: market-cap weighted breakpoints yield weaker results
  3. **Zero-volume day exclusion**: must exclude days with v=0 when estimating gamma (regression is misspecified otherwise, as r_{i,d,t} on such days is bid-ask average, not a true return)
  4. **Price filter**: $5 < price < $1,000
- Liquidity risk factor appears unrelated to momentum when properly constructed
- Full-sample (1968-2015) alpha: 0.44-0.46%/month (t = 2.85-3.02) across 3-, 4-, 5-factor models

---

## Korea-Specific Implications

- PS gamma estimation feasible with Korean daily OHLCVS data IF we treat KRX's value-weighted index as the market return
- **Critical issue**: Korean stocks have many zero-volume days especially in KOSDAQ → the zero-volume day exclusion is crucial for Korean implementation
- Out-of-sample finding is encouraging: liquidity risk may be robust in Korea too, especially given multiple liquidity crises (1997, 2008, 2020)
- Annual rebalancing in December may be Korea-appropriate (fiscal year alignment, dividend record dates)
- Construction sensitivity finding means any Korean replication must test multiple variants before concluding the factor works/doesn't work

## Actionable Implementation

```r
# Pastor-Stambaugh gamma estimation for Korean stocks
# CRITICAL: exclude v_{i,d,t} = 0 days

compute_ps_gamma <- function(stock_daily_month) {
  # stock_daily_month: one stock's daily data for one month
  # Returns: gamma estimate

  df <- stock_daily_month %>%
    filter(volume_krw > 0) %>%  # CRITICAL: exclude zero-volume days
    arrange(date)

  n <- nrow(df)
  if (n < 15) return(NA_real_)  # PS requires D > 15

  # Variables
  r_excess_next <- lead(df$ret_excess)  # r^e_{d+1}
  r_excess_curr <- df$ret_excess        # r^e_{d} (used for sign)
  r_stock_curr  <- df$ret               # r_{d} (lagged control)
  vol_dollar    <- df$volume_krw / 1e8  # v_{d} in 100M KRW units

  # Remove last row (no next-day return)
  valid <- !is.na(r_excess_next)
  if (sum(valid) < 15) return(NA_real_)

  # OLS regression
  X <- cbind(1, r_stock_curr[valid], sign(r_excess_curr[valid]) * vol_dollar[valid])
  Y <- r_excess_next[valid]

  tryCatch({
    coef <- solve(t(X) %*% X) %*% t(X) %*% Y
    coef[3]  # gamma = third coefficient
  }, error = function(e) NA_real_)
}
```
