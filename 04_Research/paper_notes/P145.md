## Summary (Key Highlights — See P136.md for Full Detail)

**Core finding**: Cash Profitability (RMWcp) beats Operating Profitability (RMWop) on the maximum Sharpe ratio criterion.

**RMWcp definition:**
```
CP = OP - accruals component
   = (Operating Profit - ΔAT + ΔLT + ΔSE + ΔMI - ΔCash) / Book Equity
```

**Factor comparison (US 1963-2016):**
| Model | Max Sh²(f) |
|-------|-----------|
| FF5 (with RMWop) | 0.178 |
| FF5 (with RMWcp) | 0.190 |
| FF3 | 0.134 |

**Korean implementation key points:**
- Portfolio formation: February (not June) — Korean fiscal year December 31
- Use RMWcp over RMWop (13% Sharpe improvement)
- Momentum is redundant once RMWcp included
- Consolidated financials (연결재무제표) only
