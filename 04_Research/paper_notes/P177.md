# P177: On Persistence in Mutual Fund Performance (1997)

## Core Finding
Carhart (Journal of Finance, 1997) demonstrates that apparent persistence in mutual fund performance is almost entirely explained by common factor exposures — principally the one-year momentum factor of Jegadeesh and Titman (1993) — plus persistent expense differences, not by manager skill. Using a survivor-bias-free sample of 1,892 diversified US equity funds (1962-1993), the 4-factor model (Fama-French 3-factor + PR1YR momentum) reduces unexplained performance persistence dramatically. The key contribution is the introduction of the Carhart 4-factor model as a performance attribution benchmark.

## Key Metrics
- Alpha/Return: Top-decile funds earn ~0.67%/month (8% annualized), bottom-decile earn ~0.01%/month; but 4-factor alphas are near zero for top funds and -0.45%/month (t=-4.58) for bottom-decile funds
- Statistical strength: Momentum factor (PR1YR) monthly return 0.82% (t=4.46); explains ~31 basis points of the ~67 bps spread between top and bottom decile fund returns
- Sample: US diversified equity mutual funds, January 1962 - December 1993, 1,892 funds (survivor-bias free)

## Korea Applicability
MEDIUM — The 4-factor model (MKT + SMB + HML + MOM) is the global standard for performance attribution and is directly applicable to Korean fund evaluation. Korean active funds consistently underperform after fees, consistent with Carhart's findings. The key implication — that momentum loading drives apparent fund performance persistence — is highly relevant for understanding why Korean growth-style funds appear to persist during momentum regimes. The KOSPI200/KOSDAQ150 factor structure supports a Korean 4-factor model using KIS or QuantiWise data.

## Strategy Implication
- The Carhart 4-factor model defines the risk-adjusted performance benchmark: alpha = return - beta_MKT*MKT - beta_SMB*SMB - beta_HML*HML - beta_MOM*MOM
- For Moltbot strategy evaluation: use 4-factor alpha (not raw or 3-factor alpha) as the primary performance metric
- Momentum factor (PR1YR = top 30% minus bottom 30% eleven-month return, skipping last month) must be included in any Korean backtest attribution
- Warning: strategies that appear to generate alpha on 3-factor model may simply be loading on momentum — always check the PR1YR loading
- Expense/turnover drag: each 1% increase in annual expenses reduces performance by ~1% (one-for-one); each 1% of portfolio turnover costs ~0.95 bps in market impact
