# Paper Note: P136 — Fama & French "Choosing Factors" (2018)

**Authors:** Eugene F. Fama, Kenneth R. French
**Journal:** Journal of Financial Economics, Vol. 128, No. 1 (April 2018)
**Category:** Factor_Return / Quality_Profitability_Factors
**Priority:** 1

---

## Core Thesis

Framework for ranking multi-factor models using maximum squared Sharpe ratio. Nested model comparison via GRS tests. Key finding: **Cash Profitability (RMWcp) > Operating Profitability (RMWop)**. Momentum adds marginal value only for small-cap short-end anomalies.

---

## Main Factors

| Factor | Definition | Korean Implementation |
|--------|------------|----------------------|
| **RMWop** | (Rev - COGS - R&D) / Book Assets | DART: 매출액, 매출원가, R&D, 자산총계 |
| **RMWcp** | (OpProfit - Interest - Taxes) / Book Assets | DART: 영업이익, 이자비용, 법인세, 자산총계 |
| **CMA** | Low ΔAssets growth vs High | DART: 자산총계 year-over-year growth |
| **HML** | High Book/Mkt vs Low | DART: 자본총계 / Market Cap |
| **UMD** | Momentum | OHLCVS only — but nearly redundant after RMWcp |

## Key Results (US 1957-2016)

| Factor | Avg Return | t-stat |
|--------|------------|--------|
| HML | 0.35%/mo | 3.88 |
| RMWop | 0.31%/mo | 4.09 |
| RMWcp | 0.24%/mo | 2.75 |
| CMA | 0.27%/mo | 2.21 |

**6-Factor model Sh² = 0.190** vs 3-factor = 0.134 (36% improvement)

## Korean Implementation

**All require DART fundamentals** (NOT OHLCVS-only)

**Critical Korean-specific issues:**
1. **Portfolio formation date**: Use Feb (not June) — Korean fiscal year Dec 31, reporting lag Feb 28
2. **R&D capitalization**: F&F capitalize R&D as 5-year SL; DART reports as period expense. Add back amortized R&D to get true operating profit.
3. **Consolidated financials ONLY**: Use 연결, not 별도 — chaebol cross-holdings distort standalone
4. **Size breakpoints**: Use 30th/70th percentile of KOSPI200+KOSDAQ150 cap (not NYSE median)
5. **Momentum (UMD) is redundant** once RMWcp is included — don't double-count
6. **Mega-cap concentration**: Samsung etc dominate; compute factors within KOSPI200 and KOSDAQ150 separately

**Regime conditioning**: RMWcp has 2-3x higher premium in downturns (fundamentals re-price in recovery). Weight RMWcp × 1.5 during bear regime.
