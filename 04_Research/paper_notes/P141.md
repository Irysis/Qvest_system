## Core Thesis

Profitability anomalies arise because **analysts systematically underreact to earnings signals** — "sticky" forecasts fail to incorporate persistent profitability information. The mechanism:

1. High-quality firms have **persistently high earnings** (GP/A, ROE, CFOA are persistent)
2. Analysts update forecasts too slowly (sticky expectations, λ_f < 1)
3. Market prices follow analyst forecasts → prices also underreact
4. Result: Profitability factor generates alpha because markets systematically misprice persistent earnings

**Key finding:** The CFOA (cash flow from operations / assets) anomaly is largest among analysts with the stickiest forecasts (λ_f near 0). Stickiest analyst quintile earns **102 bps/month** 5-factor alpha vs. **51 bps/month** for least-sticky quintile.

---

## Model: Sticky Expectations

### AR(1) Earnings Process:
```
Earnings_t = φ · Earnings_{t-1} + ε_t
```
where φ = true persistence parameter.

### Analyst Forecast Update Rule (sticky):
```
F_t = (1 - λ_f) · F_{t-1} + λ_f · Earnings_t
```

where λ_f ∈ [0,1] is the **updating speed** (stickiness = 1 - λ_f).

### Implied Return Predictability:
When earnings are persistent (φ > 0) and analysts are sticky (λ_f < 1):
```
Expected excess return_t+1 ∝ (φ · λ_f / (1 - φ(1-λ_f))) × Earnings_deviation_t
```

Higher persistence (φ) × higher stickiness (1-λ_f) → stronger profitability anomaly.

### Stickiness Measure:
```
λ̂_f = estimated via: F_{t+1} - F_t = λ_f × (Earnings_t - F_t) + η_t
```
Estimate firm-analyst level λ_f via rolling OLS on consensus forecast revisions.

## Main Results

### CFOA Anomaly by Analyst Stickiness Quintile (Table 5):
| Stickiness Quintile | 5-factor alpha (%/mo) | t-stat |
|--------------------|----------------------|--------|
| Q1 (Least sticky) | 0.51 | 2.83 |
| Q2 | 0.64 | 3.31 |
| Q3 | 0.78 | 3.97 |
| Q4 | 0.89 | 4.44 |
| Q5 (Most sticky) | **1.02** | **5.12** |
| Q5 - Q1 | 0.51 | 3.84 |

5-factor model includes MKT, SMB, HML, UMD, QMJ (quality) — so these alphas are net of all standard factors.

### Key Profitability Measures Tested:
- **CFOA** (cash flow from ops / assets): Primary signal in this paper — most robust
- **GPOA** (gross profit / assets): Also tested, similar stickiness pattern
- **ROE, ROA**: Consistent results

### Persistence Estimates (φ) by Signal:
| Signal | Average φ |
|--------|-----------|
| CFOA | 0.78 |
| GPOA | 0.81 |
| ROE | 0.63 |
| Net income / assets | 0.58 |

CFOA and GPOA are most persistent — explains why they generate largest profitability alphas.

### Forecast Error Pattern:
- Analyst earnings forecast errors are **positively autocorrelated** — consistent with sticky expectations (not rational updating)
- Serial correlation of forecast errors: ρ₁ ≈ +0.35 (should be ≈ 0 under full rationality)
- Direct evidence of systematic underreaction, not overreaction

## Implications for Factor Construction

### Optimal Profitability Signal Weighting:
Under the sticky expectations model, optimal signal weight ∝ φ × (1/λ_f):
- Weight CFOA and GPOA most heavily (highest persistence AND stickiness)
- Weight ROE less (lower persistence, faster analyst updating)
- This provides a **theory-grounded weighting scheme** for QMJ composite

### When is the Anomaly Largest?
1. **Small caps**: Fewer analysts → each analyst's stickiness has larger impact on consensus
2. **Complex earnings**: More volatile companies → analysts anchor more to historical estimates
3. **Post-announcement drift**: Anomaly concentrated around quarterly earnings releases
4. **Low institutional ownership**: Retail-dominated stocks → less sophisticated price discovery

### Limits to Arbitrage Channel:
Sticky expectations mechanism implies anomaly should be:
- Larger where arbitrage is costly (small/illiquid stocks)
- Persistent because behavioral bias (stickiness) is stable trait
- Reduced by increased analyst coverage and attention

## Korean Market Implementation

**CFOA computation from DART:**
```
CFOA = 영업활동현금흐름 / 자산총계
```
(from 현금흐름표, 영업활동 section)

**Analyst stickiness estimation for Korea:**
- Consensus forecast data: FnGuide 또는 WiseFn에서 EPS 컨센서스 데이터 필요
- Alternative if no analyst data: estimate persistence φ directly from realized CFOA series
- For KOSDAQ firms with limited coverage: use sector-average stickiness as proxy

**Korean-specific considerations:**
1. **Analyst coverage gap**: KOSDAQ150 stocks have 3-5 analysts on average vs. 15+ for KOSPI200. Stickiness effect may be stronger for KOSDAQ (fewer analysts = stickier consensus).
2. **Earnings guidance**: Korean companies rarely provide guidance (unlike US), potentially increasing stickiness
3. **Quarterly reporting**: Korean companies publish 분기보고서 — same quarterly cadence as US, enabling CFOA monthly signal update
4. **Chaebol earnings complexity**: Samsung Electronics has complex subsidiary earnings — stickiness effect may be amplified for holding-company-heavy portfolios

**Implementation without analyst data (simplified):**
```r
# Estimate earnings persistence φ directly
cfoa_persistence <- dart_fund %>%
  group_by(ticker) %>%
  arrange(fiscal_year) %>%
  mutate(
    cfoa = cfo / total_assets,
    cfoa_lag = lag(cfoa),
    cfoa_deviation = cfoa - mean(cfoa, na.rm=TRUE)
  ) %>%
  summarise(phi = coef(lm(cfoa ~ cfoa_lag))["cfoa_lag"])

# Weight profitability signals by persistence
quality_weighted <- quality_dt %>%
  left_join(cfoa_persistence, by="ticker") %>%
  mutate(
    # Higher phi → upweight CFOA in composite
    cfoa_weight = phi * 2,  # persistence-weighted
    quality_adj = (cfoa_weight * z_cfoa + z_gpoa + z_roe + z_roa) /
                  (cfoa_weight + 3)
  )
```

**Regime conditioning:**
- Sticky expectations anomaly is strongest AFTER earnings announcements (post-announcement drift)
- Consider **event-driven weighting**: upweight profitability factor in months following major earnings releases (Feb-Apr for Korean 사업보고서, May for Q1, Aug for Q2, Nov for Q3)
- STR_013 enhancement: Time factor weight to peak around April (post-사업보고서) rebalancing

## Connection to QMJ (P135)

- Bouchaud et al. provide the **behavioral mechanism** that explains QMJ's alpha
- QMJ's Safety component (low beta, low distress) is NOT explained by sticky expectations — requires separate risk explanation
- CFOA (in QMJ Profitability composite as CFO/Assets) benefits most from sticky expectations
- Practical: within QMJ construction, weight CFOA by 1.5× relative to ROE (lower persistence)
