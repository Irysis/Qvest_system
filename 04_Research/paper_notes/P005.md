# P005: Appendix E — A Quantitative Analysis of the Game of Craps (2022)

## Core Finding
Using craps as a pedagogical device, this appendix demonstrates the core concepts of probability theory relevant to quantitative investing: conditional probability, expected value, house edge, and the danger of ignoring negative expected value bets. The PASS bet has win probability 0.4929 (house edge $1.41 per $100), while the free-odds bet has zero house edge — the only fair bet in the casino.

## Key Metrics
- Alpha/Return: P(win|PASS bet) = 0.492929; house edge = $1.41 per $100 bet
- Statistical strength: Exact computation via conditional probability
- Sample: Theoretical probability calculations for standard craps game

## Strategy Implication
The core lesson for strategy development: (1) always compute the expected value (alpha net of costs) before trading; (2) the "free odds" concept maps to adding uncorrelated alpha sources to a portfolio — the hurdle_gate.R implementation should reject strategies with negative expected net alpha; (3) Kelly criterion (position sizing proportional to edge/odds) is the theoretically optimal bet size, applicable to portfolio concentration decisions.
