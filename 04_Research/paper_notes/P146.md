## 1. Core Thesis

배당할인모형(DDM)을 이론적으로 정교화하여, 영구적 일정 성장률 가정 하의 주식 내재가치(intrinsic value) 결정 공식을 도출한다. 기업의 투자 결정, 자본 조달 방식, 주주 수익률(배당+시세차익) 간의 관계를 수학적으로 정리하여 이른바 "고든 성장 모델(Gordon Growth Model)"의 이론적 기반을 확립한다.

---

## 2. The Gordon Growth Model

### 핵심 공식
```
V_0 = D_1 / (r − g)

여기서:
V_0 : 현재 주식 내재가치 (intrinsic value per share)
D_1 : 다음 기 기대 배당 (= D_0 × (1 + g))
r   : 주주 요구수익률 (discount rate, cost of equity)
g   : 배당의 영구 성장률 (g < r 조건 필수)
```

### 유도 과정
배당의 영구 성장 가정:
```
V_0 = D_1/(1+r) + D_2/(1+r)² + D_3/(1+r)³ + ...
    = D_1/(1+r) + D_1(1+g)/(1+r)² + D_1(1+g)²/(1+r)³ + ...
    = D_1 × Σ[(1+g)/(1+r)]^(t-1)  for t=1 to ∞
```

등비급수 수렴 조건: (1+g)/(1+r) < 1, 즉 g < r
```
V_0 = D_1 / (r − g)
```

---

## 3. Growth Rate Decomposition

### g의 결정요인
```
g = b × ROE

여기서:
b   : 이익 유보율 (retention ratio = 1 − payout ratio)
ROE : 자기자본이익률 (return on equity)
```

### 직관
- 기업이 이익의 b 비율을 재투자
- 재투자된 자본이 ROE를 달성
- → 배당 성장률 = 유보율 × ROE

### 배당과 성장의 트레이드오프
```
D_1 = EPS_1 × (1 − b)
g   = b × ROE

V_0 = EPS_1 × (1−b) / (r − b×ROE)
```

- 배당 많이 주면(b 낮음) → D_1 높음, g 낮음
- 재투자 많이 하면(b 높음) → D_1 낮음, g 높음
- **최적 자본 배분**: ROE > r이면 재투자 확대가 가치 증대

---

## 4. Key Insight: Growth Value Creation Condition

```
가치 증대 (V_0 증가) ↔ ROE > r

ROE > r: 재투자 확대 시 주가 상승
ROE = r: 재투자 비율 무관 (Miller-Modigliani 무관련 성립)
ROE < r: 재투자 시 주가 하락 (성장이 오히려 가치 파괴)
```

### 현대 투자 원칙으로의 연결
- P181(DCF Terminal Value): McKinsey Value Driver Formula = ROE > r 조건 명시적 반영
- P183(Quality Investing): CFROIC > WACC = 퀄리티 기업의 정의와 동일

## 5. Extension: Non-Constant Growth (Two-Stage Model)

Gordon(1962)은 단일 성장률 모델의 한계를 인식하고 다단계 성장 가능성을 논의:

```
V_0 = [Σ D_t / (1+r)^t for t=1 to T] + [D_{T+1}/(r−g_stable)] / (1+r)^T

여기서:
초기 T년: 높은 성장률 g_high
T년 이후: 안정 성장률 g_stable (≈ GDP 성장률)
```

## 6. Relation to Other Valuation Models

### P/E 비율 도출
```
P = D_1 / (r − g) = EPS × (1−b) / (r − b×ROE)
P/E = (1−b) / (r − g)
```

- P/E는 배당 성향(1-b), 요구수익률(r), 성장률(g)의 함수
- 성장률 높으면 P/E 높음 (성장주 프리미엄 이론적 설명)

### P/B 비율 도출
```
P = B × ROE × (1−b) / (r − g)
P/B = ROE × (1−b) / (r − g) = ROE / r  [g=0 극단적 경우]
```

- ROE > r → P/B > 1 (이론적 근거)
- 가치주(P/B 낮음) = ROE < r 또는 성장 기대 낮음

## 7. Assumptions and Limitations

### 모델 가정
1. 배당이 영구적 일정 비율로 성장
2. 성장률 g가 할인율 r보다 낮음 (g < r)
3. 자본 비용(r) 불변
4. 기업 위험 불변

### 주요 한계
- **단일 성장률 가정**: 현실적이지 않음 (고성장 기업)
- **g < r 조건**: 고성장 신흥기업에 적용 불가
- **배당 미지급 기업**: D_1 = 0이면 V_0 = 0 (오류)
  - 해결: FCFE(주주잉여현금흐름) 대체 또는 총주주환원(배당+자사주) 사용
- **일정 자본비용**: 레버리지, 리스크 변화 미반영

## 8. Application to Factor Investing

### 가치 팩터(P/B)와의 연결
- P/B = ROE × (1−b) / (r − g)
- **낮은 P/B 기업**: 시장이 낮은 ROE 또는 낮은 성장 기대 → 가치 함정 주의
- **Fama-French HML(P178)**: P/B 역수(BE/ME) 기반 → Gordon 모델에서 이론적 근거

### 배당 수익률과 기대 수익률
```
r = D_1/V_0 + g = 배당 수익률 + 성장률
```
- P147(배당 서프라이즈 = 이익 성장)과 직접 연결
- 배당 증가 → 기업 자신감 신호 → g 상향 조정

## 9. Strategy Ideas Derived

### Idea 1: ROE-Adjusted Value (QARP Basis)
P/B가 낮으면서 ROE > r인 기업 선별 → 진정한 저평가 (가치 함정 회피)
- `fundamental_dart.parquet`의 ROE × (1−b) / (r−g) 계산 가능

### Idea 2: Implied Growth Rate Extraction
현재 P와 EPS로부터 시장이 내재한 g 역산:
```
g_implied = r − EPS × (1−b) / P
```
g_implied가 비현실적으로 낮으면 → 저평가 신호

### Idea 3: Dividend Payout Optimization Signal
b(유보율) 변화를 통한 자본배분 효율성 측정 → ROE vs r 비교를 통한 투자 퀄리티 측정
