# P062: Beta and Firm Age (Chincarini, D. Kim, Moneta 2020)
**Category:** Factor_Return / Beta
**Feasibility:** high
**Novelty vs existing (BAB failed, LowVol passing):** high

## Core Claim
기업 나이(firm age = 상장 이후 경과 연수)가 증가할수록 시장 베타가 단조 감소한다. 신규 상장 기업(young firms)의 베타는 ~1.7, 100년 이상 기업은 ~1.0에 수렴. 나이를 통제한 후에는 CAPM 베타-수익 관계가 양(+)이며 통계적으로 유의해진다. 즉, beta anomaly(저베타 프리미엄)의 상당 부분이 기업 나이 효과로 설명된다.

## Factor Definition
**기업 나이 (Firm Age)**:
```
Age_i,t = 측정 시점 t - 기업 상장일 (또는 최초 CRSP 등재일)
단위: 연(year)
```

**나이-베타 관계 (패널 회귀)**:
```
beta_i,t = gamma_0 + gamma_1 * log(Age_i,t) + gamma_2 * Controls + epsilon_i,t
gamma_1 추정치: -0.007/year (t = -6.16) → 매년 0.007씩 베타 감소
```

**나이-조정 베타 (Age-Adjusted Beta)**:
```
AdjBeta_i,t = raw_beta_i,t - E[beta | Age_i,t]
           = raw_beta_i,t - (gamma_0 + gamma_1 * log(Age_i,t))
```
나이 효과를 제거한 잔차 베타 → 진정한 체계적 위험 측정

**이론적 기제 — Familiarity Premium**:
- 신규 기업: 추정 리스크(estimation risk) 높음 → 투자자 요구수익 높음 → 고베타
- 시간이 지나면서 정보 축적 → 추정 불확실성 감소 → 베타 감소
- Klein & Bawa (1976) "unfamiliarity premium" 실증 확인

## Key Results
- 미국 CRSP 1926-2010, 약 11,000개 종목, 월별 데이터
- 나이 1분위(신생) vs 10분위(노령) 베타 차이: 약 0.7 (1.7 vs 1.0)
- 나이 통제 후 베타-수익 관계: gamma_beta = +0.15% per month (t=2.1, 유의)
  - 통제 전: gamma_beta = -0.08% (비유의, 기존 beta anomaly)
- **나이 자체가 팩터**: 젊은 기업 포트폴리오 vs 노령 기업 포트폴리오 수익 차이 유의
- 나이 효과는 소형주에서 더 강함 (정보 비대칭 심한 기업군)
- 나이는 beta anomaly 단독 설명 변수 중 가장 강력
- 통제 변수: B/M, Size, Momentum, Liquidity, Idiosyncratic Vol

## Korea Applicability
**적용 가능성: 높음**
- KRX 상장일 데이터 공개: 모든 KOSPI/KOSDAQ 종목의 상장일 수집 가능
- 한국 시장 특성상 KOSDAQ 신규 상장 테마주 풍부 → 고베타 신생주 다수
- Universe 필터: 신규 상장 후 36개월 미만 종목 제외 → estimation risk 낮추기
- 나이-베타 관계 한국 확인 연구 없음 → 독자 발굴 여지 있음
- `universe.parquet`에 상장일 컬럼 추가 후 즉시 구현 가능
- 리밸런싱 주기: 월별, 나이 기준 분류는 연 1회 update로 충분

## Actionable Ideas
- **NEW IDEA A — 상장 나이 필터**: Universe 구성 시 상장 후 36개월(또는 60개월) 미만 종목 제외. Rationale: 신규 상장주는 추정 리스크로 인해 구조적 고베타 → LowVol 선별 오염 방지. 구현 간단, 즉시 적용 가능.
- **NEW IDEA B — Age-Adjusted Beta**: rolling 24개월 OLS 베타에서 나이 효과 제거 → 잔차(나이-조정) 베타로 LowVol 팩터 구성. 나이가 아닌 진정한 체계적 위험으로만 선별. 구현: `AdjBeta_i = raw_beta_i - fitted_from_age_regression`.
- **NEW IDEA C — Young Firm Exclusion + Old Firm Low-Beta Tilt**: 상장 5년 미만 종목 제외 + 상장 10년 이상 저베타 종목 집중 → 나이와 베타의 이중 필터로 LowVol 개선.
- **우선순위**: Idea A(상장 나이 필터)가 구현 즉시 가능하고 가장 실용적. Idea B는 DART 회계데이터와 결합 시 강력.
