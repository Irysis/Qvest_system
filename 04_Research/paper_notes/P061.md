# P061: Time Horizon and the Beta Anomaly (Fong 2016)
**Category:** Factor_Return / Beta
**Feasibility:** low
**Novelty vs existing (BAB failed, LowVol passing):** low

## Core Claim
저베타 이상현상(beta anomaly)은 투자 수평선(time horizon)이 길어질수록 **강화**된다. 단기(1개월)보다 장기(20년)에서 저베타 포트폴리오와 고베타 포트폴리오의 Sharpe 비율 격차가 더 커진다. 고베타 주식의 과대평가는 복권형 수요(lottery preference)와 우편도(idiosyncratic skewness)로 설명된다.

## Factor Definition
Frazzini-Pedersen 방식의 베타 추정:
```
beta_i = rho_im * (sigma_i / sigma_m)
  - sigma_i: 252일 일별 수익률 표준편차
  - sigma_m: 252일 시장 수익률 표준편차
  - rho_im: 1260일(5년) 3-day overlapping return 기반 상관계수
```
베타 shrinkage: `beta_shrunk = 0.6 * beta_ts + 0.4 * 1.0`

포트폴리오: 5분위 (B1=저베타 ~ B5=고베타), 월별 리밸런싱, 동일가중

수평선 분석: Block bootstrap (60개월 블록, 10,000회 시뮬레이션)으로 1~20년 수평선별 성과 추정

## Key Results
- B1(저베타): 월평균 수익 1.07%, 변동성 4.54%, 장기 Sharpe 0.51→1.20 (1yr→20yr)
- B5(고베타): 월평균 수익 1.06%, 변동성 9.39%, 장기 Sharpe 0.27→0.50
- 고베타 주식: idiosyncratic skewness 유의하게 더 높음 (복권 선호 투자자 수요로 과대평가)
- UPR (Upside Potential Ratio), Omega ratio, Prospect Theory 기준 모두 저베타 우위
- 표본: NYSE/AMEX/NASDAQ 1926-2013, 월별 데이터

## Korea Applicability
**적용 가능성: 낮음**
- LowVol (STR_003/STR_011)이 이미 저베타 이상현상을 포착 중 (MDD 42% 통과)
- 수평선 분석 자체는 구현 가능하나 추가 alpha 생성 경로 불명확
- KOSDAQ 비동기 거래 문제: Dimson 보정 베타 필요 (P061은 US 데이터 기반)
- 복권형 수요(lottery stocks) 한국 시장에서도 존재 (KOSDAQ 테마주) → 별도 팩터로 활용 가능하나 베타와 직접 연결은 약함

## Actionable Ideas
- **SKIP**: 저베타 이상현상은 이미 LowVol 전략으로 구현 완료 (STR_003/STR_011 통과). 수평선 분석은 새로운 팩터가 아니라 기존 팩터의 유효성 확인에 불과. Idiosyncratic skewness를 별도 팩터로 사용하는 아이디어는 복권주 제외 필터로 STR_003에 통합 가능하나 독립 전략 불필요.
- **부수적 활용**: 저베타 종목 선별 시 고 idiosyncratic skewness 종목 제외(복권주 필터) → STR_003 수익성 개선 가능. 별도 전략보다는 LowVol 필터 강화로 편입.

## Notes
- Frazzini-Pedersen 베타 계산식 (5년 correlation × 1년 vol)은 P063 BAB와 동일한 방법론
- Block bootstrap 방법론은 beta_anomaly의 robustness 검증에 유용하나 전략 자체에 새로움 없음
- P061 핵심 기여: 베타 이상현상이 단순 noise가 아니라 장기적으로도 지속되는 구조적 현상임을 확인
- 한국 전략 관련: 이미 충분히 탐색된 영역 (STR_001~003)
