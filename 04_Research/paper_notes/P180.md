## 1. Core Thesis

팩터 모델(Factor Model for Asset Returns)의 이론적 구조를 세 가지 유형(거시경제 팩터, 펀더멘털 팩터, 통계적 팩터)으로 분류하고, 각각의 추정 방식(시계열 회귀 vs 횡단면 회귀)과 공분산 행렬 분해 구조를 해설한다. BARRA 스타일의 횡단면 팩터 모델과 Fama-French 스타일의 시계열 팩터 모델의 수학적 동치성과 차이점을 명확히 한다.

## 2. Three Types of Factor Models

### 2.1 거시경제 팩터 모델 (Macroeconomic Factor Models)

**구조**: 팩터가 관측 가능한 거시경제 변수
```
R_it = α_i + β_i1·f_1t + β_i2·f_2t + ... + β_iK·f_Kt + ε_it
```

**대표 사례**: Chen, Roll & Ross (1986)
- 산업생산 성장률
- 기대 인플레이션 변화
- 기대치 못한 인플레이션
- 장단기 금리 스프레드
- 신용 스프레드 (Baa-Aaa)
- 석유가격 변화

**추정 방식**: 관측 팩터(f_t)를 독립변수로 시계열 OLS → β_i 추정

### 2.2 펀더멘털 팩터 모델 (Fundamental Factor Models)

**구조**: 팩터 노출도(β)가 관측 가능하고, 팩터 수익률(f_t)을 추정
```
R_it = β_i1·f_1t + β_i2·f_2t + ... + β_iK·f_Kt + ε_it
```

**BARRA 스타일**: 매 시점 t에서 횡단면 회귀 (N개 종목에 대해)
- β_ik: 시점 t에서 종목 i의 팩터 k 노출도 (관측 가능: BE/ME, ROE 등)
- f_kt: 추정되는 팩터 수익률 (횡단면 회귀 계수)

**FF 스타일**: 명시적 팩터 포트폴리오(SMB, HML)를 먼저 구성 후 시계열 회귀

**BARRA vs FF 비교**:

| 구분 | BARRA (횡단면) | Fama-French (시계열) |
|---|---|---|
| 팩터 | 추정됨 | 관측됨 (포트폴리오 수익률) |
| 노출도 | 관측됨 | 추정됨 |
| 추정 방향 | 매 시점 횡단면 회귀 | 각 종목 시계열 회귀 |
| 강점 | 많은 종목에 강건 | 직관적 팩터 해석 |

### 2.3 통계적 팩터 모델 (Statistical Factor Models)

**구조**: 팩터도 노출도도 추정 (PCA, Factor Analysis)
- PCA → 수익률 행렬의 고유벡터 추출
- 첫 번째 PC = 시장 팩터에 근접
- 경제적 해석이 어려움
- 주로 리스크 모델 목적

## 3. General Factor Model Framework

### 기본 수식
```
R_it = α_i + β'_i · f_t + ε_it

여기서:
R_it : 종목 i의 t기 수익률
α_i  : 종목 i의 절편 (가격결정 오류 없으면 0)
β_i  : K×1 팩터 노출도 벡터
f_t  : K×1 팩터 수익률 벡터
ε_it : 잔차 수익률 (idiosyncratic return)
```

### 행렬 표현
```
R = α + BF + E

여기서:
R : N×T 수익률 행렬
B : N×K 팩터 노출도 행렬 (베타 행렬)
F : K×T 팩터 수익률 행렬
E : N×T 잔차 행렬
```

## 4. Covariance Matrix Decomposition

### 핵심 공분산 분해 공식
```
Ω_FM = B · Ω_f · B' + D

여기서:
Ω_FM : N×N 수익률 공분산 행렬 (팩터 모델 추정)
B    : N×K 팩터 노출도 행렬
Ω_f  : K×K 팩터 수익률 공분산 행렬
D    : N×N 대각 행렬 (잔차 분산, idiosyncratic risk)
```

### 의미
- **팩터 공통 리스크**: B·Ω_f·B' → K개 팩터로 설명되는 공분산
- **개별 리스크**: D → 각 종목 고유의 잔차 분산 (서로 독립 가정)
- **차원 축소**: N×N → K×K (K << N) → 파라미터 수 대폭 감소

### 포트폴리오 응용
```
포트폴리오 분산:
σ²_p = w' · Ω_FM · w
     = w'B · Ω_f · B'w + w'Dw
     = β'_p · Ω_f · β_p + σ²_p,idio

여기서 β_p = B'w (포트폴리오 팩터 노출도)
```

## 5. OLS Estimation Proofs

### 시계열 OLS (거시경제/FF 방식)
```
β̂_i = (F'F)^(-1) · F' · R_i

F : T×K 팩터 수익률 관측치 행렬
R_i : T×1 종목 i 수익률 벡터
```

### 횡단면 OLS (BARRA 방식, 매 시점 t)
```
f̂_t = (B'B)^(-1) · B' · R_t

B : N×K 팩터 노출도 관측치 행렬
R_t : N×1 시점 t의 종목 수익률 벡터
```

### WLS 확장 (가중최소제곱법)
```
f̂_t = (B'WB)^(-1) · B'W · R_t

W : 가중치 행렬 (시가총액 가중 또는 잔차 분산 역수 가중)
```

## 6. Time-Varying Beta Methods

### 6.1 Rolling Window Regression
- 과거 60개월(또는 36개월) 롤링 윈도우
- 간단하나 구조 변화에 느린 반응

### 6.2 Kalman Filter
```
State equation:    β_t = β_{t-1} + η_t,  η_t ~ N(0, Q)
Observation eq.:   R_t = f'_t · β_t + ε_t, ε_t ~ N(0, σ²)

예측: β̂_t|t-1 = β̂_{t-1}
업데이트: β̂_t = β̂_t|t-1 + K_t(R_t - f'_t · β̂_t|t-1)
칼만 게인: K_t = P_t|t-1 · f_t / (f'_t · P_t|t-1 · f_t + σ²)
```
- 시간에 따른 베타 변화를 실시간으로 반영
- 상태공간 모델: 베타가 랜덤워크를 따른다고 가정

### 6.3 GARCH 기반 조건부 공분산
- DCC-GARCH: 동적 조건부 상관 → 시변 팩터 공분산 Ω_f,t 추정

## 7. Factor Model Types: Pros and Cons

| 구분 | 장점 | 단점 |
|---|---|---|
| 거시경제 | 경제 직관, 해석 용이 | 팩터 수 제한, 설명력 낮음 |
| 펀더멘털 | 많은 팩터 수용, 높은 설명력 | 팩터 해석 어려움, 파라미터 많음 |
| 통계적 | 데이터 주도, 가정 최소 | 경제적 의미 없음, 불안정 |

## 8. Risk Management Applications

### 팩터 리스크 분해
```
총 위험 = 팩터 위험 + 개별 위험
        = β'·Ω_f·β + σ²_idio
```

### 팩터 중립화 (Factor Neutralization)
- 특정 팩터 β = 0이 되도록 포트폴리오 조정
- 예: 시장 중립 (β_market = 0), 규모 중립 (β_SMB = 0)

### 기여도 분석
- 각 팩터의 포트폴리오 위험 기여도:
```
Risk Contribution_k = β_pk · [Ω_f · β_p]_k
```

## 10. Strategy Ideas Derived

### Idea 1: Covariance Matrix Estimation via Factor Model
전체 공분산 행렬(800×800 파라미터) 대신 팩터 공분산(K×K, K=10~20) 추정 → 포트폴리오 최적화 안정성 향상

### Idea 2: Kalman Filter Beta
Maxwell Protocol에 Kalman Filter 시변 베타 도입 → 레짐 변화 시 팩터 노출도 자동 업데이트

### Idea 3: Residual Decomposition (Already in Use)
R_it = α_i + β'_i·f_t + ε_it 의 잔차 ε_it를 팩터 계산 기반으로 활용 → 기존 프로젝트의 "Residual-First" 원칙과 직접 연결

## 11. Mathematical Derivations Summary

### 팩터 모델 → APT 연결
- APT(Ross 1976): 차익거래 없으면 α_i ≈ 0
- CAPM: K=1, f_1t = R_Mt (시장 팩터)
- FF3: K=3, f = [RM-RF, SMB, HML]'

### 잔차의 성질
- E[ε_it] = 0
- Cov(ε_it, f_kt) = 0 (팩터와 무상관)
- Cov(ε_it, ε_jt) = 0 (종목간 무상관, 팩터 모델 가정)
