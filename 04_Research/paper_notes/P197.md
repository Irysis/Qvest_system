# Paper Note: P197 — Vigilant Asset Allocation: VAA (2017)

**Authors:** Wouter J. Keller, Jan Willem Keuning
**Source:** SSRN Working Paper (2017)
**Category:** Asset_Allocation
**Priority:** 1

## Core Thesis

VAA (Vigilant Asset Allocation) introduces the 13612W momentum filter — a weighted average of 1, 3, 6, 12-month returns with weights 12:4:2:1 (normalized to 19) — and a breadth-based "crash filter" (CF) that provides continuous, graded protection as market breadth deteriorates. The 40% weight on the last month means VAA reacts much faster than equal-weight 13612 or 13612 filters. "Vigilant" refers to this fast reaction capability.

## Strategy Description

**13612W Momentum Filter (KEY FORMULA):**
```
13612W = 12*(p0/p1 - 1) + 4*(p0/p3 - 1) + 2*(p0/p6 - 1) + 1*(p0/p12 - 1)
```
- Equivalent using price ratios:
```
13612W = 12*(p0/p1) + 4*(p0/p3) + 2*(p0/p6) + 1*(p0/p12) - 19
```
- Weights: 1-month gets 12/19 = 63% effective weight vs 1/4 = 25% in equal-weight
- This makes VAA ~3x more responsive to recent price changes than standard 13612

**Why 13612W vs. standard 13612:**
- 13612 (equal-weight): each horizon gets same weight
- 13612W: exponential taper, 1-month dominates
- In standard 13612, a single bad month is diluted by 3/4 weight from prior months
- In 13612W, a bad month has 40% weight → signal triggers faster

**Breadth Protection (Crash Filter CF):**
- b = number of assets with 13612W < 0 (bad assets)
- B = breadth threshold parameter
- CF = b/B if b < B; CF = 1 if b >= B
- When CF < 1: hold top T offensive assets at (1-CF) weight, cash at CF weight
- "Easy Trading" variant: CF = (1/T) * floor(b*T/B) — stepwise, reduces trading

**Cash Universe (always pick best 13612W):** SHY, IEF, LQD

**4 Universes Tested:**
- VAA-G12 (Gregarious 12): 12-asset offensive universe
  - Assets: SPY, QQQ, IWM, VGK, EWJ, EEM, VNQ, DJP, GLD, HYG, LQD, TLT
  - Best T/B: 2/4 (IS optimization)
  - RAD = 19.7% (in-sample optimal metric)
  - Full Sample: R=15.6%, V=10.2%, D=-13%, SR=0.85, MAR=1.20, RAD=13.3%
- VAA-G4 (Gregarious 4): 4-asset offensive universe
  - Assets: SPY, VEA, VWO, BND
  - Best T/B: 1/1
  - Full Sample: R~16%, D~-12%, SR~0.85
- VAA-U15 (Ulcer 15): 15-asset universe
- VAA-U6 (Ulcer 6): 6-asset universe

**RAD Metric:**
- RAD = R * (1 - D/(1-D)) if R>=0 and D<=50%, else 0
- Combines return and drawdown in single optimization metric
- Equivalent to penalizing drawdown heavily

**In-Sample Optimization (IS: 1970-2012, 43 years):**
- VAA-G12: T=2, B=4 achieves highest RAD
- VAA-G4: T=1, B=1 achieves highest RAD

**Full Sample (Dec 1970 - Aug 2017):**
- VAA-G12: R=15.6%, V=10.2%, D=-13%, SR=0.85, MAR=1.20

## Key Results

- 13612W's front-loading of recent returns is the key innovation over PAA's SMA12
- VAA reacts in 1 month to market deterioration vs. PAA's SMA12 lag
- Breadth threshold B=4 for G12 optimal: catches crises before they deepen
- VAA outperforms PAA and traditional 60/40 on both return and drawdown
- Cash asset selection (best of SHY/IEF/LQD by 13612W) adds 1-2% to safe periods
- Easy Trading variant reduces turnover by ~30% with minimal performance impact
- VAA-G4 is simpler and nearly as good as VAA-G12

## Implementation in Korean Market

**13612W for Korean ETF proxies:**
```r
# VAA-style momentum for Korean assets
vaa_mom <- function(prices) {
  p0 <- prices[nrow(prices)]
  p1 <- prices[nrow(prices)-1]
  p3 <- prices[nrow(prices)-3]
  p6 <- prices[nrow(prices)-6]
  p12 <- prices[nrow(prices)-12]
  return(12*(p0/p1) + 4*(p0/p3) + 2*(p0/p6) + 1*(p0/p12) - 19)
}
```

**MVAA vs. original VAA:**
- MVAA (P190) uses the same 13612W signal; VAA is the academic source
- MVAA modifies: B threshold applied as (number negative)/10 → continuous weight
