**Priority:** 1

## Core Thesis

Extends the Fama-French 3-factor model with **Profitability (RMW)** and **Investment (CMA)** factors, motivated by dividend discount model theory. The 5-factor model captures more cross-sectional variation than FF3 and makes HML redundant.

**Key implication**: HML's information content is subsumed by RMW + CMA — the model's theoretical foundation (DDM linking value, profitability, and investment) explains all three jointly.

---

## Model Specification

```
E[Ri] - Rf = bi(E[Rm-Rf]) + si·E[SMB] + hi·E[HML] + ri·E[RMW] + ci·E[CMA]
```

### Five Factors:

| Factor | Name | Construction | Korean Mapping |
|--------|------|-------------|----------------|
| **MKT** | Market excess return | CRSP value-weighted | IKS200 |
| **SMB** | Small minus Big | Size portfolios (2×3 sort) | KOSPI200 vs KOSDAQ150 |
| **HML** | High minus Low B/M | Value portfolios (2×3 sort) | DART 자본총계 / 시가총액 |
| **RMW** | Robust minus Weak profitability | Profitability portfolios (2×3 sort) | DART 영업이익 / 자본총계 |
| **CMA** | Conservative minus Aggressive investment | Investment portfolios (2×3 sort) | DART ΔAT/AT |

### Operating Profitability (OP) Definition:
```
OP = (REVT - COGS - XSGA - XINT) / BE
   = (Revenues - COGS - SGA - Interest) / Book Equity
```

**Korean DART mapping:**
```
OP = (매출액 - 매출원가 - 판매관리비 - 이자비용) / 자본총계
```

Note: This is "operating profitability" but subtracts interest (unlike standard operating income definition). It is effectively a return on equity that includes financing costs.

### Investment Factor (CMA):
```
CMA = Low investment (Conservative) - High investment (Aggressive)
    = Sort on ΔAT/AT_{t-1} (total asset growth)
```

## Main Results (US, 1963-2013)

### Factor Returns (Table 1):

| Factor | Avg Return (%/mo) | t-stat | Correlation with MKT |
|--------|------------------|--------|----------------------|
| MKT    | 0.50 | 2.66 | 1.00 |
| SMB    | 0.29 | 2.01 | -0.28 |
| HML    | 0.37 | 2.63 | -0.29 |
| **RMW** | **0.25** | **2.92** | **-0.35** |
| **CMA** | **0.33** | **4.07** | **-0.40** |

### GRS Test Results (Table 2):
- FF5 > FF3 > CAPM on GRS test (reject model H0 less often)
- FF5 reduces average |alpha| for 25 Size-B/M portfolios from 0.14% (FF3) to 0.08%
- FF5 reduces average |alpha| for 25 Size-OP portfolios from 0.20% (FF3) to 0.07%
- FF5 reduces average |alpha| for 25 Size-Investment portfolios from 0.27% (FF3) to 0.07%

### HML Redundancy Test (Table 4):
| Factor | Intercept in spanning regression | t-stat | R² |
|--------|----------------------------------|--------|-----|
| HML regressed on others | **0.03%/mo** | **0.63** | **0.93** |

**HML intercept = 0.03, t=0.63 → HML is NOT significant once RMW and CMA are included.** This is the key FF5 finding: HML's information is subsumed by profitability and investment.

## Theoretical Foundation (DDM Link)

From the dividend discount model:
```
M_t = Σ E[Y_{t+τ} - dB_{t+τ}] / (1+r)^τ
```

Where Y = earnings, B = book equity, dB = investment.

This implies (holding M constant):
1. **Higher expected profitability** → higher expected return (RMW)
2. **Lower expected investment** → higher expected return (CMA)
3. **Lower B/M** → higher expected future profitability and/or investment → **lower** expected return

Therefore B/M should be redundant given OP and investment — exactly what FF5 finds empirically.

## Portfolio Construction Details

### 2×3 Double Sort (Size × Profitability):
- **ME breakpoint**: NYSE median (small = below, big = above)
- **OP breakpoints**: NYSE 30th and 70th percentile (robust = top 30%, weak = bottom 30%)
- **RMW = 1/2(Small Robust + Big Robust) - 1/2(Small Weak + Big Weak)**

Same construction for CMA using investment (ΔAT/AT) breakpoints.

### Annual Rebalancing:
- Portfolios formed at end of June each year
- Accounting data from fiscal year ending December t-1
- Market cap from end of December t-1

## Key Issues and Limitations

### 1. The Momentum Problem:
FF5 does NOT include momentum. Results show:
- Aggressive-growth portfolios with low current returns are poorly priced by FF5
- Adding momentum (FF6) fixes this but momentum has its own problems (crashes, implementation costs)
- For Korean strategy: momentum requires separate treatment (see P136 FF2018)

### 2. Small Stock Underperformance:
- Small, weak-profitability, aggressive-investment stocks have **very low** predicted and actual returns
- "Bad" small stocks cluster at the dangerous corner of the factor space
- Eliminating microcaps largely resolves this

### 3. HML Redundancy vs. HML Persistence:
- HML is theoretically redundant but still used by many practitioners
- In international markets, HML often adds value even with RMW + CMA (less redundancy outside US)
- Korea: Test HML redundancy for Korean data before dropping it

## Korean Implementation

**Direct DART mapping for FF5 factors:**

```r
# Operating Profitability (OP) — Korean definition
ff5_factors <- dart_fund %>%
  mutate(
    # OP = (Revenue - COGS - SGA - Interest) / Book Equity
    op = (매출액 - 매출원가 - 판매관리비 - 이자비용) / 자본총계,

    # Investment (asset growth for CMA)
    ia = (자산총계 - lag(자산총계)) / lag(자산총계),

    # B/M for HML
    bm = 자본총계 / market_cap
  )

# 2×3 sorts using Korean breakpoints
# Use KOSPI200 breakpoints for large-cap universe
ff5_kospi <- ff5_factors %>%
  filter(index == "KOSPI200") %>%
  group_by(rebal_date) %>%
  mutate(
    me_median = median(market_cap),
    op_p30 = quantile(op, 0.30, na.rm=TRUE),
    op_p70 = quantile(op, 0.70, na.rm=TRUE),
    ia_p30 = quantile(ia, 0.30, na.rm=TRUE),
    ia_p70 = quantile(ia, 0.70, na.rm=TRUE),
    size_grp = ifelse(market_cap >= me_median, "Big", "Small"),
    op_grp   = case_when(op >= op_p70 ~ "Robust",
                         op <= op_p30 ~ "Weak",
                         TRUE ~ "Neutral"),
    ia_grp   = case_when(ia <= ia_p30 ~ "Conservative",
                         ia >= ia_p70 ~ "Aggressive",
                         TRUE ~ "Neutral")
  )
```

**Korean-specific adjustments:**

1. **OP definition**: Korean 판매관리비 includes both SGA and some R&D. For pure replication, separate out R&D (연구개발비 in footnotes).

2. **Book equity**: Use 지배기업 지분 자본총계 (controlling shareholders' equity), not total equity including minority interests — especially important for chaebol groups.

3. **Rebalancing date**: April 1 (Korean fiscal year December 31, 사업보고서 filing by March 31) — NOT June as in US.

4. **Breakpoints**: Use KOSPI200 breakpoints separately from KOSDAQ150 (different size distribution). Do NOT use NYSE median analogy.

5. **HML redundancy**: Test in Korean data before dropping. Korean value premium has been robust historically — HML may NOT be redundant in Korea.

**Expected performance for Korea:**
- Based on FF5 US results + Wahal pre-sample haircut + Cakici Asia Pacific calibration:
- RMW Korea estimate: 0.25% × (Asia Pacific premium / US premium) ≈ 0.25-0.40%/mo
- CMA Korea estimate: 0.33% × Wahal_haircut(~0.05) ≈ 0.02-0.05%/mo (weak, invest elsewhere)
- HML Korea: 0.37% (US) likely still significant given Korea's value culture

## Comparison: FF5 vs. q-Factor (P137)

| Feature | FF5 | q-factor |
|---------|-----|---------|
| Profitability measure | OP (annual, June) | ROE (quarterly, monthly) |
| Theoretical basis | DDM | Investment CAPM |
| # Anomalies explained | Better on investment | Better on momentum-related |
| Momentum included | No | No |
| Korea advantage | Simpler implementation | Higher-frequency ROE signal |
