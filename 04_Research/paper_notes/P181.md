## 1. Core Thesis

DCF 터미널 밸류(Gordon Growth Model과 McKinsey Value Driver Formula)를 이용하여 S&P 500 비금융주의 내재가치를 추정하고, 시장가 대비 내재가치가 높은 종목(저평가)이 이후 초과수익을 창출하는지 검증한다. Morningstar의 스타 등급과 비교하여 DCF 기반 전략의 실용성을 평가한다.

## 3. Terminal Value Models

### Model 1: Gordon Growth Model (고든 성장 모델)
```
TV_Gordon = FCFF_t × (1 + g) / (WACC − g)

여기서:
TV      : 터미널 밸류
FCFF_t  : 터미널 연도 잉여현금흐름(기업)
g       : 영구 성장률 (통상 GDP 성장률, 2~3%)
WACC    : 가중평균자본비용
```

**가정**: 영구적 일정 성장률 (constant perpetual growth)

### Model 2: McKinsey Value Driver Formula
```
TV_McKinsey = NOPLAT_t × (1 − g/ROIC) / (WACC − g)

여기서:
NOPLAT : 세후 순영업이익
ROIC   : 투자자본수익률
g      : 성장률
```

**장점**: ROIC와 성장률의 상호작용 반영 → g가 높아도 ROIC < WACC이면 가치 파괴 인식

| 전략 | 연환산 수익률 | 벤치마크 대비 |
|---|---|---|
| S&P 500 비금융 (벤치) | 12.5% | — |

| 기준 | Gordon Growth | Value Driver |
|---|---|---|

## 5. Gordon Growth Model: Connection to P146

본 논문은 P146(Gordon 1962)의 핵심 모델을 응용:
```
P_0 = D_1 / (r − g)     [Gordon 1962: 주가 수준]
TV   = FCFF / (r − g)   [본 논문: 터미널 밸류]
```
- 연간 배당 D → FCFF(잉여현금흐름)로 대체
- 주가 수준 산정 → 터미널 밸류 산정으로 응용
- r(주주요구수익률) → WACC로 대체

---

## 6. WACC Estimation

```
WACC = E/(E+D) × r_e + D/(E+D) × r_d × (1 − τ)

r_e = RF + β × ERP      [CAPM 기반]
r_d = 부채 이자율
τ   = 법인세율
ERP = Equity Risk Premium (P182 Damodaran 참조)
```

### WACC 추정의 어려움
- ERP 추정 불확실성 (Damodaran 방식 vs 역사적 프리미엄)
- 베타 추정 불안정성
- 부채 비용 추정 (신용등급 vs 실제 이자율)
- 터미널 밸류가 전체 가치의 60~80% → WACC 오차가 크게 증폭

---

## 7. Sensitivity Analysis

### 터미널 성장률(g) 민감도
- g = 0%: 보수적 → 가치 낮게 추정 → 많은 종목이 "저평가"
- g = 3%: 기본 가정
- g = 5%: 낙관적 → 가치 높게 추정 → 적은 종목이 "저평가"

### WACC 민감도
- WACC 1%p 변화 → 터미널 밸류 수십% 변화 (분모 효과)
- 저금리 환경에서 민감도 급증

## 8. Strategy Implementation

### 선정 기준
```
Intrinsic Value / Market Price > 1.0 (저평가 기준)

또는:

IV/P 기준 상위 분위 → Long 포트폴리오
```

### 포트폴리오 구성
- Equal-weighted 또는 IV/P 가중
- 분기/반기 리밸런싱
- 금융주 제외 (WACC 개념 적용 어려움)

## 9. Comparison: DCF vs Simple Multiples

| 방식 | 장점 | 단점 |
|---|---|---|
| DCF | 이론적 완결성, 성장 반영 | 가정 민감도 높음, 추정 오류 |
| P/E, P/B | 단순, 데이터 가용성 높음 | 성장률 미반영, 섹터 비교 어려움 |
| EV/EBITDA | 레버리지 중립 | 터미널 성장 미반영 |

## 10. Strategy Ideas Derived

### Idea 1: Value Driver Formula for Korean Quality-Value
ROIC-조정 터미널 밸류 → ROIC > WACC인 기업만 "진정한 저평가" 인정 → 한국 가치 함정 회피

### Idea 2: DCF + HML 조합
P178에서 확인된 한국 HML 프리미엄(11.3%/yr) + DCF 내재가치 필터 → 장부가 높은 기업 중 현금흐름 기반으로도 저평가된 종목 선정

### Idea 3: WACC Regime Adjustment
P182(Damodaran ERP)의 implied ERP를 동적으로 반영 → 시장 상황에 따른 WACC 업데이트 → 레짐 조건부 DCF 밸류에이션

## 11. Limitations

- 터미널 밸류 민감도 과도함 → 전체 가치의 60-80%가 TV
- WACC 추정 오류가 결과를 좌우
- 성장률(g) 가정이 결과에 결정적 영향
- 회계 데이터 시차(look-ahead bias) 위험
- 실제 구현에서 거래비용 미반영
