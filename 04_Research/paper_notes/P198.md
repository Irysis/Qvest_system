## Core Thesis

The TF (Trend Following) Black-Litterman Model fuses trend-following signals into the classic Black-Litterman framework by setting P as the identity matrix and Q as a trend-adjusted return vector. The Black-Litterman model already implicitly contains weak trend-following (via market cap weights reflecting "recent winners get more weight"), and TF-BL makes this explicit and controllable via a single parameter theta (θ). This creates a unified framework for asset allocation that blends equilibrium returns with trend signals.

## Strategy Description

**Standard Black-Litterman Review:**
- Prior (equilibrium): Π|E(R) ~ N(E(R), τΣ)
  - Π = λΣW_mkt + R_f (implied equilibrium returns from market cap weights)
  - W_mkt = market cap weights; Σ = covariance matrix; λ = risk aversion
- View (investor): P·E(R) ~ N(Q, Ω)
  - P = pick matrix; Q = expected return vector; Ω = uncertainty matrix
- Posterior (BL output):
  - E(R)|Π ~ N( [(τΣ)^{-1} + P^T Ω^{-1} P]^{-1} [(τΣ)^{-1}Π + P^T Ω^{-1} Q], [(τΣ)^{-1} + P^T Ω^{-1} P]^{-1} )
- Final weights:
  - W_BL = (λΣ)^{-1} (E(E(R)|Π) - R_f)

**TF Black-Litterman Extension:**
- Set P = Identity matrix (I): direct, one-to-one view on each asset
- Set Q = trend-adjusted expected returns:
  ```
  Q = Π + θ·r_f · (MA_i,short / MA_i,long - 1) for each asset i
  ```
  - MA_i,short = short-term moving average of asset i
  - MA_i,long = long-term moving average of asset i
  - θ = trend strength parameter (controls how much trend is incorporated)
  - When MA_short > MA_long: trend positive → Q > Π → asset gets higher BL weight
  - When MA_short = MA_long: no trend → Q = Π → standard BL
- Ω is automatically determined by P and τΣ (diagonal matrix)

**θ Parameter:**
- θ > 0: standard trend following embedded in BL
- θ < 0: mean-reversion strategy (contrarian)
- θ = 0: pure Black-Litterman without trend
- θ is tuned to maximize Sharpe Ratio in simulation
- Key insight: θ alone controls the balance between equilibrium and trend views

**Simulation Results:**

Financial asset allocation (equities, bonds, commodities, cash, Jan 2010 - Jan 2020):
- TF Black-Litterman: Return 4.67%, Volatility 19.10%, Sharpe 24.45, Hit Ratio 53.26%
- Benchmark (market cap weighted): Return 4.29%, Vol 19.29%, Sharpe 22.22%

Sector allocation within Korean equities (GICS 10 sectors, 2004-2020):
- TF Black-Litterman: Return 18.93%, Vol 78.00%, Sharpe 24.27, Hit Ratio 54.76%
- Benchmark (KOSPI): Return 12.18%, Vol 60.68%, Sharpe 20.07

**Current market application (as of May 2018):**
- Financial allocation: Reduce cash, increase EM equity (신흥국 주식), EM bonds (신흥국 채권)
- Korean sector allocation: Overweight IT (반도체), 의료, 산업재; Underweight 통신서비스, 필수소비재

## Key Results

- TF-BL outperforms standard BL and market cap benchmark on Sharpe ratio basis
- Sector allocation benefit larger than asset allocation benefit (IT sector outperformance)
- θ parameter provides single-knob control over trend intensity
- Model naturally overweights assets with MA_short > MA_long (uptrending)
- The framework is highly practical: only requires MA calculations, no complex forecasting
- Remaining challenges (epilogue): optimal θ linkage to economic cycle, more sophisticated MA specifications, optimal rebalancing frequency

**Key Insight:**
- Market cap weights are implicitly "weak trend following" (winners get more weight)
- TF-BL makes this explicit and adds controllable strength
- Regime linkage suggested: θ > 0 in expansions, θ < 0 in recessions for maximum performance

## Implementation in Korean Market

**Korean sector application (directly relevant):**
- Universe: GICS 10 sectors in KOSPI
- Compute MA_short/MA_long for each sector ETF or sector index
- Q_sector = Π_sector + θ·r_f·(MA_short/MA_long - 1)
- Available sector data: `RAWDATA.parquet` allows sector return computation

**Asset allocation application:**
- Use Korean market cap weights as prior (Π from KOSPI sector weights)
- Apply TF signal (6-month / 12-month MA ratio) for each asset class
- Output: BL-adjusted weights for KOSPI/KTB/Gold/USD asset mix

**Regime-linked θ:**
