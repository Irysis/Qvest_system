# P064: The Capital Asset Pricing Model: Some Empirical Tests (Black, Jensen, Scholes 1972)
**Category:** Factor_Return / Beta
**Feasibility:** low (theory foundation, no direct new strategy)
**Novelty vs existing (BAB failed, LowVol passing):** low

## Core Claim
CAPM의 실증 검증. 1926-1966 미국 데이터에서 SML이 CAPM 예측(기울기=시장 리스크 프리미엄)보다 **유의미하게 평탄**하다. 저베타 주식은 양의 알파, 고베타 주식은 음의 알파. 단순 CAPM 대신 제로-베타 포트폴리오(Z)를 포함한 **2-팩터 모델** 제안:

```
E[r_i] = E[r_z] + beta_i * (E[r_m] - E[r_z])
  - r_z: 시장과 무상관인 최소분산 포트폴리오 (zero-beta portfolio)
  - E[r_z] > rf (실증적으로 rf보다 높음)
```
이는 현재 BAB/LowVol 이상현상의 최초 이론적·실증적 근거.

## Factor Definition
**BJS 포트폴리오 구성법 (측정오차 최소화)**:
1. 각 월 t에서 직전 5년 베타 추정 (OLS, 월별 수익률)
2. 10분위 베타 포트폴리오 구성 (시가총액 가중)
3. 1년 hold, 매년 리밸런싱 → 베타 측정오차의 포트폴리오 분산 효과 활용
4. 사후 포트폴리오 베타 계산 (사전-사후 분리로 편의 제거)

**BJS 포트폴리오 알파**:
```
r_p,t - rf,t = alpha_p + beta_p * (r_m,t - rf,t) + epsilon_p,t
```
저베타(P1): alpha > 0, 유의 (월 0.10~0.19%)
고베타(P10): alpha < 0, 유의 (월 -0.07~-0.24%)

**시계열 월별 검정**: 1931-1965, 전체 및 서브기간(1931-39, 1940-48, 1948-57, 1957-65) 일관성 확인

## Key Results
- SML 실증 기울기: 약 0.36%/month (이론: ~0.11%/month 예측, 절편 양수)
- 절편이 CAPM 예측(rf)보다 유의하게 높음 → 저베타 과소평가 확인
- 저베타 포트폴리오(P1, 베타 ~0.5): 평균 초과수익 월 0.08%, 베타 양의 알파
- 고베타 포트폴리오(P10, 베타 ~1.6): 월 초과수익 0.14%이나 베타 음의 알파
- 결과는 1931-1965 전 서브기간에서 일관
- 무위험 이자율 제한(borrowing constraint) → zero-beta 수익이 rf 초과 설명
