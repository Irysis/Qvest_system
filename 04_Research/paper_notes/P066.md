# P066: Betas and Their Regression Tendencies (Blume 1975)
**Category:** Factor_Return / Beta
**Feasibility:** high
**Novelty vs existing (BAB failed, LowVol passing):** medium

## Core Claim
베타는 시간이 지남에 따라 1.0을 향해 **평균 회귀(mean reversion)**하는 경향이 있다. 이는 단순 통계적 측정 편의가 아니라 기업의 경제적 위험 구조가 실제로 시간이 지나면서 평균으로 수렴하는 **실질적 비정상성(genuine non-stationarity)**이다. 따라서 단순 OLS 베타보다 평균 회귀 조정된 베타(Adjusted Beta)가 미래 베타의 더 나은 예측값이다.

## Factor Definition
**Blume/Vasicek 조정 베타 공식**:
```
E[beta_{t+1} | beta_hat_t] - 1 = [sigma^2(beta_true) / sigma^2(beta_hat)] * (beta_hat_t - 1)

정리하면:
adj_beta_i = alpha + lambda * beta_hat_i

여기서:
  lambda = sigma^2(beta_true) / sigma^2(beta_hat) = 경험적으로 0.67~0.92 범위
  alpha = 1 - lambda  (즉, (1-lambda) * 1.0 로의 수렴)
```

**Merrill Lynch 관행 (업계 표준)**:
```
adj_beta_i = 0.67 * OLS_beta_i + 0.33 * 1.0
```
(lambda = 0.67, alpha = 0.33)

**Bloomberg 관행**:
```
adj_beta_i = 0.67 * OLS_beta_i + 0.33 * 1.0  (동일)
```

**이론적 근거**:
- 측정 기간 간 실제 베타 변화: `sigma^2(beta_true)` = 기업 위험의 실제 분산
- 측정 오차: `sigma^2(beta_hat) - sigma^2(beta_true)` = 순수 통계 오차
- 비율 lambda가 1 미만이면 조정 적용

**R 구현**:
```r
blume_adj_beta <- function(raw_beta, lambda = 0.67) {
  lambda * raw_beta + (1 - lambda) * 1.0
}
```

## Key Results
- 표본: NYSE, 1954-1961(기간1) → 1961-1968(기간2) 개별 종목 약 700개
- 기간1→기간2 베타 변화:
  - 베타 2.0 이상: 평균 하락 → 1.4 수준
  - 베타 0.5 미만: 평균 상승 → 0.7 수준
  - 중간(0.75~1.25): 거의 변화 없음
- 회귀식: `beta_2 = 0.343 + 0.677 * beta_1` (R² = 0.60)
  → lambda = 0.677, alpha = 0.343 (절편 > 0 확인)
- 조정된 베타의 미래 예측력이 원시 OLS 베타보다 유의하게 우수
- 이 경향은 포트폴리오에서도 유지되나 개별 종목에서 더 강함 (P067 보완)

## Notes
- Blume(1975)는 Bloomberg/Merrill Lynch의 adjusted beta 관행의 이론적 근거
- 측정 기간: 1기간 베타 추정에 5년 사용 (BJS와 동일). 분기별 업데이트로도 사용 가능.
- Vasicek(1973) "A Note on Using Cross-Sectional Information in Bayesian Estimation of Security Betas": 베이지안 방법으로 동일 조정 도달. 업계에서 두 방법 모두 "Blume/Vasicek 조정"으로 통칭.
- 조정 강도: lambda = 0.67(Merrill) ~ 0.92(개별종목 최대). 한국 소형주는 lambda 낮게 설정 권장 (이익 변동성 큼 → 측정 오차 비율 높음 → 더 강한 조정 필요).
