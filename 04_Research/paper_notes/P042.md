---

## Core Claim

The total accrual component of earnings is not monolithic — it can be decomposed by the reliability of the underlying accounting measurements. Less reliable accruals have lower earnings persistence, which in turn generates stronger mispricing. The comprehensive balance sheet decomposition TACC = ΔWC + ΔNCO + ΔFIN captures all accrual components and explains mispricing better than the traditional Sloan (1996) working capital measure alone.

---

## Factor Definition

**Comprehensive Accrual Decomposition:**

```
TACC = ΔWC + ΔNCO + ΔFIN
```

Where:
- **ΔWC** (Working Capital Accruals) = ΔCOA − ΔCOL
  - ΔCOA = ΔCA − ΔCASH (change in current operating assets)
  - ΔCOL = ΔCL − ΔSTD − ΔITP (change in current operating liabilities)
- **ΔNCO** (Non-Current Operating Accruals) = ΔNCOA − ΔNCOL
  - ΔNCOA = ΔTA − ΔCA − ΔLTI − ΔIVAO (non-current operating assets)
  - ΔNCOL = ΔTL − ΔCL − ΔLTD (non-current operating liabilities)
- **ΔFIN** (Financial Accruals) = ΔSTI + ΔLTI − ΔFINL
  - Financial assets minus financial liabilities

**Reliability Hierarchy:**
- ΔCOA = Low reliability (hardest to verify)
- ΔCOL = High reliability
- ΔNCOA = Low reliability
- ΔNCOL = Medium reliability
- ΔFIN = High reliability (market-valued)

**Scaling:** All components scaled by average total assets

**Persistence Hierarchy (regression coefficients):**
- CFO: ~0.74 (most persistent)
- ΔWCACC: ~0.49
- ΔNCO: ~0.37
- ΔFIN: ~0.30 (least persistent)

---

## Key Empirical Results

- Sample: 108,617 firm-years, 1962–2001, NYSE/AMEX/NASDAQ
- Errors-in-variables model: less reliable accruals → lower persistence → market overestimates persistence → negative future returns
- Hedge portfolio (long bottom TACC decile, short top TACC decile): ~18% annual abnormal return
- ΔNCO component adds incremental predictive power beyond Sloan's ΔWC alone
- ΔFIN component also significantly predicts returns (negative for high ΔFIN)
- Fama-MacBeth regressions confirm each component predicts returns independently
- Results hold after controlling for size, BM, momentum

## Korea Applicability

- **Medium-High.** K-IFRS requires balance sheet data sufficient to compute TACC = ΔWC + ΔNCO + ΔFIN
- ΔNCO (non-current operating accruals) is the key incremental component beyond STR_012
- Financial accruals (ΔFIN) may behave differently in Korea due to chaebol cross-holdings (equity method investments are large), which inflates ΔFIN
- Korean code-law system: expect 40–60% of US effect magnitude
- DART data provides the required balance sheet items via `fundamental_dart.parquet`

## Actionable Strategy Ideas

1. **ΔNCO Factor (highest priority):** Compute non-current operating accruals = ΔNCOA − ΔNCOL, scaled by average assets. This is NOT in STR_012 and adds incremental predictive power beyond working capital accruals. Long low-ΔNCO, short high-ΔNCO.

2. **Reliability-Weighted Accrual Score:** Construct a composite score that weights each accrual component by inverse reliability (ΔCOA gets highest weight, ΔFIN lowest weight). This is a differentiated signal versus the uniform Sloan measure.

3. **Three-Component Decomposition Signal:** Use TACC = ΔWC + ΔNCO + ΔFIN as three separate signals in a factor model. Run cross-sectional Fama-MacBeth to determine which component dominates in Korea.

```r
# R implementation sketch
# Requires: fundamental_dart.parquet with balance sheet items
accrual_decomp <- fundamentals %>%
  mutate(
    # Working capital accruals
    dCOA = (act - che) - lag(act - che),
    dCOL = (lct - dlc - txp) - lag(lct - dlc - txp),
    dWC  = dCOA - dCOL,
    # Non-current operating accruals
    dNCOA = (at - act - ivao) - lag(at - act - ivao),
    dNCOL = (lt - lct - dltt) - lag(lt - lct - dltt),
    dNCO  = dNCOA - dNCOL,
    # Financial accruals
    dFIN  = (ivst + ivao) - dltt - lag(ivst + ivao - dltt),
    # Comprehensive total
    TACC  = (dWC + dNCO + dFIN) / ((at + lag(at)) / 2)
  )
```
