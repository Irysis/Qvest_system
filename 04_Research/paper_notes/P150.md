# P150: Portfolio Selection (1952)
**Category:** Portfolio_Theory | **Priority:** 3
**Author:** Harry Markowitz | **Journal:** Journal of Finance, Vol. 7, No. 1, pp. 77-91

## Core Contribution to Factor Investing
Markowitz's 1952 paper is the single most important foundation for all quantitative portfolio construction. It proved that maximizing expected return alone (the "discounted returns" rule) cannot produce diversified portfolios and must be rejected. The **Expected Returns–Variance (E-V) rule** — maximize E while minimizing V — is the first principled framework that simultaneously motivates diversification and provides a tractable optimization target. For factor investing specifically: the covariance matrix structure Markowitz defines is the direct ancestor of the factor covariance models we use to estimate portfolio risk; the efficient frontier concept defines the feasible tradeoff space within which our signal-weighted portfolios must operate.

## Key Formula/Result
Covariance between securities i and j:
```
σ_ij = E{ [R_i - E(R_i)] · [R_j - E(R_j)] }
     = ρ_ij · σ_i · σ_j
```

Portfolio variance:
```
V = Σ_i Σ_j x_i · x_j · σ_ij
```

Portfolio expected return:
```
E(R_p) = Σ_i x_i · E(R_i)
```

Key finding: diversification cannot eliminate **all** variance because returns from securities are intercorrelated. The minimum variance is bounded below by the average covariance between all pairs — this is systematic (market) risk. Only the idiosyncratic component can be diversified away by holding many stocks.

Law of Large Numbers does NOT apply to portfolios because returns are correlated — this was the critical insight that separated Markowitz from all prior portfolio theory.

## Modern Relevance for Korea Strategy
The E-V framework is directly implemented in our `backtest_harness.R` via `summarise_perf()`. More importantly: Markowitz's proof that intercorrelation sets a lower bound on portfolio variance is the reason regime detection matters — in Korean market crises (2008, COVID-2020), cross-stock correlations spike toward 1.0, collapsing the efficient frontier and making all diversification benefits temporary. Our Maxwell Protocol's regime detection step is a direct response to the time-varying nature of σ_ij that Markowitz treated as static. For a concentrated 20-30 stock portfolio, precise covariance estimation (not sample covariance, which is singular for N > T) is essential.
