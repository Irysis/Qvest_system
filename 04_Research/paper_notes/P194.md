# Paper Note: P194 — Protective Asset Allocation: PAA (2016)

**Authors:** Wouter J. Keller, Jan Willem Keuning
**Source:** SSRN Working Paper (2016)
**Category:** Asset_Allocation
**Priority:** 1

## Core Thesis

PAA (Protective Asset Allocation) is the first paper in Keller's tactical allocation family and introduces the concept of "breadth momentum protection" — the idea that asset allocation should become increasingly defensive as the number of assets with positive momentum declines. The protection fraction (Bond Fraction BF) is a continuous function of market breadth, unlike binary all-or-nothing switches. PAA achieves near-zero drawdowns in all 5-year sub-periods since 1970.

## Strategy Description

**Momentum Signal:**
- MOM(L) = p0/SMA(L) - 1
- p0 = current price, SMA(L) = L-month simple moving average
- Asset is "good" if MOM(L) > 0, "bad" if MOM(L) <= 0
- Best L = 12 months

**Offensive Universe (N=12):**
SPY, QQQ, IWM, VGK, EWJ, EEM, IYR, GSG, GLD, HYG, LQD, TLT

**Safe Asset:** IEF (7-10 year US Treasury)

**Protection Mechanism:**
- n = number of good assets (MOM > 0)
- n1 = a * N/4 (lower threshold for protection)
- **Bond Fraction BF = (N - n) / (N - n1)**
- BF = 1 (100% bonds) when n <= n1
- BF = 0 when n = N (all assets good)

**Protection Factors (a parameter):**
- PAA0 (a=0): n1=0; BF = (12-n)/12; linear protection
- PAA1 (a=1): n1=3; BF = (12-n)/9; moderate protection
- PAA2 (a=2): n1=6; BF = (12-n)/6; BF=100% when 6 or fewer assets positive (HIGH PROTECTION)

**Portfolio Construction:**
- Top T assets (by momentum) get (1-BF) weight equally
- IEF gets BF weight
- Best IS: T=6, L=12, a=2 (PAA2)

**Full Sample Performance (Dec 1970 - Dec 2015):**
- Return: 13.7% p.a.
- Volatility: 8.6%
- Max Drawdown: -10.4%
- Win0 (positive 5Y rolling): 96%
- Win5 (beat 5% hurdle in 5Y rolling): 99.4%
- Sharpe Ratio: 1.02
- MAR: 1.32
- vs 60/40: R=9.7%, D=-29.5%, SR=0.48

**IS/OS/FS Validation:**
- IS (Dec 1970 - Dec 1992): R=13.0%, SR=0.92, D=-10.4%
- OS (Jan 1993 - Dec 2015): R=14.4%, SR=1.11, D=-6.1%
- OS improves over IS → no data-snooping concern

## Key Results

- PAA2 with L=12, T=6 is the definitive optimal configuration
- Win5=99.4%: only 0.6% of 5-year rolling periods fail to exceed 5% return
- Breadth-based protection is superior to simple momentum timing
- PAA eliminates catastrophic drawdowns: max DD never exceeds -12% in full sample
- Returns are consistently 13-15% with < 10% drawdown
- PAA is the cleanest, most interpretable strategy in the Keller family

## Implementation in Korean Market

**Korean adaptation:**
- Replace N=12 ETFs with Korean-accessible equivalents
- Replace IEF with Korean bond ETF or TIGER 미국채10년선물
- MOM(12) = KOSPI/SMA(12) - 1 directly computable from RAWDATA.parquet

**R Code Sketch:**
```r
# PAA2 Bond Fraction
N <- 12
a <- 2
n1 <- a * N / 4  # = 6
# n = number of assets with MOM(12) > 0
BF <- pmax(0, pmin(1, (N - n) / (N - n1)))
# If n <= n1: BF = 1 (full bonds)
# Risky weight = (1 - BF) / T for top T assets
```

**Feasibility: VERY HIGH** — simplest strategy in the family, very clean implementation
