## Core Thesis

"Quality" = characteristics rational investors should pay more for:
- **Profitability + Growth + Safety**

High-quality firms DO command higher prices — but not nearly enough relative to theory. The residual pricing gap generates the **QMJ factor**: Long top-quality, short lowest-quality.

**US Long Sample (1957-2016):** CAPM alpha = +64 bps/month (t=8.23), 4-factor alpha = +105 bps/month
**Global 24-country:** 4-factor alpha = +99 bps/month (t=6.67)

## Quality Score Construction

### Profitability (6 sub-factors, z-score of z-scores):
```
Profitability = z(GPOA + ROE + ROA + CFOA + GMAR + ACC)
- GPOA = Gross Profit / Total Assets  (Novy-Marx measure — most predictive sub-factor)
- ROE  = Net Income / Book Equity
- ROA  = Net Income / Total Assets
- CFOA = CFO / Total Assets
- GMAR = Gross Profit / Revenue
- ACC  = CFO / |Net Income|  (cash fraction, HIGH = GOOD here)
```

### Growth (5-year changes in each Profitability metric):
```
Growth = z(Δ5yr_GPOA + Δ5yr_ROE + Δ5yr_ROA + Δ5yr_CFOA + Δ5yr_GMAR)
```

### Safety (5 sub-factors):
```
Safety = z(-Beta + (-Leverage) + (-O_score) + (-Z_distress) + (-EarningsVol))
- BAB  = low market beta (Frazzini & Pedersen)
- LEV  = low leverage (총부채/자본)
- O    = low Ohlson O-score (bankruptcy probability)
- Z    = low Altman Z-score (distress)
- EVOL = low ROE standard deviation (5-year rolling)
```

### Final Composite:
```
Quality = z(Profitability + Growth + Safety)
```

## Key Korean-Market Considerations

1. **QMJ is NEGATIVELY correlated with value (HML)** — quality firms are expensive. Good diversifier against crowded Korean PBR value strategies.
2. **5-year Growth limited** in early DART history (2016-2024 data → 2021+ for full 5yr)
3. **BAB conflict**: Safety includes low-beta. Don't run standalone BAB simultaneously with full QMJ composite.
4. **GPOA mapping**: KOSDAQ IT services may lack explicit COGS (매출원가). Fall back to operating profit/assets for those firms.
5. **Price of Quality (시장 퀄리티 프리미엄)**: When current Price-of-Quality is LOW (P/B doesn't reflect quality), future QMJ returns are HIGH. Estimable via cross-sectional regression of P/B on Quality_z.

## Implementation Blueprint (R Code)

```r
# Profitability score
prof <- dart_fund %>%
  group_by(ticker, fiscal_year) %>%
  mutate(
    gpoa = gross_profit / total_assets,
    roe  = net_income / book_equity,
    roa  = net_income / total_assets,
    cfoa = cfo / total_assets,
    gmar = gross_profit / revenue,
    acc  = cfo / abs(net_income)  # HIGH is GOOD
  ) %>%
  group_by(fiscal_year) %>%
  mutate(across(c(gpoa,roe,roa,cfoa,gmar,acc),
                ~ (rank(.)-.N/2)/sd(rank(.)), .names="z_{.col}")) %>%
  mutate(Profitability = z_gpoa + z_roe + z_roa + z_cfoa + z_gmar + z_acc)

# Composite Quality (after computing Growth + Safety similarly)
quality_dt[, Quality := z(Profitability + Growth + Safety)]
```
