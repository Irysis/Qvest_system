## Core Thesis
Factor returns follow their own **sentiment-driven cycle** that is only weakly related to the macroeconomic business cycle. Traditional business cycle indicators (NBER recessions, inflation, ISM PMI) have minimal discriminatory power for factor returns. Instead, the quant cycle consists of three stages:

1. **Normal stage** (~2/3 of time): All factors deliver solid positive returns above their long-term averages
2. **Drawdown stage** (~once per decade, lasting ~2 years): Either (a) growth rally — value crashes while momentum gains; or (b) value crash — value crashes while quality/momentum gain
3. **Reversal stage**: (a) Bear reversal — growth stocks crash back (value rebounds strongly, all factors positive) or (b) Bull reversal — beaten-down stocks recover (momentum crashes, quality negative, only value positive)

The key empirical finding: a simple 3-stage quant cycle model inferred **directly from factor returns** explains far more time variation in factor premiums than any macroeconomic indicator. The investor sentiment index of Baker-Wurgler (2006) is more effective than business cycle metrics but still limited — the quant cycle itself is the best predictor of its own next stage.

## Key Quantitative Results
- HML value factor: long-term premium ~3% p.a.; -20% annual return in 1998-1999; +15% annual return in 2000-2006
- Market factor: NBER expansion vs. recession spread = 8.8% vs. -7.4% (strong); all other factors virtually unaffected by NBER cycles
- Baker-Wurgler sentiment: value, quality, low-risk show strong returns when sentiment positive, weak when negative; momentum resilient across sentiment states
- Growth rallies identified: Nifty Fifty (early 1970s), energy/commodities (1979-1980), biotech/healthcare (late 1980s), tech bubble (1998-2000), FANMAG/Tesla (2018-2020)
- Bull reversal example 2009: cheap financials bounced +50-80% — momentum crashed severely
- Normal stage frequency: ~65% of time; drawdown stage: ~20%; reversal stage: ~15%
- Transition probability from normal to drawdown: ~16% per year (average normal stage duration ~6 years)
- During growth rallies: 1/N multi-factor mix has **flat** average return (momentum gains offset value losses)
- During bear reversals: 1/N mix generates **spectacular** returns (all factors positive, market crashes)
- During bull reversals: 1/N mix generates **large negative** returns (momentum crashes dominate)
- iMom (idiosyncratic momentum) strongly outperforms WML momentum during bull reversals, limiting losses

## Application to Korean Factor Strategy

**What drives the quant cycle — and how to detect crowding in Korea:**

The quant cycle is NOT driven by macroeconomics. It is driven by **investor sentiment shifts** that create and then reverse extreme style tilts. In the Korean market context:

**Korean Quant Cycle Characteristics:**
1. Korea experienced its own growth rally in 2017-2021 driven by KAKAO, Naver, Samsung Biologics, Krafton — direct analog to FANMAG
2. Korean value stocks (POSCO, KB Financial, HyundaiSteel) dramatically underperformed 2018-2021 — matching global pattern
3. Post-COVID bull reversal (2020-2021): Korean small-cap value and reopening stocks bounced violently; momentum strategies suffered
4. Current status (as of 2026): Korea appears to be in post-bull-reversal normal stage; value has partially recovered

**Quant Crowding Detection in Korea — Specific Methods:**

1. **Value spread monitoring** (most important signal):
   ```r
   # Monthly: compute spread between top/bottom value quintile P/B or P/E ratios
   # If spread > historical 80th percentile → crowding in growth stocks → value drawdown stage entry
   # If spread < historical 20th percentile → value overshoot → bear/bull reversal imminent
   value_spread <- median(pb_bottom_quintile) / median(pb_top_quintile)
   ```

2. **Factor return cumulative drawdown tracking:**
   ```r
   # Track rolling 12-month return of each factor signal
   # If value factor 12M return < -15% → drawdown stage confirmed
   # If momentum 12M return > +20% concurrent with value < -10% → growth rally detected
   ```

3. **Cross-factor correlation as crowding indicator:**
   - During normal stage: value-momentum correlation near zero or slightly negative
   - During growth rally: value-momentum correlation strongly negative (momentum gains, value loses)
   - During bull reversal: value-momentum correlation strongly positive and both volatile
   ```r
   rolling_vm_corr <- rollapply(cbind(value_ret, momentum_ret), width=12,
                                 function(x) cor(x[,1], x[,2]), by.column=FALSE)
   ```

4. **iMom (idiosyncratic momentum) vs. raw momentum spread:**
   - When iMom significantly outperforms raw momentum → bull reversal risk is elevated (market has strong systematic momentum tilt that is about to reverse)
   - Compute residual momentum after stripping sector and beta effects

5. **Baker-Wurgler analog for Korea:**
   - Korean proxy: KOSDAQ IPO volume (high = euphoria), retail investor margin debt (high = sentiment), new equity issuance as % of market cap
   - When Korean sentiment proxy in top quintile → increase quality/momentum vs. value; reduce concentration

**Stage-conditional factor allocation for Korean strategy:**
| Quant Cycle Stage | Value Weight | Quality Weight | Momentum Weight | Low-Vol Weight |
|-------------------|--------------|----------------|-----------------|----------------|
| Normal | 25% | 25% | 25% | 25% |
| Growth rally (detected) | 5% | 35% | 40% | 20% |
| Value crash (detected) | 5% | 40% | 35% | 20% |
| Bear reversal (detected) | 35% | 25% | 25% | 15% |
| Bull reversal (detected) | 40% | 10% | 5% | 45% |

**Integration with macro_regime.parquet:**
The existing macro regime signals (VIX, YC, HY Spread, KRW) capture macroeconomic regime but NOT quant cycle stage. Add quant cycle stage as a **fifth regime dimension** orthogonal to macro regime. The quant cycle is inferred from factor returns themselves, not macro data.
