# P105: Kyle Microstructure Invariance
**Authors:** Kyle, Obizhaeva (2016, SSRN 2722524)
**Category:** Factor_Return / Liquidity_Factors

## Core Idea
비즈니스 타임(business time) 기반 불변성 원리. 거래 활발한 종목은 비즈니스 타임이 빠르게 흘러감. 비유동성 지수:

```
1/L ∝ (sigma² / DollarVol)^(1/3)
```

큐브루트 스케일링으로 아웃라이어 압축, 이론적으로 유도된 형태.

## Key Results
- 400,000+ 포트폴리오 전환 주문으로 불변성 실증
- 비유동성 지수가 실질 거래비용(implementation shortfall) 설명
- 베팅 도달률 gamma ∝ W^(2/3) (W = sigma × Price × Vol)
- 로그정규 베팅 크기 분포, 로그분산 2.53

## Parameters
- sigma: trailing 60일 수익률 표준편차 (Garman-Klass 또는 Parkinson 가능)
- DVOL = Close × Vol
- Kyle_Illiq = (sigma² / DVOL)^(1/3)
- 월별 집계, 최소 40 거래일

## Korean Market Notes
- 큐브루트 압축이 한국 소형주 아웃라이어 문제 완화
- sigma 추정에 High-Low 기반 Parkinson/GK 사용 가능 (OHLCVS 보유)
- W = sigma × DVOL → 시장 레짐 지표로도 활용 가능
- 절대 거래비용 추정보다 **상대 순위** 목적으로 사용 (상수 불필요)

## Strategy Design → STR_008 (or 앙상블 컴포넌트)
- Kyle_Illiq + OCAM 앙상블: 0.5 × rank(OCAM) + 0.5 × rank(Kyle_Illiq)
- 레짐: 고VIX → OCAM 가중치 증가 (overnight 노이즈 더 심해지므로)
- 잔차 분해 후 팩터 구성 (Size, Beta 통제)
