## Core Thesis

Extension of Sloan (1996): not all accruals are equally unreliable. Decompose accruals by **reliability tier** — less reliable accruals (higher measurement error) generate lower earnings persistence AND larger investor mispricing. This amplifies the accrual anomaly signal by 2-3x vs. Sloan's aggregate metric.

---

## Key New Finding vs. Sloan 1996

Sloan treated all accruals equally. Richardson et al. introduce **reliability ranking**:

| Component | Reliability | Example | Hedge Return t+1 |
|-----------|-------------|---------|-----------------|
| ACOA (current operating assets) | Lowest | ΔInventory, ΔReceivables | **+14.8%** |
| ANCO (non-current operating assets) | Low-Medium | ΔPP&E net | **+16.3%** |
| AFIN (financial) | High | ΔEquity, ΔDebt | -0.8% (opposite direction) |
| Total accruals (Sloan) | Mixed | — | +13.3% (vs Sloan's +10.4%) |

**Key insight:** AFIN (financial accruals) go in the OPPOSITE direction — high financial accruals (e.g., equity issuances) predict POSITIVE returns. Use ANCO and ACOA as shorts, AFIN as additional long signal.

## Extended Accrual Decomposition

```
TACC = ΔAWC + ΔANCO + ΔFIN

AWC  = Change in Working Capital (current assets - current liabilities, excl cash/debt)
ANCO = Change in Non-Current Operating Assets (PP&E, intangibles)
FIN  = Change in Financial Assets/Liabilities (equity, long-term debt, investments)
```

**Implementation:**
```r
# From DART balance sheet:
delta_AWC  <- (현금제외유동자산 - 유동부채차입금제외) - lag(same)
delta_ANCO <- (비유동영업자산) - lag(비유동영업자산)
delta_FIN  <- (금융부채+자본변동) - lag(same)
TACC <- (delta_AWC + delta_ANCO + delta_FIN) / avg_total_assets

# Signal: SHORT high TACC (especially high ANCO/ACOA)
#         LONG low TACC / high AFIN
```

## Key Performance Numbers (1962-2001, 40 years)

- Total TACC hedge: **13.3% annual** (t=10.25)
- ACOA decile spread: **14.8% annual** (t=14.26)
- ANCO decile spread: **16.3% annual** (t=14.91)
- AFIN decile spread: **-0.8% annual** (t=-7.49, reverse direction)
- ROA₍t+1₎ persistence: ACOA coeff = -0.064 (t=-12.08), ANCOL = -0.047
- No anomaly decay: 40-year window confirms persistence even more than Sloan

## Korean Market Implementation

- All components available from DART: 재무상태표 (balance sheet)
- Segment by reliability: 유동영업자산 (AWC) = 매출채권 + 재고자산 + 기타유동자산
- 비유동영업자산 (ANCO) = 유형자산 + 무형자산 + 투자부동산
- Use ANCO short signal as primary (highest anomaly return 16.3%)
- More powerful in KOSDAQ (lower institutional accrual screening)
- Overlay regime filter: accrual anomaly weakens in crisis (liquidity premium dominates)

## Strategy Implication

For STR_012 (Sloan Accrual), consider using Richardson et al.'s decomposed TACC instead of simple CFS method:
- **SHORT high ANCO/ACOA** (non-current operating + current operating accruals)
- **LONG low total accruals** (earnings backed by cash flow)
- Score = -Z(ANCO) * 0.6 + -Z(ACOA) * 0.4 (sector-neutralized)
