# P063: Betting Against Beta (Frazzini & Pedersen 2014)
**Category:** Factor_Return / Beta
**Feasibility:** low (Korean long-only context)
**Novelty vs existing (BAB failed, LowVol passing):** low

## Core Claim
레버리지 제약을 받는 투자자가 고베타 주식에 과잉 수요를 일으켜 SML이 CAPM 예측보다 평탄해진다. 저베타 매수 / 고베타 공매도 (leverage-neutral BAB 포트폴리오)로 미국에서 월 알파 0.73% (FF3 기준, t=7.39), Sharpe 0.78 달성. 19개 선진국 중 18개국에서 양의 수익.

## Factor Definition
**Frazzini-Pedersen 베타 추정**:
```
beta_i = rho_im * (sigma_i / sigma_m)
  - sigma_i: 252일 일별 수익률 표준편차 (log return)
  - sigma_m: 252일 시장 수익률 표준편차
  - rho_im: 1260일(5년) 3-일 overlapping return 기반 Pearson 상관계수
```
**Shrinkage**: `beta_shrunk = 0.6 * beta_ts + 0.4 * 1.0`

**BAB 포트폴리오 수익**:
```
r_BAB = (1/beta_L)(r_L - rf) - (1/beta_H)(r_H - rf)
  - r_L: 저베타 포트폴리오 수익 (베타 가중 rank-sorted)
  - r_H: 고베타 포트폴리오 수익
  - 각 레그는 beta=1로 레버리지 조정
```
섹터 중립화, 월별 리밸런싱

## Key Results
- 미국 1926-2012, 월별
- BAB 월 alpha (FF3): 0.73%, t=7.39
- BAB 월 alpha (Carhart): 0.55%, t=5.59
- Sharpe ratio: 0.78
- 실현 베타: 약 -0.06 (시장 중립)
- TED spread 높을 때(funding stress) BAB 수익 하락 → 레버리지 제약 이론 지지
- 전 세계 주식, 채권, FX, CDS 등 다양한 자산군에서 BAB 성립

## Korea Applicability
**적용 가능성: 낮음 — STR_001 이미 실패**
- **STR_001 결과**: Long-only BAB → MDD 99.9%, Turnover 1201% → 완전 실패
- **Lesson L-02**: 저베타 long-only = 비유동 소형주 역선택
- 공매도 불가 (한국 공매도 제한): L/S BAB 전략 구현 불가
- 레버리지 제약 이론 → 한국 시장에서도 이론상 성립하나 구현 수단 없음
- 저베타 레그만 사용 시 구조적 문제(비유동 소형주 편향) 해결 불가

## Actionable Ideas
- **SKIP**: 한국 long-only 환경에서 BAB 구현 불가. STR_001에서 이미 검증 완료.
- **부수적 참고**: Frazzini-Pedersen 베타 추정 방식 (5년 correlation × 1년 vol + 0.6/0.4 shrinkage)은 LowVol/베타 팩터 계산 시 표준 방법론으로 활용 가능. BAB 전략 자체가 아닌 베타 추정 formula만 채용.
- **베타 추정 개선**: `rho_im * (sigma_i / sigma_m)` 방식이 단순 OLS 베타보다 안정적 → STR_003 LowVol에서 베타 계산 시 FP 방식 적용 검토.

## Notes
- 한국 시장에서 BAB가 실패하는 구조적 이유: (1) 저베타 주식 = 비유동 소형주, (2) 공매도 제한, (3) 레버리지 제약 투자자 비중이 낮음
- 이론적으로는 가장 정교한 저베타 전략이나 한국 규제·시장구조상 구현 불가
- LowVol (STR_003)이 BAB의 long 레그를 유동성 필터와 결합한 실용적 대안으로 이미 작동 중
- 참고: 논문의 FP 베타 공식은 P061(Beta Anomaly), P063(BAB) 공통 방법론
