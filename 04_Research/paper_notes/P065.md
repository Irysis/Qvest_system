# P065: Beta and Return (Black 1993)
**Category:** Factor_Return / Beta
**Feasibility:** low (theory update, no new strategy)
**Novelty vs existing (BAB failed, LowVol passing):** low

## Core Claim
베타는 살아 있다(Beta is alive). 1926-1991 장기 데이터에서 BJS(1972) 결과가 재확인된다. 저베타 초과성과는 차입 제약(borrowing restrictions)으로 인해 저베타 주식을 레버리지 수단으로 활용하는 투자자 수요가 만드는 구조적 현상이다. Fama-French(1992)의 베타 사망 선고에 대한 반론.

## Factor Definition
**BJS 업데이트 포트폴리오 (1926-1991)**:
```
- 동일한 10분위 베타 정렬 방식
- 사전 5년 베타 추정 (월별 수익률 OLS)
- 표본: NYSE 전체, 총 66년
```

**베타-수익 관계 검정 (기간별)**:
```
단기(1926-65): 저베타 양의 알파, 고베타 음의 알파 → BJS 복원
장기(1926-91): 여전히 베타-수익 양의 관계 유의
1966-91 서브기간: 약화되었으나 소음(noise)으로 해석
```

**차입 제약 모델 (이론)**:
```
저베타 → 레버리지 투자자 수요 → 가격 상승 → 미래 수익 하락
그러나 차입 제약 비율이 충분히 높으면 저베타 보유 투자자는 초과수익
균형: E[r_z] > rf (zero-beta return > risk-free rate)
```

## Key Results
- 1926-1991 전체: 베타와 수익의 양의 관계 유지, FF(1992) 주장과 달리 베타 유효
- 1931-65(BJS 원 표본): 10분위 포트폴리오 모두 유의한 beta-return 양의 관계
- 차입 제약: TED spread, margin 요건과 저베타 초과수익 음의 상관 (간접 증거)
- 규모(size), B/M: 데이터 마이닝 결과일 가능성 높음 (베타의 대리변수)
- 베타는 장기적으로 수익의 유의한 예측변수 (단기 노이즈 있으나 장기 지속)

## Notes
- 배경: Fama-French(1992) "The Cross-Section of Expected Stock Returns"이 베타가 수익 예측력 없다고 주장한 것에 대한 Fischer Black의 반론
- Black의 주장: FF(1992)는 표본 선택 편의(1963-90, 생존 편의) + 데이터 마이닝
- 현재 consensus: 베타는 수익 예측력 제한적이나 저베타 anomaly는 실재 (P061, P063 등이 확인)
- 역사적 가치: CAPM 논쟁사에서 중요한 위치. 순수 실무 전략에는 직접 기여 낮음.
