# P167: Strategic Beta and Style Investing — Independent vs. Dependent Sorting (2017)
**Category:** Smart_Beta | **Priority:** 3

## Core Finding
Fays, Lambert & Papageorgiou (2017) compare independent vs. dependent sorting for strategic beta on style portfolios (size, value, momentum). Market equity and B/M are negatively correlated (-5%), causing systematic imbalance in independent sorts that inflates apparent factor premia. Dependent sorting delivers significantly higher Sharpe ratios by properly stratifying stocks. Average inter-portfolio correlation: independent 2x3 sort = 84.99, dependent 2x3 sort = 78.00. Mean-variance spanning tests show dependent sort strategies improve the tangency portfolio (6/12 for MV, 12/12 for MD); independent sort strategies never improve the tangency portfolio.

## Key Risk/Concern for Korean Implementation
Korean DART data covers multiple financial ratios simultaneously (P/B, ROE, Accrual, ICR). If we sort independently on multiple factors, we will inadvertently create imbalanced portfolios due to intercorrelations between DART metrics (e.g., high-ROE companies tend to have high P/B, creating a correlated double-tilt). Independent sorting in Korea likely overstates both quality premia and value premia due to this structural correlation.

## Actionable Takeaway
1. Implement dependent (sequential) sorting in the factor construction pipeline: when building composite factor portfolios, sort first on the primary factor (e.g., value/P/B), then within each quintile sort on the secondary factor (e.g., quality/ROE), following the Fays methodology.
2. Use the Booth-Fama (1992) diversification return decomposition to verify that dependent sorting genuinely improves portfolio-level diversification return in the Korean context before adopting it universally.
