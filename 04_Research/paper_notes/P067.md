# P067: Portfolio Theory: A Step Toward Its Practical Application (Blume 1970)
**Category:** Factor_Return / Beta
**Feasibility:** high (methodological foundation)
**Novelty vs existing (BAB failed, LowVol passing):** medium

## Core Claim
개별 종목의 베타는 표본 오차가 크고 기간 간 불안정하지만, **포트폴리오 수준의 베타는 20개 이상 종목에서 기간 간 매우 안정적**이다. 저베타 포트폴리오를 개별 종목이 아닌 포트폴리오 단위로 구성하면 베타 추정 오차를 크게 줄일 수 있다. 또한 주식 수익률 분포는 정규분포보다 안정 분포(stable distribution)가 더 잘 적합하며, 특성 지수(characteristic exponent) θ는 1.7~1.8.

## Factor Definition
**개별 종목 베타 vs 포트폴리오 베타 비교**:
```
개별 종목 OLS 베타: beta_i = Cov(r_i, r_m) / Var(r_m)
  - 측정 오차 분산: sigma^2(e_i) / [T * Var(r_m)]  → T=60개월 시 크지 않으나 충분하지 않음
  - 기간1-기간2 상관: R ≈ 0.5~0.6 (개별 종목)

포트폴리오(n종목) 베타: beta_P = sum(w_i * beta_i) / n
  - 측정 오차: 개별 오차의 n분의 1로 감소 (분산화)
  - 기간1-기간2 상관: R ≈ 0.98 (50종목 포트폴리오)
  - R ≈ 0.95 (20종목 포트폴리오)
```

**포트폴리오 단위 베타 추정 방법 (BJS식)**:
1. 기간1(5년)에서 개별 종목 베타 추정
2. 10분위 포트폴리오 배정 (베타 기준)
3. 기간2(5년)에서 포트폴리오 베타 재추정
4. 기간1-기간2 상관으로 베타 안정성 측정

**안정 분포 적합**:
```
수익률 ~ Stable Distribution with characteristic exponent θ
최적 θ: 1.7~1.8 (정규분포 θ=2, Cauchy θ=1)
결론: 주식 수익률은 fat-tailed (두꺼운 꼬리), 이분산성 존재
```

## Key Results
- 표본: NYSE, 1926-1968, 10-year sub-periods
- 개별 종목 베타 기간간 상관: R = 0.59 (5년)
- 20종목 포트폴리오 베타 상관: R = 0.95
- 50종목 포트폴리오 베타 상관: R = 0.98
- 포트폴리오 크기와 베타 안정성은 n ≈ 20에서 급격히 개선, 50 이상에서 포화
- 안정 분포 θ = 1.7~1.8 추정: 정규분포 VaR 과소추정, 실제 꼬리 리스크 더 큼
- 포트폴리오 베타 예측에서 과거 5년 데이터가 최적 (3년 부족, 10년 과거 의존도 과다)
