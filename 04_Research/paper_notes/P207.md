# P207: The 101 Ways to Measure Portfolio Performance
**Category:** Risk_Portfolio | **Priority:** 3
**Authors:** Philippe Cogneau, Georges Hubner (University of Liege, HEC Management School) | **Source:** SSRN 1326076

## Core Thesis
A comprehensive census and taxonomy of 101 portfolio performance measures from the academic and practitioner literature. The paper classifies all measures along a binary tree: (1) skill type (asset selection vs. market timing), (2) individualization (standardized/risk-adjusted vs. preference-dependent), (3) value creation measure (excess return vs. gain potential), and (4) translation type (relative/ratio vs. absolute/difference). The paper identifies "dead-end" categories where a dominant generalization exists and highlights which measure families remain active research areas.

## Key Quantitative Results — Taxonomy Structure

**Level 1: Asset Selection vs. Market Timing**
- Asset selection measures dominate (most of the 101)
- Market timing measures: Treynor-Mazuy (quadratic regression), Henriksson-Merton (option-based), Ferson-Schadt (conditional)

**Level 2: Standardized (Risk-Adjusted) Measures — Primary Families:**

**Category 3.1: Absolute Risk Ratios (Return / Risk)**

| Measure | Formula | Key Property |
|---------|---------|--------------|
| Sharpe Ratio | (R_p - r_f) / σ_p | Baseline; not manipulable by leverage |
| Modified Sharpe (Israelsen) | (R_p - r_f) / σ_p^{sign(R_p-r_f)} | Handles negative excess return |
| Double Sharpe (Vinod-Morey) | SR / std(SR) via bootstrap | Adjusts for estimation error |
| Sortino Ratio | (R_p - R_min) / downside_σ | Only penalizes downside variance |
| Sortino-Satchell | (R_p - R_min) / LPM_q | Generalizes Sortino with risk aversion order q |
| Upside Potential Ratio (UPR) | E[R - R_min]_+ / downside_σ | Reward/risk with same threshold |
| Farinelli-Tibiletti | UPM_p / LPM_q | Most general; Omega is p=q=1, UPR is p=1, q=2 |
| Omega (Bernardo-Ledoit) | E[R-threshold]_+ / E[threshold-R]_+ | Ratio of call/put on portfolio return |
| Calmar Ratio | Annualized return / Max Drawdown | Common in CTA/hedge fund evaluation |
| Sterling Ratio | Return / Avg(top N drawdowns) + 10% | Less sensitive to outliers than Calmar |
| Burke Ratio | Return / sqrt(Σ drawdowns²) | Most robust drawdown-based measure |
| Ulcer Performance Index | Return / Ulcer Index | Ulcer = quadratic mean of % drops from peak |
| MAD Ratio | Return / Mean Absolute Deviation | Robust to outliers; linear risk measure |
| Sharpe/VaR | Return / VaR_α | Discriminates irregular vs. repeated losses |
| Sharpe/CVaR | Return / CVaR_α | Sub-additive; accounts for tail severity |
| Sharpe/Cornish-Fisher VaR | Return / CF-VaR | Non-normal distribution correction |
| ASSR (Adjusted for Skewness) | Sharpe adjusted for skewness | Zakamouline-Koekebakker 2008 |
| ASKSR (Adjusted for Skew+Kurt) | Sharpe adjusted for 3rd+4th moments | Full higher-moment adjustment |
| Rachev Ratio | CVaR(−R,α) / CVaR(R,β) | Ratio of upper to lower tail CVaR |

**Category 3.2: Systematic Risk Ratios**

| Measure | Formula | Key Property |
|---------|---------|--------------|
| Treynor Ratio | (R_p - r_f) / β_p | Uses systematic risk only; requires good benchmark |
| Jensen's Alpha | R_p - [r_f + β(R_m - r_f)] | CAPM-relative alpha; can be manipulated by leverage |
| Appraisal Ratio | Jensen Alpha / Residual Std Dev | Alpha per unit of idiosyncratic risk |
| Information Ratio | (R_p - R_b) / TE | Active return per unit of tracking error |

**Category 3.3: Market Timing Measures**

| Measure | Formula | Key Property |
|---------|---------|--------------|
| Treynor-Mazuy | R_p = α + β·R_m + γ·R_m² + ε | γ > 0 = positive market timing |
| Henriksson-Merton | R_p = α + β₁·R_m + β₂·max(0,-R_m) + ε | Option-replication approach |

## Application to Korean Factor Strategy

**Which metrics to add to `summarise_perf()` function:**

**Current `summarise_perf()` likely includes:** Sharpe ratio, annualized return, annualized volatility, max drawdown, Calmar ratio, Information ratio vs. IKS200, Jensen's alpha.

**Priority additions from P207 taxonomy:**

**Tier 1 — Must Add (directly relevant for concentrated factor strategy):**

1. **Sortino Ratio** — Essential for strategies with asymmetric return profiles (factor strategies have positive skew from quality/momentum but fat left tails during reversals)
   ```r
   sortino <- function(returns, rf=0, target=0) {
     excess <- returns - target
     downside_var <- mean(pmin(excess, 0)^2)
     mean(returns - rf) / sqrt(downside_var) * sqrt(12)
   }
   ```

2. **Omega Ratio** — Incorporates all higher moments without parametric assumptions; captures the full return distribution which is non-Gaussian for Korean factor strategies
   ```r
   omega <- function(returns, threshold=0) {
     sum(pmax(returns - threshold, 0)) / sum(pmax(threshold - returns, 0))
   }
   ```

3. **Calmar Ratio** (3-year rolling) — Already standard but ensure using 3-year rolling window, not full sample; Korean strategies need cycle-aware drawdown measurement

4. **CVaR (Conditional Value at Risk) at 5%** — Sub-additive risk measure, better than VaR for tail risk; particularly relevant for Korean factor strategies where tail events (COVID-2020, 2008 GFC) are episodic but severe
   ```r
   cvar_5pct <- function(returns) {
     threshold <- quantile(returns, 0.05)
     mean(returns[returns <= threshold])
   }
   ```

5. **Upside Potential Ratio (UPR)** — Measures ability to capture upside while controlling downside; highly relevant for our regime-conditional strategy that aims to participate in bull stages and protect in bear stages

6. **Information Ratio with rolling 12M window** — Static IR hides regime variation; rolling IR reveals whether strategy is consistent or episodic outperformer

**Tier 2 — Recommended Additions:**

7. **Burke Ratio** — More robust than Calmar/Sterling for concentrated portfolio with episodic drawdowns

8. **Ulcer Index** — Measures depth AND duration of drawdowns simultaneously; "ulcer" = pain from prolonged underwater periods, relevant for strategies that may have multi-year drawdown periods (as in 2018-2021 factor crash)

9. **Appraisal Ratio** (Jensen Alpha / Residual Std Dev) — Measures alpha per unit of idiosyncratic risk taken; critical for evaluating whether our concentrated 20-30 stock portfolio justifies its stock-specific risk

10. **MAD Ratio** — Returns/MAD; more robust than Sharpe for Korean market where a few extreme months (COVID, 2008) dominate standard deviation calculation

**Tier 3 — Situational (add for specific analyses):**

11. **Rachev Ratio** — Compares upper tail CVaR to lower tail CVaR; if > 1, strategy has positively skewed tail profile; check whether Korean factor strategies have positive or negative Rachev ratios
12. **ASSR / ASKSR** — Sharpe adjusted for skewness and kurtosis; use when reporting to investors who understand higher-moment statistics

**Recommended `summarise_perf()` extension in R:**
```r
summarise_perf_extended <- function(returns, benchmark_returns, rf=0.03/12) {
  # Existing metrics (assumed present)
  sharpe <- mean(returns - rf) / sd(returns) * sqrt(12)
  ann_ret <- prod(1 + returns)^(12/length(returns)) - 1
  ann_vol <- sd(returns) * sqrt(12)
  max_dd <- maxDrawdown(returns)  # PerformanceAnalytics
  ir <- mean(returns - benchmark_returns) / sd(returns - benchmark_returns) * sqrt(12)

  # Tier 1 new additions
  sortino_r <- SortinoRatio(returns, MAR=rf)  # PerformanceAnalytics
  omega_r <- Omega(returns, L=rf)             # PerformanceAnalytics
  cvar_5 <- CVaR(returns, p=0.05)             # PerformanceAnalytics
  calmar_r <- Return.annualized(returns) / abs(maxDrawdown(returns))
  upr <- UpsidePotentialRatio(returns, MAR=rf)  # PerformanceAnalytics

  # Tier 2 new additions
  burke_r <- BurkeRatio(returns)              # PerformanceAnalytics
  ulcer_r <- UlcerPerformanceIndex(returns)   # PerformanceAnalytics
  appraisal_r <- AppraisalRatio(returns, benchmark_returns)

  list(sharpe=sharpe, ann_ret=ann_ret, ann_vol=ann_vol, max_dd=max_dd, ir=ir,
       sortino=sortino_r, omega=omega_r, cvar_5pct=cvar_5, calmar=calmar_r,
       upr=upr, burke=burke_r, ulcer=ulcer_r, appraisal=appraisal_r)
}
```
