## Quality Score Formulas (Explicitly Stated in SSRN Draft)

### Profitability Score (Equation 2):
```
Profitability = z(z_GPOA + z_ROE + z_ROA + z_CFOA + z_GMAR + z_ACC)

GPOA = GP / AT  (gross profit / total assets, Novy-Marx)
ROE  = NI / BE  (net income / book equity)
ROA  = NI / AT  (net income / total assets)
CFOA = CFO / AT (cash flow from ops / total assets)
GMAR = GP / REV (gross margin)
ACC  = CFO / |NI|  (HIGH is GOOD — cash earnings fraction)
```

### Growth Score (Equation 3):
```
Growth = z(z_Δ5GPOA + z_Δ5ROE + z_Δ5ROA + z_Δ5CFOA + z_Δ5GMAR)
```
5-year changes in each profitability component.

### Safety Score (Equation 4):
```
Safety = z(-z_beta + z_lev + z_Oscore + z_Zscore + z_EVOL)

beta   = Frazzini-Pedersen beta (5yr correlation × 1yr volatility)
lev    = Total debt / Total assets (LOW leverage is SAFE)
Oscore = Ohlson (1980) O-score (LOW Oscore is SAFE)
Zscore = Altman (1968) Z-score (HIGH Zscore is SAFE)
EVOL   = 5-year rolling std dev of ROE (LOW EVOL is SAFE)
```

Note: The z-score construction is z(x) = (r_x - 0.5) / std(r_x) where r = rank(x)/N.

### Quality Score (Equation 5):
```
Quality = z(Profitability + Growth + Safety)
```

### QMJ Factor Construction (Equation 7):
```
QMJ = (1/2)(Small Quality + Big Quality) - (1/2)(Small Junk + Big Junk)
```
- Small/Big split at NYSE median market cap
- Quality/Junk split at 30th/70th percentiles within each size group
- Returns are value-weighted within each portfolio

## Korean Implementation Notes

See P135.md for the complete Korean implementation blueprint. The following supplements that:

**Working paper's explicit construction details for Korean adaptation:**

1. **z-score construction**: Use rank-based z-scores, NOT direct z-scores:
   ```r
   z_score <- function(x) {
     r <- rank(x, na.last="keep", ties.method="average")
     n <- sum(!is.na(x))
     (r - 0.5*n) / sd(r, na.rm=TRUE)
   }
   ```
   This is more robust to outliers than direct standardization.

2. **Accrual (ACC) sign**: ACC = CFO / |NI|. This is the **cash earnings fraction** — HIGH ACC = HIGH quality (unlike accruals in FF2008 sense where high accruals = bad). Be careful of sign convention.

3. **Safety beta**: Use Frazzini-Pedersen beta (5yr correlation × 1yr vol), NOT Dimson or rolling OLS.
   ```r
   # Korean beta using Frazzini-Pedersen method
   beta_fp <- function(stock_ret, mkt_ret, n_corr=60, n_vol=12) {
     corr_60m <- cor(stock_ret[tail(seq_along(stock_ret), n_corr)],
                     mkt_ret[tail(seq_along(mkt_ret), n_corr)],
                     use="complete.obs")
     vol_stock_12m <- sd(stock_ret[tail(seq_along(stock_ret), n_vol)], na.rm=TRUE)
     vol_mkt_12m   <- sd(mkt_ret[tail(seq_along(mkt_ret), n_vol)], na.rm=TRUE)
     corr_60m * (vol_stock_12m / vol_mkt_12m)
   }
   ```

4. **Composite construction**: Sub-scores are SUMMED (not averaged) before final z-scoring:
   ```r
   Quality = z(Profitability + Growth + Safety)
   # NOT: z((Profitability + Growth + Safety) / 3)
   # The sum preserves covariance benefits; averaging reduces them
   ```
