# P060: The Association Between Market Determined and Accounting Determined Risk Measures (Beaver, Kettler, Scholes 1970)
**Category:** Factor_Return / Beta
**Feasibility:** medium
**Novelty vs existing (BAB failed, LowVol passing):** high

## Core Claim
시장 베타(market beta)는 7개의 회계 지표(accounting risk measures)로 상당 부분 설명된다. 특히 이익 변동성(earnings variability)과 이익 공변동성(earnings covariability = accounting beta)이 시장 베타와 가장 강하게 연관된다. 회계 베타는 시장 베타의 선행(forward-looking) 대리변수로 기능할 수 있다.

## Factor Definition
7개 회계 리스크 지표:
1. **Payout ratio** = 배당 / 순이익 (-)
2. **Asset growth** = 총자산 증가율 (+)
3. **Leverage** = 총부채 / 총자산 (+)
4. **Liquidity** = 유동자산 / 유동부채 (-)
5. **Asset size** = log(총자산) (-)
6. **Earnings variability** = 이익률의 표준편차 (+)
7. **Accounting beta** = 이익률 변화와 시장 평균 이익률 변화의 공분산 / 시장 분산 (+)

핵심 공식:
```
Accounting_Beta_i = Cov(ΔE_i/P_i, ΔE_m/P_m) / Var(ΔE_m/P_m)
```
- E = 주당이익, P = 주가, m = 시장 평균
- 분기 또는 연간 EPS 시계열에서 계산 가능

회귀 복합 지수 (Composite Risk Score):
```
CRS_i = w1*Payout + w2*Growth + w3*Leverage + w4*Liquidity + w5*Size + w6*EarnVar + w7*AccBeta
```
가중치는 시장 베타와의 Spearman 상관 기반으로 결정 (논문에서 상관계수 제시)

## Key Results
- 포트폴리오 수준에서 회계 베타 composite의 시장 베타와의 상관: 0.72~0.80
- 개별 종목 수준: 0.44~0.53
- **이익 변동성(Earnings Variability)**: 시장 베타와 상관 0.44 (단일 변수 중 최고)
- **Accounting Beta**: 상관 0.23 (단독으로는 중간), composite에서 중요 기여
- **Leverage**: 상관 0.23
- **Payout, Size**: 음의 상관 (고배당/대형주 = 저베타)
- 복합 지수는 단일 변수보다 우수한 시장 베타 예측력

- 이익 공변동성(accounting beta)은 시장 베타 예측에 사용 → 저회계베타 선별이 저시장베타 대리 가능
- 제약: DART 데이터 품질 (소형주 분기 이익 누락, 수정 잦음)

## Actionable Ideas
- **NEW IDEA A — Accounting Beta Factor**: DART 분기 EPS 시계열로 `Accounting_Beta = Cov(ΔE_i, ΔE_m) / Var(ΔE_m)` 계산. 저회계베타 + 저이익변동성 복합 스코어 → 저시장베타 대리 선별 팩터. LowVol의 가격 기반 베타 추정을 근본적(fundamental) 베타로 보완.
- **NEW IDEA B — Fundamental Beta Composite**: Leverage + EarnVar + AccBeta + Payout + Size 5개 회계 변수의 Z-score 합산 → FundamentalBeta Score. 이를 가격 기반 LowVol 팩터와 rank-combine → 더 안정적이고 포워드루킹한 저베타 포트폴리오.
- **실용 우선순위**: Idea A가 더 직접적. `fundamental_dart.parquet`에 분기 EPS 추가 후 rolling 8-quarter window로 accounting beta 계산.
