# Paper Note: P200 — Direction is More Important than Speed: Direction Prediction of S&P 500 Excess Returns (2025)

**Authors:** Tingting Cheng, Yitong Shang, Albert Bo Zhao
**Source:** SSRN Working Paper (2025) — Nankai University / Chinese University of Hong Kong
**Category:** Asset_Allocation
**Priority:** 2

## Core Thesis

Predicting the direction (sign) of S&P 500 excess returns is more valuable than predicting the magnitude (level). Using 26 predictors and ML models (GBDT, RF, NN, Logistic), direction prediction models achieve 61%+ accuracy and outperform value prediction models in terms of Certainty Equivalent Return (CER). The key insight: magnitude prediction errors are irrelevant for binary timing strategies, and direction classification handles the heavy tails and non-linearity of return distributions better than regression.

## Strategy Description

**26 Predictors (full list):**
- Valuation: logDP (log dividend-price), logDY (log dividend yield), logEP (log earnings-price), logDE (log dividend-earnings), BM (book-to-market)
- Risk: SVAR (stock variance), VOL (volatility), SKEW (skewness), KURT (kurtosis)
- Interest rates: TBL (T-bill rate), LTY (long-term yield), LTR (long-term return), TMS (term spread = LTY-TBL), DFY (default yield spread = BAA-AAA), DFR (default return spread)
- Macro: CPIG (CPI growth), PPIG (PPI growth), IPG (industrial production growth), lagI (lagged inflation)
- Technical: MA(1,12) (1 vs 12-month MA signal), MA(3,12), MOM(6) (6-month momentum sign), NTE (net equity expansion)

**Models Compared:**
- Regression (value prediction): OLS, PCA-OLS, Lasso, ElasticNet, GBDT, RF, NN, combinations
- Classification (direction prediction): Logistic, PCA-Logistic, Lasso-L, Enet-L, GBDT-C, RF-C, NN-C, combinations

**Training/Validation/Test Split:**
- Training: 1927-1956 (30 years)
- Validation: 1957-1966 (10 years) — for hyperparameter tuning
- Testing: 1967-2022 (56 years OOS)

**Best Direction Models (Test Period):**
| Model | Accuracy | F-stat |
|-------|----------|--------|
| Logistic | 57.2% | 11.4 |
| PCA-Logistic | 57.8% | 13.1 |
| GBDT-C | 61.01% | 29.96 |
| RF-C | 61.31% | 38.65 |
| Avg(nonlin/NN) | 61.61% | 35.67 |

**Key Predictors (variable importance):**
1. logDP (log dividend-price ratio) — most important
2. Lagged sign of return (momentum of direction)
3. TMS (term spread) — yield curve slope
4. DFY (default yield spread)
5. SVAR (stock variance / volatility clustering)

**Direction Strategy Construction:**
- Signal: classify S&P 500 excess return sign next month
- If predicted positive: long S&P 500
- If predicted negative: long T-bills (risk-free)
- Measure: Certainty Equivalent Return (CER) = mean - 0.5*gamma*variance

**Volatility Clustering Finding:**
- High volatility periods → more negative return signs → direction more predictable
- SVAR (stock variance) captures this: high SVAR → higher probability of negative sign

## Key Results

- Direction prediction significantly outperforms value prediction on CER basis
- Best model (Avg nonlin) achieves 61.61% direction accuracy — substantially above 50%
- Direction strategies deliver positive CER premium over buy-and-hold
- Volatility clustering is the primary source of direction predictability
- Magnitude prediction errors are irrelevant for binary strategies
- Ensemble of non-linear models (GBDT + RF + NN average) is most robust
- Term spread (TMS) and default spread (DFY) are the most actionable macro predictors
- Long historical validation (56-year OOS) provides strong evidence against data-snooping

## Implementation in Korean Market

**Connection to existing infrastructure:**
- `macro_fred.parquet` already contains: TBL, LTY, TMS equivalent (US data; Korean yield curve data needed separately)
- SVAR (stock variance) computable from `RAWDATA.parquet`: Korean daily returns → monthly variance
- Korean yield curve spread: BOK data or FRED IRLTLT01KRM156N (10Y Korean bond)

**Korean adaptation:**
- Predictors: Korea-specific versions of logDP (KOSPI dividend yield), YC slope (Korean 10Y-3M), SVAR (KOSPI monthly return variance), 6-month momentum sign
- Target: KOSPI monthly excess return direction
- Model: GBDT classification (R: `lightgbm` or `xgboost`)
- Training: 2001-2015, OOS: 2016-2026

**R Code Sketch:**
```r
# KOSPI direction prediction
library(lightgbm)

features <- rawdata_monthly %>%
  mutate(
    svar = rollapply(ret, 12, var, fill=NA),  # volatility clustering
    mom6 = sign(lag(ret, 1) + lag(ret, 2) + ... + lag(ret, 6)),
    tms = korean_10y - korean_3m,  # term spread
    dp_log = log(dividend / price),
    target = as.integer(lead(ret_excess) > 0)
  )

# GBDT classification
model <- lgb.train(params=list(objective="binary"), ...)
```

**Feasibility: MEDIUM** — ML models require more setup; but logDP + TMS alone (simpler) still meaningful
