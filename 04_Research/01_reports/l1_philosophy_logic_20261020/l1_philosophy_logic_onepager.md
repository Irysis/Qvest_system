# 1계층 리서치는 어떻게 투자철학에 맞춰 전략을 개선하나

2026-10-20 · Q · 내부 용어 없이 표준 퀀트 용어로 정리한 판

**한 줄**: 투자철학을 '목표로 하는 수익 곡선의 모양'으로 바꾸고, 새 방어 아이디어마다 "**그냥 베타를 낮추거나 현금을 섞어도 같은 효과가 나지 않았나?**"를 대조군으로 검증해, 그보다 나은 것만 채택한다.

## 1. 목표: 철학을 숫자로

- 철학: 시장이 크게 빠질 때 덜 잃어서 장기 복리를 키운다. 숫자로는 위기 downside capture(전략 낙폭 ÷ 시장 낙폭) ↓ · 강세장 upside capture ≥ 0.55 · 꾸준한 우상향(Calmar).
- 상승장을 55%만 따라가며 사이클마다 시장을 이기려면 (1 + 0.55U)(1 - dD) ≥ (1 + U)(1 - D) → 위기 낙폭을 시장의 약 60~70% 이하로 막아야 한다.
- 이상형: **좋은 종목 선택 모델의 수익 곡선은 그대로 두고 위기 낙폭만 줄인 곡선.** 시장 노출만 줄이면 상승장 수익도 같이 깎여 복리가 준다 - 오를 땐 따라가고 내릴 땐 덜 빠지는 비대칭이 필요하다.
- 지금의 병목: 전략 = 수익 엔진(종목 선택 모델) × 방어 장치 × 포트폴리오 구성. 지금까지의 변형 1,202개 중 목표 등급 통과 0(주로 Calmar 미달) - 딥러닝 종목 선택 모델은 알파가 뚜렷하지만(t 3.5~3.9) 최대낙폭이 시장 수준(53~55%)이다. **즉 병목은 방어다.**

## 2. 실험 방식: 사전등록

- 측정 전에 가설 · 기대 방향 · 반증 조건 · 최종 후보 선택 규칙을 문서로 고정해 git 에 커밋한다 → 결과를 본 뒤 규칙을 바꿀 수 없다.
- 개발에는 2022년까지만 쓰고, 2023년 이후(2024~25 · 2026 급락 포함)는 손대지 않는 표본 외 검증으로만 쓴다.

## 3. 핵심: '겉보기 방어'를 걸러낸다

| 겉보기 방어 | 걸러내는 방법 |
|---|---|
| 베타를 낮추거나 현금을 섞어 덜 빠짐 | 같은 베타로 맞춘 '엔진 + 현금' 혼합과 비교 - 깊은 위기 · 급락 위기 대다수에서 그보다 덜 빠져야 인정 |
| 대형주를 덜 들어서 덜 빠짐 | 종목 크기 분포 · 평균 노출이 같은 무작위 포트폴리오 200개 대비 분위 |
| 한두 번의 위기에서만 운 좋게 | 위기 대다수 + 깊은 위기(낙폭 중앙값 이상) 대다수에서 개선 - 중앙값 개선만으론 불인정 |
| 방어하느라 수익 엔진을 망침 | 강세 구간 대다수에서 원래 엔진 upside capture 의 80% 이상 · 베타 조정 알파 유의한 감소 없음 |
| 오를 때 덜 오르고 내릴 땐 같이 내림 | 하락장 베타 < 상승장 베타일 때만 베타 축소를 방어로 인정 |
| 얕지만 회복이 느림 · 한 종목 쏠림 | 위기별 회복 기간 비교 · 깊은 위기에서 한 종목이 -10% 넘게 깎으면 탈락 |

방어의 출처도 나눠 기록한다(종목 선택 / 현금 전환 시점 / 종목 크기 / 시장 노출). 뒤의 둘은 실력으로 치지 않는다.

## 4. 위기 때 현금을 늘리는 '시점 선택' 방어 (10-17 ~ 10-18 보완)

- **인정 조건 셋**: ① 같은 베타의 현금 혼합보다 깊은 위기 대다수 **그리고** 급락 위기 대다수에서 덜 빠짐 ② 서로 다른 수익 엔진 2개에서 재현 ③ 완만한 약세장에서의 개선이 신호를 한 달 늦게 적용해도 유지.
- 급락형 위기는 현금 전환 · 종목 선택 방어 모두 판정하고 무엇 덕분인지 기록한다. 한 달 지연 테스트는 완만한 약세장에서만 필수 - 급락형은 월간 신호로 원리상 늦을 수 있어 '실행 지연에 민감' 표시만 한다.
- 위기 바닥 뒤 3 · 6개월의 주식 비중을 기록한다(현금 전환의 가장 큰 위험 = 반등을 놓치는 것). 판정 기준은 문헌 근거로 따로 정한다.
- 위기 수는 Lunde-Timmermann(2004) 약세장 정의로 센다(2008년의 연속 하락은 두 건).
- 결과는 증거 기록에 남고, 세 조건을 모두 채워야 등급 상향이 가능하다. **아직 충족 사례는 0.**

## 5. 등급 · 감독 · 지금까지

- 종합점수 = Calmar 와 포트폴리오 알파 t값의 6:4 가중 기하평균. A 등급 최소 조건 = CAGR ≥ 16% · Calmar ≥ 같은 기간 KOSPI200 · Sharpe ≥ 0.8 · 알파 t ≥ 2.0 · 표본 외 기간 성적. 진짜 위기 방어(종목 선택, 또는 증거를 갖춘 시점 선택)면 한 단계 상향, 위기 방어가 약하면 한 단계 하향 · A 불가.
- 위기마다 이긴 장치를 골라 이어 붙이지 않는다(사후 선택 금지). 투자철학 검토 에이전트가 설계 · 판정 직후 · 최종 후보 단계마다 의견을 내고(거부권 없음), 통과 부품만 조립 → A 등급 → 미래참조 검증 → 모의 운용 등록(도훈 승인).
- 지금까지: 포트폴리오 구성 5종 · 위기 현금 전환 7종 · 방어주 틸트 4종 모두 낙폭은 줄였지만, 깊은 위기에서 '같은 베타 현금 혼합'을 이긴 것이 없다 → **결국 베타를 낮춘 효과였다.** 다음: 수익 분포(하방 꼬리)를 직접 예측하는 모델 · 위기 시작 전 정보로 위기 유형 구분 · 딥러닝이 아닌 새 수익 엔진.
