# 1계층 리서치 — 투자철학에 맞춰 전략을 개선하는 핵심 로직

2026-10-20 · Q · 정본: 투자철학 헌장 · research-program SKILL · 등급 v3.2

**한 줄** — 철학을 '곡선의 모양'으로 번역하고, 라운드마다 그 모양에 다가갔는지를 "**같은 효과를 싸게 내는 대체물(현금 · β 축소 · 크기)을 이겼는가**"로 판정해, 이긴 부품만 쌓는다.

```
라운드  사전등록 → 등록 커밋(결과 전 증명) → 측정 → 행동 카드(β 짝 · MC8) → 판정 → 철학 P2 → 교훈
        통과한 부품만 → P4 조립 → 등급 A → Judge(PIT) → BOOK(도훈 confirm)
```

## 1. 철학 → 목표 모양 → 병목

- 헌장: **남들 다 깨질 때 방어해 복리를 극대화한다** — 위기 하락 포착 ↓ · 강세 상승 포착 ≥ 0.55 · 꾸준한 우상향(Calmar).
- 두 숫자는 묶여 있다: `(1+0.55U)(1−dD) ≥ (1+U)(1−D)` → 위기 낙폭 ≤ 시장의 약 60~70%(예: +100% → −50% 사이클이면 d ≤ 0.71).
- 정답 모양(도훈 눈검사): **수익 엔진의 모양은 지키고 위기 낙폭만 막는다.** 노출만 줄이면 복리가 깎이는 '현금 기계' — 비대칭이 필요조건.
- 전략 = 수익 엔진(P1) × 방어(P2) × 구성(P3) → 조립(P4). 소급 1,202칸 중 S ≥ 1 은 0(구속 축 Calmar) → **지금 병목은 방어**.

## 2. 핵심 — '진짜 방어'만 센다

| 가짜 방어(싼 대체물) | 판정 장치 |
|---|---|
| 현금 · β 를 줄여 덜 빠짐 | **β 짝** — 같은 β 의 '엔진 + 현금' 사본을 깊은 위기 · 빠른 급락 과반에서 이겨야 방어 · β 방어는 하락장 β < 상승장 β 일 때만 |
| 초대형주를 덜 들어 덜 빠짐 | **MC8 짝** — 크기 분포 · 평균 노출이 같은 무작위 포트폴리오 200개 중 분위 |
| 한 위기에서만 운 좋게 | 위기별 과반 + 깊은 위기 과반(중앙값만 움직이면 방어 아님) |
| 방어하느라 엔진을 죽임 | 강세 구간 과반에서 상승 포착 ≥ 같은 엔진의 80% · β-통제 알파 비열등 |
| 얕지만 오래 잠김 · 한 종목 폭발 | 회복 거래일 꼬리표 · 깊은 위기 한 종목 기여 −10% 초과 시 제외 |

방어엔 출처 라벨(선택 / 타이밍 / 크기 / 노출)을 붙이고, 크기 · 노출 방어는 실력으로 쓰지 않는다.

## 3. 타이밍 방어(현금 늘리기) — 10-17 밤 ~ 10-18 갱신

- **자리(헌장 빈칸 9 · A′)**: 타이밍도 실력으로 인정 — 셋 모두: (a) 같은 β 현금 사본을 깊은 위기 과반 **그리고** 빠른 급락 과반에서 이김 (b) 독립 엔진 2개에서 확인 (c) 느린 약세 개선이 신호 한 달 지연(lag-1)에도 유지.
- **판정 범위(빈칸 10 · 11)**: 빠른 급락은 현금 층 · 보유 방어 모두 판정 · 귀속(타이밍 / 선택) 기록. lag-1 강건성은 느린 약세에서만 요구(무너지면 누출 조사 · 선택 보류) · 빠른 급락의 lag-1 붕괴 = '지연 민감' 꼬리표.
- **재진입(빈칸 12)**: 위기 바닥 뒤 3 · 6개월 반등 노출 기록 — 판정 문턱은 문헌 근거로 따로(그 전엔 회복 꼬리표).
- **셈 단위(빈칸 13 · 도훈 10-18)**: 과반 = Lunde-Timmermann 위기 수(같은 사건이 깊은 위기 · 빠른 급락 양쪽에 셈 · 2008-05~10 과 2008-11 은 따로). 상태 일화 단위는 기록만.
- **집행(등급 v3.2)**: 라운드 평가만 증거 등록부에 플래그 4개((a) 깊은 위기 · (a) 빠른 급락 · (b) · (c))를 쓰고, 모두 참이어야 '강함' 노치(단위 불일치 = 가점 없음). **현재 기록 0** — P2R03 (a) 충족 0/14.
