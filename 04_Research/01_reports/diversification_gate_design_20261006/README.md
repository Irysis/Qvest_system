# 기저 분산성 관문 — 강화 개시 기준에 '기존 전략과의 상관' 추가 (설계안 v0 · 2026-10-06)

> 도훈 요청(2026-10-06): "신규 논문 기반 전략 최초 백테스트하고 이 전략이 강화러너를 탈 가치가 있는지 판단하는 기준에서,
> 다른 전략과의 상관관계도 추가하고 싶은데" → "기준설계부터해서 알려줘".
> 상태: **역사 재생 완료(§11) · 레인 미배선.** 결정 항목(§8)은 도훈 승인 대상. ★재생이 §2-1 의 잣대(초과수익)를 기각했다 — 정본 척도 = 2요인 잔차(§11.1).

## 1. 문제

- 현행 강화 개시 관문은 사실상 하나다: 충실구현 기저 `PORT_t ≥ base_min_port_t(=0)` (`02_Infrastructure/ops/rf_replication_verify.R:478`).
  예외 = 롤링 구제(`recent_regime_rescued`) · 방어형 경로(음수 알파라도 하락월 초과가 있으면 2계층 풀 등재).
- 이 관문은 **기존에 이미 가진 것과 같은 전략인지**를 보지 않는다.
  - 복제본도 강화 4~5시간을 그대로 쓴다.
  - 이 프로그램의 B급 전략은 한 점(CAGR 15~17% · SR 0.6 · MDD 57~63% · β 0.8)으로 수렴하는 경향이 실측됐다
    (memory: lean-loop day1 13라운드 · DFA 아크 "남는 건 알파가 아니라 베타").
- 반대로 단독 알파가 약해도 **기존 풀과 겹치지 않는** 전략은 2계층(국면 배합 · 전천후)의 재료로 가치가 있는데,
  현행 관문은 이를 알파 하나로만 거른다.

## 2. 원칙

1. **원수익 상관은 쓰지 않는다.** 롱온리 25종 전략끼리는 시장 베타 때문에 수익 상관이 0.8~0.9로 다 비슷하다(판별력 0).
   판정은 **벤치(KOSPI200) 대비 월간 초과수익**의 상관으로 한다.
2. **필터가 아니라 분기다.** 관문을 하나 더 얹어 버리는 쪽으로 쓰면 과거 사고를 되풀이한다
   (memory: 음수 알파 게이트가 방어형 11/14 를 버렸다 · 기저 관문이 최고 계보를 죽일 뻔했다).
   중복은 "버림"이 아니라 "뒤로", 독창은 "앞으로"다.
3. **문턱은 데이터에서 보정한다.** 기존 풀의 분포(분위수)에서 정한다 — 하드코딩 금지(CLAUDE.md 절대 규칙).
4. **판정 경로와 전략 경로를 분리한다.** 전 기간 상관은 *연구 자원 배분*(무엇을 강화할지) 통계라 전략의 PIT 위반이 아니다.
   단 이 값이 셀 엔진·보유 결정으로 흘러 들어가면 C1(전 표본 통계 선정)이 된다 → 출력은 요청·원장 메타에만 쓴다.

## 5. 지표

| 지표 | 정의 | 용도 |
|---|---|---|
| ρ_max | 후보 월간 초과수익과 풀 대표들의 상관 중 최대(공통 구간 ≥ 60개월) + 그 이웃 id | **판정** |
| R²_span | 후보 초과수익을 상관 상위 5개 대표로 회귀한 R² (두 전략의 섞음인 복제도 잡는다) | **판정**(ρ_max 와 OR) |
| J | 이웃과의 월별 보유 종목 Jaccard 평균 | 설명(왜 겹치나) |
| ρ_down | 풀 대표 평균이 하락한 달만의 상관 | 분산 재료 경로 판정 |

공통 구간 < 60개월이면 `판정 불능` → 현행 처분 그대로(조용히 통과시키지 않고 사유를 남긴다).

## 6. 문턱(보정)

- 풀 구성원 각각에 같은 지표를 **자기 계보 제외**로 계산 → 기존 계보들의 최근접 ρ·R² 분포.
- τ_dup = 그 분포의 상위 10% 경계(기존 계보 90%보다 더 이웃과 닮았다 = 중복).
- τ_div = 하위 25% 경계(기존 계보 75%보다 더 독자적 = 독창).
- 값·풀 스냅샷 날짜·계산 근거를 설정 파일에 기록하고 주 1회(또는 풀 변화 시) 재보정. 분위 자체(10%·25%)는 §8 결정 대상.

## 7. 판정 행렬

| | 기저 알파 ≥ 문턱(현행 0) | 기저 알파 < 문턱 |
|---|---|---|
| **독창** (ρ_max < τ_div ∧ R²_span 낮음) | 강화 **개시**(정상 우선순위 — 중복이 뒤로 가므로 상대적으로 앞) | 강화 미개시. **분산 재료 후보**: ρ_down 낮음 ∧ (방어형 ∨ 롤링 통과) 이면 2계층 풀 등재(신규 경로 `diversifier`) |
| **보통** | 현행대로 개시 | 현행대로(방어형 경로 판정) |
| **중복** (ρ_max ≥ τ_dup ∨ R²_span ≥ τ_dup) | 이웃 **기저** PORT_t 를 넘으면 개시(개선된 복제), 못 넘으면 `idle_only` 우선순위로 개설(큐가 빌 때만 돈다 — 버리지 않음) | 현행대로 미개시(중복 + 음수 = 새 정보 없음) |

- 비교는 **기저 대 기저**다 — 이웃의 강화 최고 칸과 비교하면 사과와 배다(memory: 결합 프롬프트 '단독 t' 는 강화 최고 시도지 기저가 아니다).
- `idle_only` 는 이미 있는 비차단 우선순위(반사실 레인과 같은 칸) — 새 우선순위 등급을 만들지 않는다.
- 구제(롤링)·방어형 경로는 그대로 두고, 이 관문은 그 위에 **순서**만 더한다.

### 11.4 분산 재료(diversifier) 경로

- 판정 후보(e2): 2301.09173(F · 생성 α t 1.97) · 2006.04639 재측정(F · t 0.37) — 둘 다 시장중립 롱숏 기저.

  생성 α t ≥ 2(Huberman-Kandel 생성 검정 5%)로 올리면 잡음 통과 3.5~5% · 역사 후보는 0건.

### 11.5 권고 (Q)

1. **'중복 → 강화 미실행' 처분은 켜지 않는다.** 재생에서 유일한 발동이 최고 계보의 뿌리였고, 닮음이 생산성과 무관하다.
2. 관문은 **정보로 상시 기록**한다(그림자 모드를 끝내지 않는 형태): 원장 메타·텔레그램에 "가장 닮은 기존 전략 X · ρ · R² · 최근 60개월 ρ". 판단은 도훈.
3. 처분을 꼭 붙이려면 n=1 에 맞춘 규칙이 되지 않도록 **새 증거로** 정한다 — 후보: 전기간 ∧ 최근 60개월이 모두 중복일 때만(1403.8125 는 최근 0.25 라 통과).
4. diversifier 는 **생성 α t ≥ 2** 로 강화하거나 보류. 2계층 소비는 as-of 재계산 필수(§PIT 주석).
5. 척도 = 2요인 잔차(e2) · 풀 = 표식 포함판(C1 표식은 A 자격 문제지 '이미 가진 전략' 여부와 별개 — 제외판은 22632 를 자를 만큼 공격적).
