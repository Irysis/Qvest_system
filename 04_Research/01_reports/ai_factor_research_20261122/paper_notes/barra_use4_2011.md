## 1. 추정 유니버스 · 팩터 구조 · 수익 식

### 1.1 모형 개요(p3)
- USE4 의 새 요소(원문 나열 순): ① Eigenfactor Risk Adjustment(최적화 포트폴리오 위험 과소예측 교정) ② Volatility Regime Adjustment(팩터 변동성과 고유 위험을 현재 시장 수준에 맞춤) ③ 국가(Country) 팩터 도입 ④ 일간 종목 고유수익 기반의 새 고유 위험 모형 ⑤ 고유 위험의 베이즈 조정 ⑥ 팩터 · 고유 성분의 반응성 통일 ⑦ GICS 기반 복수 업종 노출 ⑧ 이중 맹검 개발로 생산 코드 독립 검증 ⑨ 모든 구성요소 **일간 갱신**.
- 판별: **USE4S**(단기 · 월 예측 지평에서 가장 정확하도록 반응적) / **USE4L**(장기 · 정확도 일부를 안정성과 교환). **두 판은 팩터 노출 · 팩터 수익이 같고, 팩터 공분산과 고유 위험 예측만 다르다.**
- **예측 지평 = 1개월**(p18). 팩터 상관 · 변동성은 **일간** 팩터 수익으로 추정.

### 1.2 일반 팩터 모형(p6)
- (1.1) r_n = sum_k X_nk f_k + u_n
- (1.2) R_P = sum_n w_n r_n
- (1.3) X_k^P = sum_n w_n X_nk
- (1.4) R_P = sum_k X_k^P f_k + sum_n w_n u_n
- 가정: (a) 팩터 수익과 고유수익 무상관 (b) 고유수익끼리 무상관.
- (1.5) var(R_P) = sum_kl X_k^P F_kl X_l^P + sum_n w_n^2 var(u_n)   (F_kl = 팩터 k,l 예측 공분산)
- 예: 팩터 60개면 팩터 공분산 독립 원소 2천 개 미만. 2000 종목 직접 공분산은 2백만 개 초과(p6).

### 1.3 USE4 수익 식(p13, 식 3.1)
- (3.1) r_n = f_c + sum_i X_ni f_i + sum_s X_ns f_s + u_n
  - r_n = **현지 초과수익**(local excess return · 무위험 대비), f_c = 국가 팩터 수익(모든 종목 노출 1), f_i = 업종 팩터 수익, f_s = 스타일 팩터 수익, u_n = 고유수익.
- 국가 노출 ≠ 시장 노출. 시장 민감도는 Beta 스타일 팩터가 잡는다. Beta 팩터는 국가 팩터와 **시계열로** 높은 상관(횡단면 아님) → 위험 분석 때 둘을 함께 본다(p13).
- (3.2) sum_i X_ni = 1 (모든 n) → 국가 팩터와 정확한 공선성 → 제약 필요.

### 1.4 팩터 수
- 업종 팩터 **60개**(p17 그림 3.2 설명: "60 industry factors", 업종 쌍 1770개 = 60·59/2).
- 스타일 팩터 수 · 목록: **원문에 없음**(이 문서). 그림 4.1·4.3·4.4 의 가로축(고유팩터 번호)이 약 73~74까지 찍혀 있어 K ≈ 73(?) = 국가 1 + 업종 60 + 스타일 약 12(?)로 추정되나 본문 서술 없음.

### 1.5 추정 유니버스
- 정의(종목 선정 규칙 · 크기 · 유동성 기준): **원문에 없음**. 원문은 "estimation universe"를 쓰기만 하고 구성 규칙을 적지 않는다. 자료는 MSCI Global Investable Market Indices 와 같은 자료 기반에서 가져온다(p8).
- 표준화의 평균(시가총액 가중)은 추정 유니버스 안에서 계산(p9).

### 1.6 팩터 구조의 품질 기준(p7~8)
- **팩터 안정성 계수**(2.1): rho_kt = sum_n v_n^t (X_nk^t − Xbar_k^t)(X_nk^{t+1} − Xbar_k^{t+1}) / [ sqrt(sum_n v_n^t (X_nk^t − Xbar_k^t)^2) · sqrt(sum_n v_n^t (X_nk^{t+1} − Xbar_k^{t+1})^2) ]
  - v_n^t = 시점 t 의 회귀 가중. 한 달 → 다음 달 노출의 횡단면 상관(가중).
  - 경험칙: **0.90 초과 = 바람직 · 0.80 미만 = 모형에 넣기엔 너무 불안정.**
  - Xbar 가 가중 평균인지 단순 평균인지: 원문에 명시 없음(?).
- **공선성 VIF**: (2.2) X_nk = sum_{k'≠k} X_nk' b_k' + e_nk  → (2.3) VIF_k = 1 / (1 − R_k^2). 큰 VIF = 과도한 공선성. 임계값 수치: 원문에 없음.
- 직교화(orthogonalization)는 공선성을 줄이고 해석을 쉽게 하는 팩터 회전(Menchero 2010). 예: **직교화 뒤 비선형 규모(Non-Linear Size)는 사실상 중형주와 전체 시장의 수익 차이를 잡는다**(p8). 구체 절차는 원문에 없음.
- 그 밖 기준: 간결성(parsimony) · 통계적 유의성이 기간에 걸쳐 지속 · 직관성(가치 · 성장 지수는 해당 팩터에 양의 노출).

## 2. 스타일 팩터 만들기

### 2.1 자료 품질과 이상치(p8)
- 원자료(raw descriptor · GICS · 국가 분류 · 일간 수익)는 MSCI 지수 자료 기반에서 품질 관리된 것을 사용.
- **다단계 이상치 알고리즘**: 관측을 세 무리로 나눈다.
  1. 너무 극단적이라 자료 오류 후보로 보고 **추정에서 제거**.
  2. 정당한 값이지만 너무 커서 영향 제한 → **평균에서 3 표준편차로 절단(trim)**.
  3. 평균에서 3 표준편차 미만 → 그대로 둠.
- 1번 무리를 가르는 경계 수치(예: 몇 표준편차 초과면 제거)는 **원문에 없음**. 평균 · 표준편차가 무엇 가중인지도 이 절엔 없음(?).

### 2.2 결측 처리(p8~9)
- 결측 원인: 자료 없음 또는 이상치 제거.
- **자료 대체 알고리즘**: 결측 아닌 노출을 "팩터의 부분집합"에 회귀하고, 그 기울기로 결측 종목의 노출을 추정. 직관 = 업종 소속 · 시가총액이 비슷한 종목은 노출이 비슷. 어떤 부분집합(어느 팩터들)인지 · 회귀 가중: **원문에 없음**(예시로 업종 · 시가총액만 언급).
- **팩터 단위로 적용(지표 단위 아님)**: 한 스타일 안의 지표 일부만 있으면 있는 지표로 노출 계산. 지표가 **전부** 없을 때만 대체 알고리즘 작동.

### 2.3 표준화와 합성(p9)
- (2.4) d_nl = (d_nl^Raw − mu_l) / sigma_l
  - **mu_l = 추정 유니버스 안 시가총액 가중 평균**(잘 분산된 시총가중 포트폴리오의 스타일 노출 ≈ 0 이 되도록).
  - **sigma_l = 동일가중 표준편차**(대형주가 노출 척도를 좌우하지 않도록).
- (2.5) X_nk = sum_{l∈k} w_l d_nl   (w_l = 지표 가중, 그 스타일의 지표들에 대해 합)
  - **지표 가중 w_l 은 모형 설명력을 최대화하는 최적화 알고리즘으로 정함**. 실제 값 · 최적화 방식: 원문에 없음.
- 마지막 단계: 합성 노출을 **다시 표준화**(시가총액 가중 평균 0 · 동일가중 표준편차 1).
- 결측 지표가 있을 때 가중을 재정규화하는지: 원문에 명시 없음(있는 지표로 계산한다는 서술만).

### 2.4 직교화
- 일반 원칙과 비선형 규모 예시(1.6절)만 있음. **무엇을 무엇에 직교화하는지(예: 잔차 변동성을 베타 · 규모에, 비선형 규모를 규모에) · 회귀 가중 · 순서: 원문에 없음.**

## 3. 업종 팩터와 복수 업종 노출(p9~12)

### 3.1 업종 선택 기준(p10)
- GICS 계층의 한 수준만 쓰지 않고 섹터마다 다른 수준으로 내려가 시장 특성에 맞춘 맞춤 구조.
- 기준: (a) 경제적 직관 (b) 강한 통계적 유의성 (c) 추가 시 설명력 유의 증가 (d) 종목 수 적은(thin) 업종 회피. 최소 종목 수 등 수치: 원문에 없음. USE4 업종 60개의 목록: 원문에 없음.

### 3.2 복수 업종 노출(p10)
- 각 업종 안에서 시가총액을 보고 자산(Assets)에 회귀:
  - (2.6) M_n = sum_k beta_k^A A_nk + e_n   (M_n = 시가총액, A_nk = 업종 k 부문 자산, beta_k^A = 업종 베타 = 업종 주가/자산 비율)
  - (2.7) X_nk^A = beta_k^A A_nk / sum_k beta_k^A A_nk   (합 = 1)
- 매출(Sales)로 같은 방식 X_nk^S.
- (2.8) **X_nk = 0.75 · X_nk^A + 0.25 · X_nk^S**
- **최대 5개 업종**. 부문이 5개 초과면 상위 5개를 취하고 합 1로 재정규화.
- 부문 자료(NAICS)를 GICS 로 매핑 — NAICS 는 GICS 의 약 10배 부문 수(p11).
- 회귀 가중 · 절편 유무 · 주기: 원문에 없음(식 2.6 엔 절편 없음).

## 4. 횡단면 회귀(p13~16)

- **방법: 가중최소제곱(WLS)**. 가정 = 고유수익 분산이 **총 시가총액의 제곱근에 반비례** → **회귀 가중 = sqrt(시가총액)**.
- **주기: 일간**(5.1절 "daily cross-sectional regressions"; 모형 전 구성요소 일간 갱신 p3). 월간 회귀는 이 문서에 없음.
- 종속변수: 현지 초과수익(무위험 대비).
- **업종 제약**(3.3): sum_i w_i f_i = 0, w_i = 추정 유니버스의 업종 i **시가총액 비중**. 제약 선택은 적합도 · 설명력에 영향 없고 해석만 바꾼다.
- 해석(3.4~3.5): 시총가중 추정 유니버스 수익 R^E = f_c + sum_i w_i f_i + sum_s X_s^E f_s + sum_n h_n^E u_n. 업종 합 = 0(제약), 스타일 항 = 0(시총가중 평균 0 표준화), 고유항 ≈ 0 → **R^E ≈ f_c**. 국가 팩터 ≈ 시총가중 추정 유니버스. 그림 3.1: 시계열 상관 약 **99.9%**.
- 업종 팩터 = 해당 업종 100% 매수 · 국가 팩터 100% 매도의 달러 중립 포트폴리오(스타일 노출 0). 스타일 팩터 = 해당 스타일 단위 노출, 다른 모든 팩터 노출 0, 각 업종 순비중 0인 달러 중립 포트폴리오.
- 전통 모형(국가 팩터 없음)(3.6): r_n = sum_i X_ni f~_i + sum_s X_ns f_s + u_n. 관계 (3.7) f~_i = f_c + f_i.
- (3.8) 국가 팩터가 있는 모형에서 순매수 업종 i,j 상관:
  rho~_ij = (sigma_c^2 + rho_ci sigma_c sigma_i + rho_cj sigma_c sigma_j + rho_ij sigma_i sigma_j) / (sigma~_i sigma~_j)
  국가 변동성이 짧은 변동성 반감기로 추정되므로 업종 상관이 더 빨리 반응.
- 국가 팩터 포함 시 업종쌍 포트폴리오(f~_i − f~_j)의 MRAD 가 평균 약 **80bp** 감소(1995-06-30 ~ 2011-05-31, p17).
- **이상치 처리 · 회귀 안의 수익 절단**: 2.2절의 일반 이상치 알고리즘 외 회귀 수익 자체에 대한 별도 규칙은 **원문에 없음**.
- 제약 회귀의 구현(제약 행렬 R, 해 공식): 원문에 없음.

## 5. 팩터 공분산(p17~27 · 부록 B p40~42)

### 5.1 기본 추정(4.1절)
절차:
1. **상관 행렬**: 일간 팩터 수익의 지수가중 평균, 상관 반감기 tau_rho^F. 유효 관측 수 T 가 팩터 수 K 보다 충분히 커야 행렬 조건수가 좋다.
2. **Newey–West** 시차 L_rho^F 로 계열 상관 반영(예: L=2 → 두 거래일 안에서 어느 팩터든 다른 팩터와 상관 가능).
3. 결측 팩터 수익(예: 늦게 생긴 업종 팩터)은 **EM 알고리즘(Dempster 1977)** 으로 상관 추정(반복 · 양반정치 보장).
4. **변동성**: 지수가중, 변동성 반감기 tau_sigma^F, Newey–West 시차 L_sigma^F.
5. (4.1) F0_ij = rho_ij · sigma_i · sigma_j
- 변동성 반감기는 상관 반감기보다 훨씬 짧게 둘 수 있다(대각 오차는 조건수에 거의 영향 없음). 너무 짧으면 덜 안정적이고 덜 정확.
- Newey–West 의 구체 식(바틀렛 가중 등) · 지수 가중의 정규화: 원문에 없음.
- **일간 → 월간 변환 방법**(예: ×21 거래일): **원문에 없음**. 지평이 1개월이고 NW 로 일간 계열상관을 반영한다는 서술뿐.

### 5.2 표 4.1(p19) — 팩터 공분산 매개변수 (단위: 거래일)

### 5.3 고유팩터 위험 조정(Eigenfactor Risk Adjustment · 4.2절 · 부록 B)
- 배경(4.2): Shepard(2009) 정규 · 정상 · 큰 N 가정에서 (4.2) sigma_true ≈ sigma_pred / (1 − K/T)  (쪽 그림으로 확인; K = 팩터 수, T = 공분산 계산의 유효 관측 수). 원인 = 추정 오차로 표본 안 좋은 헤지가 표본 밖에서 덜 헤지.
- 고유팩터 = 팩터 공분산의 고유벡터(단위 노름) = 서로 무상관인 순수 팩터 포트폴리오. 저변동 고유팩터일수록 과소예측(그림 4.1: 최저 변동 고유팩터 실현 변동성이 예측보다 약 **40%** 높음).

부록 B 절차(매일 수행):
- (B1) F0 = cov(f, f'), f = K×T 실현 팩터 수익(4.1절 추정기).
- (B2) D0 = U0' F0 U0  (U0 열 = F0 고유벡터; U0 의 k열 j원소 = 고유팩터 k 의 순수 팩터 j 비중; D0 대각 = 고유분산)
- (B3) 모의 m: f_m = U0 b_m, b_m 은 K×T, k행은 평균 0 · 분산 D0(k) 정규 난수. (참 공분산 = F0.) 본문 p21: 콜레스키 분해 등으로 F0 정규분포에서 수익 이력 모의.
- (B4) F_m = cov(f_m, f_m')  — **F0 과 같은 추정기**(같은 반감기 · NW 등으로 해석(?), 원문: "uses the same covariance estimator").
- (B5) D_m = U_m' F_m U_m
- (B6) D~_m = U_m' F0 U_m  (모의 고유팩터의 참 공분산 · 대각만 씀)
- (B7) **모의 변동성 편향** v(k) = sqrt( (1/M) · sum_m D~_m(k) / D_m(k) ),  M = 모의 횟수. 매일 계산.
- (B8) 배율판(scaled): ① v(k) 를 매일 **포물선**으로 적합, 적합 때 **처음 15개 고유팩터 가중 0**(그림 4.3 왼쪽 톱니 제거) ② v_S(k) = a · [v_P(k) − 1] + 1, **a = 1.4**(경험 상수).
- (B9) D~0 = v^2 · D0   (v^2 = 원소 v(k)^2 의 대각 행렬)
- (B10) F~0 = U0 · D~0 · U0'   (고유조정 팩터 공분산)
- **USE4 생산판은 배율판(B8)이 아니라 더 온화한 모의판(B7)을 그대로 쓴다**(p23 · p41): 배율판은 순수 팩터 단위(특히 변동성 가장 작은 스타일 팩터)를 약간 위로 편향시키므로. 모의판으로도 최적화 포트폴리오 편향이 크게 줄고 스타일 팩터 편향 통계는 대부분 95% 신뢰구간 안.
- **모의 횟수 M 의 값 · 모의 이력 길이 T 의 값: 원문에 없음.** 고유값 정렬 순서는 그림에서 "저변동 → 고변동"(p20).
- VRA 와의 적용 순서(고유조정 → VRA 인지): 명시 없음. 다만 VRA 는 행렬 전체에 단일 스칼라 lambda_F^2 를 곱하므로(4.5) 순서가 바뀌어도 결과 동일.
- 검증 실험(p20): 팩터 단위 무작위 알파 100개(표준정규), 시간 불변, 매월 초 추정 유니버스 시총가중 알파가 0 이 되게 중심화, alpha = 1 제약(알파 노출 1) 하 최소위험 팩터 포트폴리오를 매월 구성.

### 5.4 변동성 국면 조정(VRA · 4.3절)
- 표준화 수익 f_kt / sigma_kt (sigma_kt = 그날 시작 시점의 1일 변동성 예측).
- (4.3) **팩터 횡단면 편향 통계** B_t^F = sqrt( (1/K) · sum_k (f_kt / sigma_kt)^2 ). 예측이 작으면 B_t^F > 1. (동일가중 · 평균 차감 없음.)
- (4.4) **팩터 변동성 배수** lambda_F = sqrt( sum_t (B_t^F)^2 · w_t ), w_t = 반감기 tau_VRA^F 의 지수 가중(합 1 정규화로 해석(?) — 원문 명시 없음).
- (4.5) sigma~_k = lambda_F · sigma_k  ⇔ 팩터 공분산 전체에 lambda_F^2 곱. 상관 불변.
- (4.6) 팩터 CSV_t^F = sqrt( (1/K) · sum_k f_kt^2 )  (진단용).
- tau_VRA^F = 42(S) / 168(L) 거래일(표 4.1). "팩터 위험 반응성의 주된 결정자".
- sigma_kt 가 VRA 이전 예측인지(고유조정 포함 여부) 명시 없음(?).

## 6. 종목 고유 위험(5장 · p28~34)

### 6.1 시계열 추정(5.1)
- (5.1) 일간 횡단면 회귀 r_nt = sum_k X_nk f_kt + u_nt 의 잔차 u_nt.
- (5.2) sigma_n^TS = C_n^NW · [ sum_t w_t (u_nt − ubar_n)^2 ]
  - 쪽 그림으로 확인한 표기 그대로: 대괄호에 제곱근이 **인쇄돼 있지 않다**(변동성이면 sqrt 가 있어야 자연스러움 — 원문 표기 누락 (?) · 구현 때는 분산 → 제곱근으로 해석 권장).
  - w_t = 고유 변동성 반감기 tau_sigma^S 지수 가중. C_n^NW = 종목별 Newey–West 계열상관 조정, **자기상관 반감기 tau_rho^S** 와 시차 L_rho^S 로 추정. C_n^NW 의 구체 식: 원문에 없음.

### 6.2 구조 모형과 혼합(5.1)
- **혼합 계수 gamma_n**: 결측 수익이 충분히 적고 고유수익 꼬리가 과도하게 두껍지 않으면 1, 둘 중 하나를 강하게 위반하면 0, 일반적으로 0~1. 대부분 종목 gamma_n = 1. **gamma 를 정하는 구체 식 · 문턱(결측 일수 · 꼬리 지표): 원문에 없음**(EUE3, Briner·Smith·Ward 2009 를 따름).
- (5.3) gamma_n = 1 인 종목만으로 매일 횡단면 회귀: ln(sigma_n^TS) = sum_k X_nk b_k + e_n  (회귀 변수 = 모형의 팩터 노출 전부 — 국가 · 업종 · 스타일; 회귀 가중: 원문에 없음)
- (5.4) sigma_n^STR = E0 · exp( sum_k X_nk b_k ),  E0 = 1 보다 **약간 큰 수**(잔차 지수화 편향 제거). 정확한 값 · 계산식: 원문에 없음(통상 E0 = 평균 exp(e_n) 꼴로 추정하나 원문엔 없음).
- (5.5) sigma^_n = gamma_n · sigma_n^TS + (1 − gamma_n) · sigma_n^STR

### 6.3 베이즈 축소(5.2)
- 문제: 극저 · 극고 고유 변동성 예측이 평균회귀 → 저변동 과소예측 · 고변동 과대예측(그림 5.1).
- **묶음 = 시가총액 규모 10분위(size decile) s_n**. 매월 분위 구성(그림 5.1 진단은 "every month"; 생산 갱신 주기 명시 없음(?)).
- (5.6) sigma_n^SH = v_n · sigmabar(s_n) + (1 − v_n) · sigma^_n
- (5.7) sigmabar(s_n) = sum_{n∈s_n} w_n · sigma^_n   (w_n = 그 규모 분위 안 시가총액 비중)
- (5.8) v_n = q · |sigma^_n − sigmabar(s_n)| / ( Delta_sigma(s_n) + q · |sigma^_n − sigmabar(s_n)| )
- (5.9) Delta_sigma(s_n) = sqrt( (1/N(s_n)) · sum_{n∈s_n} (sigma^_n − sigmabar(s_n))^2 )   (N(s_n) = 분위 종목 수; 동일가중)
- **q = 0.1**(표 5.1, S · L 동일).

### 6.4 고유 위험 VRA(5.3)
- sigma_nt = 식 5.6 의 1일 예측에서 **계열상관 조정을 뺀 것**(NW 제외).
