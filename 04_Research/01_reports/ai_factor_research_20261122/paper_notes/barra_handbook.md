## 1. 다중 팩터 모형(MFM)의 수식과 쓰는 이유 (1장 p15–26)

### 1.1 모형의 종류 (p15–16)
- 세 종류: 거시경제(관측 경제 변수) · 기본(fundamental — 배당수익률 · 장부/시가 · 업종 같은 관측 속성에 연결된 포트폴리오 수익) · 통계(수익 공분산의 요인 분석).
- Barra 주식 모형 = **기본 팩터 모형**. 설명력에서 거시 · 통계 모형보다 낫다고 적고 근거로 Connor(1995, FAJ "The Three Types of Factor Models")를 든다.

### 1.2 수식
| 식 | 원문 쪽 | 내용 |
|---|---|---|
| EQ 1-1 | p20 | r_i = x_i f + u_i (단일 팩터) — r_i = 무위험 이자율 위 초과수익, x_i = 팩터 민감도, f = 팩터 수익, u_i = 고유 수익. f 와 u 는 무상관, u 는 종목 간 무상관 |
| EQ 1-2 | p20 | r_j = x_1 f_1 + x_2 f_2 + … + x_K f_K + u_j (앞부분 = 공통 팩터 수익, u_j = 고유 수익) |
| EQ 1-3 | p21 | r_i = Σ_{k=1..K} x_ik f_k + u_i (?) — 그림 식은 확인 못 함 · 변수 설명(x_ik = 종목 i 의 팩터 k 노출, f_k = 팩터 k 수익, u_i = 고유 수익)과 EQ 3-11(p47, 판독함)이 같은 꼴 |
| EQ 1-4 | p22 | r_P = Σ_k x_Pk f_k + Σ_i h_Pi u_i, x_Pk = Σ_i h_Pi x_ik (포트폴리오 노출 = 비중 가중 합) |
| EQ 1-5 | p23 | V(i,j) = Covariance[r(i), r(j)] (종목 공분산 행렬) |
| EQ 1-6 | p23 | F(k,m) = Covariance[f(k), f(m)] (팩터 공분산 행렬) |
| EQ 1-7~1-9 | p25 | Risk = Var(r) = Var(Xf + u) = Var(Xf) + Var(u) |
| EQ 1-10 | p25 | **Risk = X F X^T + Δ** — X = n×k 노출, F = k×k 팩터 수익 공분산, Δ = 고유 분산 대각 행렬 |
| EQ 1-11 | p26 | **σ_p = sqrt( h_p (X F X^T + Δ) h_p^T )** — h_p = N 종목 비중 벡터 |

### 1.3 노출 · 팩터 수익의 시점 (p21 · p24)
- 주식 모형의 종목 노출은 **월 1회** 갱신: "마지막 거래일 정보로 다음 달의 노출을 계산"한다(채권은 대부분 일 단위).
- 노출은 **월초(=전월 말)에 알려진 값**, 수익은 **월말**에 관측 → 그 달 종목 수익을 월초 노출에 횡단면 회귀해 팩터 수익을 낸다(p21 · p24 Figure 1-3). [Q 주] PIT 관점에서 그대로 쓸 수 있는 시점 구조.
- 추정 유니버스(estimation universe) = 각 국내 시장의 '대표 종목 집합'. 매달 이 유니버스로 수익을 공통 팩터와 고유 수익으로 나눈다(p24).

### 1.4 표본 공분산 대신 쓰는 이유 (p17–19 · p22–23)
- 3,000 종목 공분산을 직접 추정하려면 최소 3,000 기간의 자료가 필요 — 월 · 주 단위로는 그런 이력이 없다.
- 추정 오차: 어떤 기간에는 업종이 다른 두 종목(Weyerhaeuser–Ford)이 같은 업종 두 종목(GM–Ford)보다 상관이 높게 나오는 식의 가짜 관계가 생긴다.
- 숫자: 1,400 종목 → 분산 · 공분산 **980,700개**(Figure 1-1). 미국 Multiple-Horizon 모형 68 팩터 → **2,346개**(Figure 1-2). 모수가 적을수록 가짜 관계를 찾을 확률이 낮다.
- 장점 목록(p16–17): 단일 팩터보다 위험 분해가 정밀 · 경제 논리로 만들어 과거 자료에만 묶이지 않음 · 이상치에 견디게 만들 수 있음 · 종목 특성 변화에 적응 · 팩터별 효과 분리 · 이해 쉬움. 한계: 위험의 전부가 아닌 대부분을 예측, 수익이 아니라 위험을 예측.

## 2. 모형 추정 절차 전체 흐름 (3장 p35–37)

### 2.1 단계 목록 (p35 옆단 "Model Estimation Process")
1. Data acquisition(자료 수집)
2. Descriptor selection and testing(지표 선택 · 시험)
3. Descriptor standardization(지표 표준화)
4. Risk index formulation(위험 지수 구성)
5. Industry allocation(업종 배정)
6. Factor return estimation(팩터 수익 추정)
   a. Covariance matrix calculation · b. Exponential weighting · c. Covariance matrix scaling: DEWIV and GARCH
7. Specific risk forecasting(고유 위험 예측)
   a. Average specific risk estimation · b. Relative specific risk estimation · c. Average and relative forecasting
8. Model updating(모형 갱신)

### 2.2 Figure 3-1 "Data Flow for Model Estimation" (p37)
- Phase I: Factor Exposures — Fundamental and Market Data →(Descriptor Formulas)→ Descriptors →(Risk Index Formulas)→ Risk Indices; Industry Allocations 가 합류 → Factor Loadings.
- Phase II: Factor Return Estimation — Asset Returns + Estimation Universe + Factor Loadings → **"Monthly Cross-Sectional Weighted Regressions"**.
- Phase III: Analysis — 회귀에서 Factor Returns → Covariance Matrix, Specific Returns → Specific Risk Forecast.

### 2.3 본문 요점 (p35–36)
- 시장 자료(가격 · 거래량 · 배당수익률 · 시가총액)와 재무 자료(이익 · 매출 · 업종 · 총자산)를 쓴다. 자본 재구성 등 이례적 사건은 시점 간 일관 비교가 되도록 특별히 다룬다.
- 위험 지수에 지표를 묶는 도구의 예로 **군집 분석(cluster analysis)**을 든다.
- 팩터 공분산은 대부분 모형에서 **지수 가중**, 이어서 **GARCH 또는 DEWIV** 로 시장 상황 반응을 키운다.
- 최종 시험: 사전 예측과 사후 실현을 비교 — 대상 = **베타 · 고유 위험 · 액티브 위험**. 대안 모형과도 비교.

### 2.4 자료 수집 (p38)
- 100개 넘는 자료 공급원 · 56개 공급사. 시장 자료는 매일, 재무 자료는 분기 · 연간 재무제표.
- 점검: 시가총액 급변 · 배당 누락 · 전일 대비 설명 안 되는 차이 · 원천 간 대조. 수치 문턱은 원문에 없음.

## 3. 지표 선택 · 표준화 · 위험 지수 · 업종 배정 (3장 p38–40)

### 3.1 지표(descriptor) 선택과 시험 (p38–39)
- 후보는 여러 원천(시장 + 재무 결합 예: 이익/가격). 정성적으로 고르고 정량 시험을 거친다.
- 조건: 개별로 의미 있음(널리 받아들여진 속성) · 시장을 잘 정의된 범주로 나눔 · **이론적 근거** · 위험 예측에 유용 · 시의적절 · 정확 · 가용한 자료. 예측력을 더하지 못하면 기각.
- 용어집 'descriptor'(p159 언저리): 변동성 위험 지수는 단기 변동성 · 장기 변동성 · 체계적 변동성 · 잔차 변동성 같은 여러 지표로 구성될 수 있다고 예시. 결합 식은 "proprietary formulas" — 원문에 없음.

### 3.2 지표 표준화 (p39 · 용어집 normalization p177 · standardization p189)
- 식(p39): **[normalized descriptor] = ([raw descriptor] − [mean]) / [standard deviation]**
- 평균 · 표준편차는 **추정 유니버스 기준**으로 낸다("standardized with respect to the estimation universe").
- 원문 표현은 "usually the mean"/"usually the standard deviation" — 평균이 시가총액 가중인지 동일 가중인지는 지표 단계에서는 원문에 없음.
- 단, 위험 지수 노출의 정의(용어집 'risk index exposure', p187): **"The average (capitalization-weighted) stock in the estimation universe has an exposure of zero"**, 범위는 보통 **−5 ~ +5** 의 표준화 수치. → 평균 = 시가총액 가중 평균이 Barra 관행임을 시사(?).
- 용어집 'standardization'(p189): 표준화는 모든 지표에 적용한 뒤 위험 지수로 묶고, **위험 지수 값도 다시 표준화**한다.
- 절단 · 이상치 처리: 3장에는 **절단 문턱 원문에 없음**. 용어집에 'winsorization' 정의만 있다(p195–196): "이상치를 남은 양 끝 극값(양쪽 하나씩)으로 바꾼다 — 이상치 개수에는 민감하지만 값에는 둔감". 'outlier'(p178): 매우 드문 사건 또는 자료 오류. 몇 표준편차에서 자르는지는 원문에 없음.
- 용어집 'exposure'(p163 언저리): 주식의 스타일 · 위험 지수 노출은 **표준편차 단위**, 업종 노출은 **포트폴리오 가치의 %**.

### 3.3 위험 지수(스타일 팩터) 구성 (p39–40)
- 절차: 표준화 뒤, **종목 수익을 업종 + 지표 하나씩**에 회귀해 각 지표의 통계적 유의성을 시험 → 결과로 지표를 골라 위험 지수에 배정.
- 반복(전진 선택) 절차: 가장 유의한 지표를 먼저 넣고, 남은 지표는 더 엄격히 시험 — **업종 팩터와 이미 배정된 지표를 넘어 설명력을 더할 때만** 추가.
- 지표 → 위험 지수 결합 가중을 어떻게 정하는지: **원문에 없음**("proprietary formulas" · 군집 분석은 배정 도구의 예일 뿐).
- 위험 지수 예(용어집): Volatility · Momentum · Size · Value / Market Variability · Earnings Variability · Size · Growth. 9장(p126): 미국 = 위험 지수 13 + 업종 55, 호주 = 위험 지수 9 + 업종 14. 미국 MH 모형 = 68 팩터(13 + 55).

### 3.4 업종 배정 (p40)
- 업종 체계: 자료 공급사 체계를 쓰거나 추정 유니버스에 더 맞게 새로 만든다.
- 대부분 모형 = **단일 업종**. 다중 업종 배정은 **미국 · 멕시코 · 일본**(p35 본문은 미국 · 일본).
- 다중 배정 가중("Learn more", p40): 사업 부문(segment) 자료로 —
  - 일본 = **매출**
  - 미국 = **영업이익 · 총자산 · 매출** (세 지표를 어떻게 섞는지는 원문에 없음)
  - 가중 합 = **100%**. 예: Walt Disney = 미디어 65% · 엔터테인먼트 35%.
- 장점: 새 사업이 주주에게 보고되는 즉시 위험 특성 변화를 반영. 시장 가격 기반 대안은 60개월 이상 자료가 있어야 변화를 알아챈다.

## 4. 팩터 수익 추정 (3장 p41 · 1장 p21 · p24)

- EQ 3-1(p41): **r_i = X_i f_i + u_i** — r = 종목 초과수익, X = 종목 × 팩터 노출 행렬, f = 추정할 팩터 수익, u = 고유 수익. 노출은 매 기간 **초**에 정해진 값.
- 결과 팩터 수익을 "robust estimates"라 부른다.
- 주기: **월간** 횡단면 회귀(Figure 3-1 "Monthly Cross-Sectional Weighted Regressions").
- **회귀 가중**: 그림에 'Weighted'라고만 적혀 있고 **무엇으로 가중하는지(예: 시가총액 제곱근) 원문에 없음**. 일반화 최소제곱(GLS) 언급도 3장에는 없음.
- 9장(p132)의 전역 팩터 수익은 "cross-sectional weighted least squares regression **subject to constraints**"로 추정 — 식별 문제(세계 팩터 + 국가 + 업종 중복)를 "국가 · 업종 팩터 수익의 **가중 결합 합 = 0**" 제약으로 푼다(p131 각주 1). 가중이 무엇인지는 원문에 없음. [Q 주] 한국 단일 국가 모형에서 시장(국가) 팩터 + 업종 팩터를 함께 넣으면 같은 식별 문제가 생기므로, 같은 꼴의 제약(업종 수익의 시총 가중 합 = 0 등)이 필요하다 — 제약 형태는 원문이 정하지 않음.
- 핸드북의 단일 국가 1장 · 3장 식에는 별도 '시장(국가) 팩터'가 명시돼 있지 않다(Figure 1-2 는 위험 지수 13 + 업종 55 = 68). 2장 Figure 2-3 은 공통 팩터를 업종 + 위험 지수로 나누고, p33 본문은 "market membership, industries, and risk indices"를 든다(?).

## 5. 공분산 행렬 계산 (3장 p41–46)

### 5.1 왜 단순 표본 공분산이 아닌가 (p41–42)
- 표본 공분산은 '안정 과정'(모든 시점이 같은 정보량) 가정. 실제로는 팩터 상관이 변하고, 시장 지수 변동성이 군집(고변동성 뒤 고변동성)한 뒤 낮은 수준으로 돌아간다.
- 두 방식으로 안정 가정을 푼다("For certain models"): ① 최근 관측에 큰 가중(지수 가중) ② 시장 지수 포트폴리오(미국 S&P 500 · 일본 TSE1)의 변동성 모형을 따로 추정하고, 팩터 공분산이 시장 포트폴리오에 대해 같은 변동성 예측을 내도록 눌러 맞춤(scaling).

### 5.2 지수 가중 (p42–43)
- EQ 3-2: **λ = (0.5)^(1/HALF-LIFE)**
- EQ 3-3: **w(t) = λ^(T−t)** (T = 현재 기간, t = 1…T)
- 예: 반감기 60개월이면 λ = 0.5^(1/60) — 60개월 전 관측 = 현재의 1/2, 120개월 전 = 1/4. "60개월은 임의 선택".
- 반감기 = ∞ 이면 동일 가중. 너무 짧으면 앞쪽 자료를 버리는 셈이라 과정이 안정적일 때 정밀도가 떨어진다.
- **"최적 반감기는 나라마다 다르다 — 단일 국가 모형마다 다른 값"**. 국가별 값은 원문에 없음.
- 핸드북 전체에서 주식 관련 반감기 값으로 나오는 것: **9장 전역 주식 팩터 공분산 G = 48개월 · 순수 국내 부분 Φ = 48개월(p133) · 자산군 간 핵심 팩터 공분산 = 36개월(p143 각주)**. (채권 · 통화 장의 8주 · 17주 · 24개월 · 24일 값은 이번 범위 밖.)

### 5.3 시장 변동성 모형으로 눌러 맞추기 — 적용 원칙 (p43)
- 관측 규칙성: 변동성 지속(군집) · **평균 이상 수익 뒤엔 낮은 변동성, 평균 이하 수익 뒤엔 높은 변동성** · 정규분포보다 두꺼운 꼬리.
- DEWIV · GARCH 변형을 "모형별로 · 시기별로 적절히" 적용. 어느 모형에 무엇을 쓰는지는 **Barra Equity Risk Model Reference Guide 로 미룸 — 모형별 표 원문에 없음**.
- 적용 전 검증: 시장 대리 포트폴리오 변동성에 DEWIV/GARCH 가 만족스럽게 맞을 때만 사용.
- **26개 신흥시장 모형은 눌러 맞추지 않는다**(GARCH · DEWIV 모두 부적합 — p43 각주).
- **"Only the systematic part of the factor covariance matrix is scaled."**

### 5.4 DEWIV (p43–44)
- EQ 3-4: **σ²_{r,t} = 21 · (1 − λ) · Σ_{s=1..∞} λ^(s−1) · (r_{t−s} − r̄)²**
  - σ²_{r,t} = t 시점 시장 수익 분산(월 단위로 환산된 값), 21 = 한 달 거래일 수(근사), λ = (0.5)^(1/HALF-LIFE), r_{t−s} = 지수 포트폴리오의 (t−s−1, t−s] 일간 수익, r̄ = 지수 수익 평균.
- 모수는 **반감기 하나**. 일간 분산 예측 × 21 = 월간 DEWIV 분산. **일별 시장 지수 자료가 있어야** 계산 가능.
- 반감기 값은 원문에 없음.

### 5.5 GARCH 와 변형 (p44–45)
- EQ 3-5: r_t = E(r_t) + ε_t (기대 부분 + 놀람)
- EQ 3-6 GARCH(1,1): **σ²_{r,t} = ω + α ε²_{t−1} + β σ²_{r,t−1}**
  - ω = "forecasted mean volatility of the market", α = 최근 실현 변동성 민감도, ε²_{t−1} = t−1 의 최근 실현 변동성, β = 이전 변동성 예측 민감도.
- 한계: 평균 이하 수익 뒤의 더 높은 변동성을 못 잡는다 → 확장:
- EQ 3-7: **σ²_{r,t} = ω + α ε²_{t−1} + β σ²_{r,t−1} + θ ε_{t−1}**
  - θ = 놀람 수익 민감도. **θ < 0** 이면 기대보다 높은 수익 뒤 변동성 하락, 낮은 수익 뒤 상승(비대칭).
- 추정된 ω · α · β · θ 값, 표본 주기(일/월), 추정 방법: **원문에 없음**. (GARCH 의 종류는 분산 예측 함수 꼴로 구분된다는 각주만 있음. 용어집에 IGARCH = 조건부 분산에 단위근 허용 — 충격이 영구 효과.)

### 5.6 눌러 맞춘 값을 팩터 공분산에 반영 (p45–46)
- 시작점: 이미 있는 양의 정부호 팩터 공분산 F 와 고유 분산 대각 행렬 Δ.
- EQ 3-8: **σ²_m = h_m^T X F X^T h_m + σ²_sp** — 눌러 맞추기 전 모형의 시장 지수 월간 총분산.
- EQ 3-9: **σ²_sp = h_m^T Δ h_m** — 시장 지수의 월간 고유 분산.
- EQ 3-10(원문 그대로): **F_s = F + [ (σ²_s − σ²_m) / (σ²_s − σ²_sp) ] · F X^T h_m h_m^T X F**
  - F_s = 눌러 맞춘 팩터 공분산(k×k), σ²_s = DEWIV(σ²_d) 또는 GARCH(σ²_g)의 **월간** 시장 지수 분산 예측, h_m = 시장 지수 보유 비중(n×1), X = n×k 노출.
  - [Q 주 — 원문 아님] 이 식으로 시장 지수 위험을 다시 계산하면 h_m^T X F_s X^T h_m + σ²_sp 가 정확히 σ²_s 가 되려면 계수가 (σ²_s − σ²_m) / (σ²_m − σ²_sp)² 이어야 한다(a = σ²_m − σ²_sp 로 두면 a + c·a² = σ²_s − σ²_sp). 인쇄된 분모 (σ²_s − σ²_sp) 는 이 조건을 만족하지 않는다 — 인쇄 오류이거나 다른 정규화가 생략됐을 수 있다(?). 구현 때는 "시장 지수 예측 위험 = σ²_s" 를 목표 조건으로 두고 계수를 직접 풀어 검증할 것. 이 식은 시장 포트폴리오 방향(F X^T h_m)으로만 랭크 1 수정을 더하므로 "체계적 부분만 눌러 맞춘다"는 원칙과 맞고, 고유 분산 Δ 는 건드리지 않는다.

## 6. 종목 고유 위험 모형 (3장 p47–49 · 2장 p34)

### 6.1 구조 (p34 · p47)
- EQ 3-11: r_i = Σ_k x_ik f_k + u_i. 고유 위험 = u_i 의 표준편차.
- 단순 방식(고유 수익의 과거 분산)은 안정성 가정 → 대신 **예측 모형**: 고유 위험 = (월별 평균 수준 예측) × (종목별 상대 수준).
- 2장(p34) 요약: ① 전 종목 평균 고유 위험 ② 유니버스 대비 종목 상대 고유 위험 ③ 둘을 곱하고 **평균 편향을 고치도록 배율 조정** → "대체로 편향 없는" 종목별 예측.
- 견고성 때문에 **분산이 아니라 절대 고유 수익 |u|** 을 먼저 모형화하고, 배율 κ 로 표준편차 단위로 바꾼다(p47 Methodology).

### 6.2 식 (p48–49)
- EQ 3-12: **σ̂_it = κ_it · (1 + V̂_it) · Ŝ_t**
  - σ̂_it = t 시점 종목 i 고유 위험, κ = 절대 수익 예측을 표준편차 단위로 바꾸는 배율(식에서는 아래첨자 it 가 붙어 있음), V̂_it = 종목 i 의 절대 고유 수익 상대 수준 예측, Ŝ_t = t 시점 전 종목 평균 절대 고유 수익 예측.
- EQ 3-13 평균 수준(시계열): **Ŝ_t = α + Σ_{i=1..k} β_i S_{t−i}**
  - S_t = **추정 유니버스 종목의 월 t 실현 평균 절대 고유 수익**, α · β = 추정 모수. 시차 수 k 값 원문에 없음.
  - 미국 Multiple-Horizon 모형 · 멕시코(MXE1) 모형은 **시차 시장 수익 항**을 추가(계수 · 꼴 원문에 없음). 본문(p47)은 "평균 수준은 과거 평균과 가끔 시차 시장 수익으로 예측 가능"이라 적음.
- EQ 3-14 상대 수준(횡단면): **V̂_it = Σ_{k=1..K} Z_ikt · γ_k**
  - Z_ikt = 종목 i 의 특성 k 노출(t 시점), γ_k = 특성 k 의 상대 고유 위험 기여.
  - "종목의 상대 고유 위험은 종목 펀더멘털과 관련" — **어떤 특성을 쓰는지(예: 규모 · 업종 · 변동성 지표) 원문에 없음**. γ 를 어떻게 추정하는지(회귀의 종속 변수 정의 등)도 원문에 없음. [Q 주] V̂ 의 정의가 (1 + V̂) 꼴이므로 종속 변수는 |u_it| / S_t − 1 같은 상대 편차로 보는 것이 자연스럽다(?) — 원문 확인 불가.
- 배율 κ 의 값 · 추정 방법: 원문에 없음. [Q 주] 정규분포라면 E|u| = σ·sqrt(2/π) 이므로 κ ≈ sqrt(π/2) ≈ 1.2533 이 기준값이 되겠지만, 꼬리가 두꺼우면 더 커진다 — 원문 수치 아님.

## 7. 모형 갱신 주기와 절차 (p49 · p21)

- 주기: **월간**(주식 노출은 매월 마지막 거래일 정보로 다음 달 노출 계산 — p21).
- 절차(p49): ① 최신 자료 수집 · 정제 → ② 지표 값 · 위험 지수 노출 · 업종 배정 계산 → ③ **직전 달** 종목 수익을 횡단면 회귀 → 팩터 수익(공분산 갱신) · 고유 수익 → ④ 고유 수익으로 상대 절대 고유 수익과 평균 절대 고유 수익 계산 → ⑤ 배율과 결합해 고유 위험 예측 → ⑥ 배포.
- 시험(p36): 사전 예측 대 사후 실현(베타 · 고유 위험 · 액티브 위험), 대안 모형과 비교. 편향 통계 같은 구체 시험 식은 원문에 없음.

## 8. 통합 모형(BIM)의 주식 부분 요점 (9장 p125–133 · p141–143)

- 국내(local) 모형을 그대로 블록으로 쓰고, 시장 간 공분산만 **구조 모형**으로 채운다. 예: 호주 = **V_aus = X_aus F_aus X'_aus + Δ_aus**(EQ 9-1). 전 세계 주식 = 블록 대각 X_E · Δ_E 와 국가 간 블록을 가진 F_E(EQ 9-2) → **V_E = X_E F_E X'_E + Δ_E**(EQ 9-3).
- 이유: 국내 주식 팩터 1,000개 이상 · 월간 자료 15년 미만 → 직접 추정하면 가짜 선형 종속 → 위험이 인위적으로 낮은 기형 포트폴리오(예: 영국 AA 금융 비중 확대를 미국 지방채 · 캐나다 자동차 비중 축소로 '헤지')가 만들어진다(p128).
- 구조 모형 EQ 9-5: **f_ac = Y_ac g_ac + φ_ac** (국내 팩터 수익 = 국내 팩터의 전역 팩터 노출 × 전역 팩터 수익 + 순수 국내 수익). 순수 국내 수익은 시장 간 무상관 · 시장 안에서는 상관 가능.
- EQ 9-6: **F̂_ac = Y_ac G_ac Y'_ac + Φ_ac** (Φ 는 같은 시장 쌍이 아니면 0). 마지막에 대각 블록을 국내 모형 값으로 맞춘다("Consistency" · p130 · p133 "Scaling to Local Markets" — 맞추는 식은 원문에 없음).
- 전역 주식 팩터(p131): 세계 팩터 · 국가 팩터 · 전역 업종 팩터 · 전역 위험 지수 4개(**Price Momentum · Size · Value · Volatility**).
- 노출 규칙: 국내 업종 팩터 = 세계 · 자기 국가 · 소속 전역 업종에 단위 노출(EQ 9-7: f_ind = g_wld + Y_cnty g_cnty + Y_ind g_ind + φ_ind). 4개 스타일에 대응하는 국내 위험 지수 = 그 스타일에 단위 노출(EQ 9-8: f_ri = g_ri + φ_ri). 나머지 국내 위험 지수 = 전역 노출 없음. 국내 업종이 여러 전역 업종에 분수 가중으로 걸릴 수 있음.
- 전역 팩터 수익 추정: 월간 국내 팩터 수익에 대해 **제약 있는 횡단면 WLS**, 1984-01~ · 모형이 없던 기간은 국가 지수 수익으로 대리(p132).
- 공분산: G(전역) · Φ(순수 국내) 모두 **지수 가중 반감기 48개월**(p133 — "이번 달 팩터 수익이 4년 전의 두 배 가중").
- 결측 자료(p134 상자): 쌍별 최대 표본 공분산은 음의 고윳값이 생길 수 있고, 결측 없는 날만 쓰면 자료를 너무 버린다 → **EM 알고리즘 최우추정**으로 양의 준정부호 공분산.
- 자산군 간: 핵심 팩터(세계 · 국가 주식 · shift · 평균 신용 스프레드 · 평균 신흥시장 스프레드)를 통해서만 상관 — EQ 9-16: g_A = Σ_{A,core} Σ_core^{-1} g_core + τ · EQ 9-17: G_{A,B} = Σ_{A,core} Σ_core^{-1} Σ_{core,B} + Σ_{τA,τB}. Σ_{A,core} · Σ_core 는 반감기 36개월(p143 각주).
- [Q 주] 한국 단일 국가 모형에는 직접 필요 없다. 쓸모 있는 부분 = ① 결측 · 짧은 이력 팩터의 EM 공분산 ② "많은 팩터 · 짧은 이력이면 구조(저차원) 모형으로 공분산을 채운다"는 원칙.

## 9. 용어집 · 부록에서 (p147–196)

| 항목 | 원문 정의 요점 |
|---|---|
| active / active return | 벤치마크와 다른 부분. 예: 포트폴리오 5% · 벤치 3% → 액티브 수익 2%. 액티브 비중 = 포트 비중 − 벤치 비중. **액티브 노출 = 포트 팩터 노출 − 벤치 팩터 노출** |
| active risk (= tracking error) | 액티브 수익의 **연율화 표준편차**. 포트와 벤치 수익 차이의 예상 표준편차 |
| tracking error | 포트–벤치 수익 차의 표준편차(지정 보유 기간) |
| common factor risk | 공통 팩터 노출에서 오는 총위험 부분 |
| specific risk | 그 종목 고유의 예측 불가에서 오는 불확실성 · 다른 자산 · 팩터와 무관(idiosyncratic) |
| specific return | 공통 팩터로 설명 안 되는 초과수익 · 팩터 및 다른 종목 고유 수익과 독립(무상관) |
| residual return / risk | 시장(또는 벤치) 수익과 무상관인 부분 = 총수익 − 베타 × 시장 수익. 잔차 위험 = 그 표준편차 |
| systematic risk | 체계적 포트폴리오 노출에서 오는 위험. 총위험은 어떤 체계적 포트폴리오 정의에서도 체계적 + 잔차로 나뉜다 |
| beta | 시장 움직임 민감도(비분산 위험). 1% 시장 변화에 대응하는 평균 수익 변화. CAPM EQ 2-1(p31): **E[r̃_i] − r_F = β_i E[r̃_M − r_F]**. β 의 공분산/분산 식은 원문 그림에서 확인 못 함(?) |
| historical beta | 보통 **60개월** 회귀 기울기(초과수익 대 시장 초과수익). 회사 구조 변화를 늦게 반영 · 일회성 사건에 왜곡(예: 1984 Bhopal 사고가 강세장 중이라 역사적 베타가 낮게 나옴) |
| predicted beta (fundamental beta) | 위험 모형에서 낸 베타 — 업종 노출 + 스타일(규모 · 변동성 · 모멘텀 · 가치). 매월 재추정되어 빨리 반응. 계산식(포트–시장 공분산 / 시장 분산 꼴)은 원문에 명시 없음 |
| R-squared | (예측) 시장 분산 / (예측) 총분산 = β² × 시장 분산 예측 / 포트 총분산 예측 |
| risk | 표준편차가 직관적 척도, **독립 위험 요소를 비교 · 합할 때는 분산을 써야 함**. 꼬리 모양이 다르면 왜도까지 |
| variance | 독립 요소들의 분산은 더해진다 |
| exposure | 주식 스타일 = 표준편차 단위 · 업종 = 포트 가치 % |
| risk index exposure | 표준화 값, 보통 −5~+5, **추정 유니버스의 시총 가중 평균 종목 = 0** |
| standardization | 평균 빼고 표준편차로 나눔 → 평균 0 · 표준편차 1. 지표에 적용 후 위험 지수로 묶고, 위험 지수도 다시 표준화 |
| winsorization | 이상치를 남은 양 끝 극값으로 대체 |
| optimization | 제약 안에서 목적 함수 최대 해. 1계 조건이 특성 간 교환 관계를 표현 |
| algorithm | "효용 함수가 주어졌을 때 위험과 수익의 최소 결합을 찾는" 예 |
| alpha | 시장 효과로 설명 안 되는 수익. 표기상 연 % 또는 연율 비율(0.01) |
| value at risk | 주어진 기간 · 확률에서 통화 단위 잠재 손실 |

- **한계 기여(marginal contribution) · 위험 회피 계수 · 효용 식 · 정보비율(information ratio): 핸드북 전체(본문 · 용어집)에 원문에 없음.** 분산을 %² 로 쓰는지 등 단위 규약도 원문에 없음. 위험 분해는 그림 2-3(총위험 = 공통 팩터(업종 + 위험 지수) + 고유) 수준의 개념만 있다. (참고 문헌으로 Grinold & Kahn 『Active Portfolio Management』 2판(1999)과 Rudd & Clasing(1988)을 든다 — p11.)
