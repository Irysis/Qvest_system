### 2.4 비대칭의 실체

- 감사 프롬프트는 abs = 초록 · pdf = 불가 · html v1 = 유일한 전문이라고 적는다(`rf_fidelity_fanout.sh:156-158`). 그러나 1회차 감사 축 세션 78개(13편 × 6축) 중 축자 원문을 읽은 것은 37개, 요약만 41개다(2508 · 2210 은 6/6 요약). 비대칭의 실체는 "같은 요약기에 감사자는 축별로 좁은 적대적 질문(예: 전처리 절만 인용하라)을, 구현자는 방법론 전체를 요약하라는 넓은 질문을 던졌다"는 것이다. 요약 모델은 좁은 질문에는 해당 절의 짧은 원문 인용을 돌려준다.
