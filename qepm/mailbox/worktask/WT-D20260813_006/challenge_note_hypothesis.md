# Self-Adversarial Challenge — WT-D20260813_006 가설설계 (alpha-hypothesis, fable)

대상: `alpha_hypothesis.json` (선택 가설 C1 — 월내 flow×수익 경로 결합)
축: 설계 축 4종만 (v8.2 축소판 — 실측·게이트 축은 alpha-research/forge 소관)

## 약점 1 — 메커니즘이 사후 서술(story-fitting)인가

**제기**: "개인이 하락일에 사고 그것이 나쁜 신호"라는 이야기는 어떤 flow 데이터에서도 지어낼 수 있는 서사 아닌가. 특히 방향(하락일 흡수 → 음의 drift)을 데이터를 보고 고른 것 아닌가.

**분류: PARTIAL**.
- 반박 근거: 방향은 본 라운드 데이터 관측에서 오지 않았다 — 설계 시점에 어떤 월내 결합 통계도 계산하지 않았고(실측 금지 준수), 방향은 제도 마찰(공매도 제약 하 부정 정보의 매도-측 반영 지연 + 개인 유동성 공급의 조정 지연)에서 연역했다. 문헌 계보(Barber-Odean 계열 retail 역추세, Diamond-Verrecchia 공매도 제약 하 정보 반영)도 사전 존재.
- 수용 부분: "개인 흡수 = 정보성 매도의 흔적"이라는 식별 가정 자체는 검증 안 된 연역이다. 그래서 반증 F1 을 **성과가 아니라 후속 flow 관측**으로 세워, 기전이 성과 이전에 독립적으로 기각될 수 있게 했다. F1 이 무유의면 성과가 우연히 나와도 기전 기각.

## 약점 2 — 반증조건이 성과 동어반복으로 위장됐나

**제기**: F2(vol·size 통제 FMB)는 결국 수익률 회귀다 — "성과가 낮으면 기각"의 위장 아닌가.

**분류: PARTIAL**.
- 반박: F1(후속 foreign/기관 flow 분위차)과 F3(월간 level 과의 상관 상한)은 순수 비-성과 관측 — field_dictionary 내 필드(A6/FDB-B4)로 확인 가능하며 성과와 독립으로 발화한다. 요건("기전 관측 최소 1개")은 F1 이 충족.
- 수용: F2 는 수익률을 좌변에 두므로 성과-인접이 맞다. 단 성과 *수준* 판정이 아니라 **통제 전후 계수 소멸 여부**(독립성 검사)라는 점에서 MAX 판례의 판별 장치를 그대로 승계한 것 — 이것을 빼면 vol-대리 재포장을 걸러낼 장치가 없다. 성과 게이트(PORT_t 2.95)와는 층이 다름을 json 에 명시했다.

## 약점 3 — 국면 경계가 메커니즘에서 도출됐나 (사후 데이터 관찰 아닌가)

**제기**: MEGA tier 약화 경계는 R16 실측(cap-tier 국소화)을 보고 넣은 사후 경계 아닌가.

**분류: ACCEPT (부분 시인 + 명시 처리)**.
- crisis 경계는 순수 기전 도출(매도의 지배 원인이 정보→유동성 청산으로 바뀌어 식별 가정이 붕괴) — 사후 관찰 아님.
- MEGA 경계는 이중 근거다: 기전 측(개인 흡수 채널의 부재)은 연역이지만, 그 경계를 **명시하게 만든 계기**는 R16 관측이다. 이를 숨기지 않고 regime_scope.boundary_rationale 에 "관측-유래 근거 병용 + cap-w 게이트 면제 사유 아님"으로 정직 표기했다. 경계 서술이 판정 완화로 소비되는 것을 차단하는 문구 포함.

## 약점 4 — settled-negative 의 재포장인가

**제기**: DIST-QPM-005 가 "개인 flow 파생 단일팩터 경로는 알파 부재 + 재구성 변형도 대수적 clone(cor 0.897)"이라 했다. '월내 결합'도 같은 원천의 재구성 변형이다.

**분류: REBUTTAL (증거 기반)**.
- DIST-QPM-005 의 clone 판정은 **-z_individual 항을 대수적으로 공유**하는 1차(level) 재구성에 대한 것. 본 피처는 2차 교차-모멘트 cov_월내(flow_d, ret_d)로, 월간 합 (Σflow, Σret) 의 어떤 함수도 아니다 — 대수적 독립이 구조적으로 성립.
- 그러나 "구조적으로 다르다"는 주장을 신뢰의 근거로 삼지 않고, F3(월간 level 팩터와 횡단면 |cor| ≥ 0.8 이면 기각)을 **기계 검사**로 내장했다 — L-160A 가 요구한 decomposition 사전체크의 실행형.
- 부수: DIST-QPM-005 retry_policy 의 프론티어 문구("독립 측정으로 구성, hidden-clone 회피")가 정확히 이 방향을 지목하고 있어 INV-7 재도전 규약과 정합.
- 인접 negative 3건 (MAX vol-대리 · R16 volume 5종 · DIST-QPM-026 spread) 과의 차별점은 json prechecks 에 항목별 기록. 특히 R16 의 cap-tier 국소화 리스크는 차별점이 아니라 **상속 리스크**로 분류해 CH5 에 남겼다 (재포장 부정이 리스크 부정으로 새는 것 방지).
