## 0. 질문

**FQ-233 3-arm(평균 / q50 / 꼬리초과확률)의 paired 무차이 판정 3건이 UNDERPOWERED(미결)인 것은
`top-25 이산 선별`이라는 소비 형태가 해상도를 붕괴시켰기 때문인가.**

표적·패널·피처·학습·워크포워드·비용은 **일절 바꾸지 않는다**(저장 스코어 재사용, **재학습 0회**).
바꾸는 것은 **소비 형태(검출 프레임)뿐**이다.

★이 라운드는 **검출 장치의 해상도**를 시험한다. 자본 후보를 만들지 않는다 — 운용 종목수 ≤ 25 는
Production Constraints 의 고정 축(INV-7)이며, 브레드스 확대는 제약 완화 레버가 아니다.

## 2. 바꾸는 것 = 소비 형태(가중 규칙)뿐 — 해상도 사다리

월별 스코어 내림차순 랭크 `rank_i` (1 = 최고 스코어), 그 달 유효 종목수 `M`.

| id | 사양 | 성격 |
|---|---|---|
| **F0** | top-25 동일가중 (기존 프레임) | 참조 기준선 — 반증 축 1 의 분모 |
| **F1** | top-50, 편입군 내 `w_i ∝ (50 − rank_i)`, 정규화 Σw=1, long-only | 경계 가중이 **정확히 0** 으로 연속 수렴 |
| **F2** | top-100, `w_i ∝ (100 − rank_i)`, Σw=1, long-only | F1 동일 기전, 브레드스 4배 |
| **F3L** | 전 브레드스, `w_i ∝ (M − rank_i)`, Σw=1, long-only | 이산화 0 · 브레드스 최대 |
| ~~F3~~ | 전 브레드스 센터드-랭크 Σ\|w\|=1 (설계 원안) | **롱숏 — 판정 바인딩 금지**(§7) · 진단 기록만 |

**가중식의 유일성 근거**: 설계가 F1/F2 에 요구한 두 성질 —「long-only」∧「경계 가중 → 0 연속 수렴」—
을 동시에 만족하는 랭크-선형 가중은 `w ∝ (N − rank)` 로 아핀 상수배까지 유일하다. 자유도 없음.

## 3. ★절대 순서 강제 (mean-blind 관문)

측정은 **두 개의 분리된 스크립트**로 실행하며, 산출물 타임스탬프로 순서를 입증한다.

1. **`gate.R`** — 프레임별 diff 계열 구성 → **sd 와 MDE 만** 산출·기록.
   - `required_effect(n=198, t_threshold=2.0, sd_monthly=sd(diff), series=diff)` 호출.
   - `series=` 로 **nw_inflation 실측 의무**(addendum 의 1.25 가정 대체).
   - ★이 스크립트는 diff 의 **평균·t 를 계산하지도 출력하지도 저장하지도 않는다.**
     arm 별 성과량(PORT_t/SR/…)도 이 단계에서 출력·기록하지 않는다.
2. **`gate_lock.json`** — 관문 판정과 선택 프레임을 고정 기록.
3. **`verdict.R`** — 잠금된 **선택 프레임 1개**에서만 co-primary paired t 산출.

**관문 통과 조건**: 실측 MDE ≤ **연 3.0%p**.
**바인딩 프레임 선택**: 통과 프레임 중 **소비-근접 우선순위 F1 > F2 > F3L 최상위 1개** — 사전 고정,
성과 무관. 통과한 하위 프레임은 병기(기록 전용).
**탈락 프레임**은 `FRAME_REJECTED_UNDERPOWERED` 로 기록하고 그 프레임의 평균·t 를 산출하지 않는다.

⚠ **재분류 조건**: paired t 를 보고 프레임·비교쌍·가중식을 바꾸는 순간 `selection_type = sweep`
+ DSR ≥ 0.5 HARD 가 붙는다.

## 6. 반증 2축 (성과와 독립 — 반드시 실측)

- **축 1 (검출 기전)**: 브레드스·랭크가중 프레임의 paired diff 월 sd 가 F0 실측치의 **50% 이하**로
  감소하지 않으면 '이산 편입 경계가 해상도 붕괴의 원천' 기전 기각.
  분모 = 본 세션 재산출 F0 sd (선행 기록 0.043381 과 대조 병기).
- **축 2 (알파 기전)**: 월내 횡단면 왜도 × diff 의 **연속 상호작용** 기울기.
  왜도 추정기 = `r33_profile_stage2.R::skew` 자구 승계(모집단 왜도).
  1차 = `frd$Ret_1m` 월별 횡단면(R31/R32/R33 인용 근거와 동일 정의) ·
  2차 = `.cache/RAWDATA.parquet` 일간 수익 파생(설계 field_dictionary 자구) — 둘 다 보고.
  회귀 `d_t = a + b·skew_t + e_t`, NW lag-3 t. **이분 라벨 금지 — 연속 상호작용만.**
  `|t_b| < 2.0 ∧ 평균 diff 유의` → 알파-기전 기각(효과는 있으나 비대칭 기원 아님 — 재귀속 라운드로 분리).

## 7. 롱숏 배제 (도훈 mandate 2026-06-11 승계)

설계 원안의 F3(센터드-랭크 Σ|w|=1)는 음의 가중을 포함하므로 **롱숏**이다.
mandate = "롱숏 불허 — 검증 단계 포함 전면 long-only. L/S 수치는 판정 근거 사용 금지, 진단 참고 라벨만."

설계 재작성이 아니라 상위 mandate 적용이며, `challenge_note.md` 에 기록한다.

## 9. 주장하지 않는 것

- 자본 자격 아님. graduation HARD 3종(PORT_t 2.95 · oos_retention 0.7 · calmar 0.64) 별도이며
  본 라운드는 그 판정을 하지 않는다.
- 브레드스 확대 프레임의 성과(SR/PORT_t)는 **검출 장치의 부산물**이지 운용 성과 주장이 아니다.
- ★**절대-스케일 바의 한계 (사전 고지)**: 브레드스가 커지면 diff 의 잡음뿐 아니라 **효과 크기도**
  함께 축소된다. 연 3%p 라는 **절대 문턱**은 스케일 의존적이므로, 관문 통과가 곧 '같은 기저 효과에
  대한 검정력 증가'를 뜻하지 않는다. 이 때문에 powered null 라벨은 **브레드스-스코프 한정**이며,
  §6 축 1(sd 감소율)과 secondary 랭크-기울기 진단이 그 한계의 정량화 장치다.
  본 라운드는 이 한계를 해소했다고 주장하지 않고, **측정해서 보고한다**(§10 scale_diagnostic).
