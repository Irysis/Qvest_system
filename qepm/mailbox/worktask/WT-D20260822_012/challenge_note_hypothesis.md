# Self-Adversarial Challenge — 가설설계 축 (WT-D20260822_012 / FQ-245)

- 작성: alpha-hypothesis (fable), finalize 직전. 축 = 설계 4축(v8.2 축소판).

## 약점 1 — 기전이 사후 서술(story-fitting)인가

**제기**: mechanism(외국인 flow 전달 + 매핑 비용 + 공매도 제약)은 실패한 무조건부 런의 stress 패턴을 보고 나서 구성됐다. COVID/EuDebt 양성을 설명하도록 역설계됐을 가능성.

**판정: PARTIAL**. (a) 라벨 규칙(3변수 부호정렬)은 에피소드와 독립적으로 사전 고정했고, 에피소드가 그 규칙으로 실제 분류되는지는 '설계 후 확인' 항목으로 격리했다(미포함 시 동기 서술 철회). (b) flow 전달 기전은 이 런과 무관한 문헌 계보(gradual information diffusion / KR 외국인 flow persistence)와 저장소 실측 원천(investor_wide)을 갖는다. (c) 그러나 3계열 선택 자체(T10Y2Y·VIX·KRW_USD)는 실패 런의 설계를 상속한 것이지 기전에서 도출한 것이 아니다 — 이 상속을 "기전이 3채널을 지목했다"고 서술하지 않도록 mechanism 문안에서 채널 선택의 근거를 주장하지 않았다. 잔여 위험은 F-flow 반증(수익이 나와도 flow 스프레드가 없으면 성립 선언 불가)이 흡수한다.

## 약점 2 — 반증 조건이 성과 동어반복으로 위장됐나

**제기**: F-flow 가 사실상 성과의 재서술일 수 있다 — 외국인이 사면 가격이 오르므로(flow-price 동시성) flow 스프레드 양성은 수익 양성과 거의 동치 아닌가.

**판정: PARTIAL → 문안 반영**. 동시성 위험은 실재한다. 다만 (a) flow 는 field_dictionary 의 별도 필드(A6/F2)이고 표적(활성수익)과 다른 관측이다. (b) 결정적으로 **역방향이 정보적**이다: 조건부 수익이 양성인데 flow 스프레드가 0 이면 기전 기각 — 이 조합은 성과 동어반복으로는 불가능한 판별을 준다(수익의 출처가 flow 가 아닌 다른 무엇 = 기전 불명 강등). (c) F-boundary(mixed vs aligned IC 비교)와 F-MDD(그릇 예측)는 성과 문턱과 독립인 구조 반증을 추가한다. 완전한 독립 반증은 아니라는 한계를 인정하고 '기각 시 강등(성립 선언 불가)'으로 귀결을 보수화했다.

## 약점 3 — 국면 경계가 기전에서 도출됐나, 사후 데이터 관찰인가

**제기**: '정렬=발화, mixed=무신호' 경계는 stress 표의 2/6 아웃퍼폼 패턴 관찰에서 온 것 아닌가. 또 aligned_up 12.3% 라는 빈도를 **먼저 재보고 나서** primary 를 pooled 로 옮긴 것은 데이터를 보고 경계를 고른 것 아닌가.

**판정: REBUTTAL(전반) + ACCEPT(부분)**. 경계 자체는 score 의 대수 구조에서 도출된다: score=Σβ·δ 는 δ 부호가 갈리면 β 가중 상쇄로 잡음이 된다 — 이는 수익 데이터 없이 성립하는 논증이다. pooled 로의 이동도 조건부 **성과를 전혀 보지 않고** 라벨 빈도(n=32 vs 74)와 sd(전표본)만으로 결정했다 — Gate 0 이 허용하는 정보만 소비. **ACCEPT 부분**: 극단 VIX 평균회귀 경계(weakens_in 3항)는 일반 지식이지 이 저장소 실측이 아니다 — 측정 단계에서 검증 없는 가정으로 표기돼야 하며, 판정 축이 아니라 진단 축으로만 뒀다.

## 약점 4 — settled-negative 의 재포장인가

**제기**: 레짐 스위칭/매크로 타이밍 계열은 7건 FAIL + DIST-RAMP-006 + FQ-239 전패다. '정렬 월만 투자, mixed 현금'은 매크로 타이밍 온오프와 형태가 같다.

**판정: PARTIAL → 설계로 차단**. hypothesis_index 조회 실측: macro_beta family 자체는 선례 0(미탐색), 죽은 것은 매크로 상태로 **노출 크기**를 조정한 배분층이다. 본 설계의 PRIMARY 는 정렬 월 **내부의** 조건부 활성수익(선별 유효성)이고, mixed 월 현금이 만드는 전기간 타이밍 성과는 판정 근거에서 명시 배제했다(differentiation 절). 잔여 위험: 소비 단계에서 이 재료가 결국 온오프 오버레이 그릇으로 흐르면 그 시점에 타이밍 계열과의 차별점을 별도 사전등록해야 한다(FQ-236 소비면 판정 ③ 승계) — handoff 에 명시.

## 추가 자가 제기 (판정 규칙 정합)

- **약점 5 — 검정력**: 기대검정력 34%. 이 라운드는 '성립'보다 '미결'로 끝날 확률이 높다. **ACCEPT** — Gate 0 floor(≥0.10)는 통과하므로 중단 사유는 아니나, 미결을 효과없음으로 오라벨하지 않도록 verdict_with_power 3분할 + 도달가능성 병기를 사전등록에 동결했고, 미결 시 동일 config 재실행 금지를 박았다.
- **약점 6 — sd 차용**: MDE 의 sd 는 무조건부 전표본(0.06162)에서 왔다. 정렬 월은 고변동 국면에 몰릴 수 있어 조건부 sd 가 더 클 수 있다(MDE 과소). **ACCEPT** — 측정 착수 시 성과 개봉 전 sd 재측정 + 1.3배 초과 시 Gate 0 재판정을 design_locks 에 동결.
