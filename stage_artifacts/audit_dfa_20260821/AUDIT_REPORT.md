**종합판정: 수정 필요** (구현 무효 아님 — BLOCK 0)
- 파이프라인의 **인과성(미래참조 부재)은 전 층에서 실증적으로 결백**: 미래교란 2시점에서 refit 파라미터·(λ,κ)·일별 상태·뷰·c 캘리브·일별/월간 손익 전부 **비트-동일**(P5), 단일일 교란의 최초 반응이 자기 사양 지연과 정확 일치(P6), 롱온리·Σw=1·점프 페널티·훈련구간 한정 기대수익 전부 확인.
- 수정 대상은 **CV 하이퍼파라미터 선택 층 1곳**: (λ,κ)을 고르는 검증 성과가 ①검증창 자체에 적합한 모델의 ②전 구간 smoothed 상태와 ③사후 상태평균으로 계산된다(C1+C8, 같은 뿌리). 인과적(결정 시점 이전 데이터만)이므로 look-ahead는 아니나, 2024a 각주14가 경고하는 "인샘플 기준 → 과소평활 λ 선택" 편향이 그대로 열려 있고, **구현측 자기 prereg(D3: "검증창 상태 = 온라인 필터 상태")와 코드가 불일치**한다.

**상위 3 발견**
1. **[FAIL·C8+C1] CV 선택 성과의 신분 위장**: `run_ramp_shumulvey_v5_daily.R:128-137` — trailing 6y 창에 sparse_jm을 **그 창 자체로 적합**하고(`Xvs` = 검증창 표준화 데이터), `fitg$s`(전 창 DP backtrace = smoothed)와 `ls_sh_t1`의 `vr`(창 전체 상태평균 = 사후 기대수익)로 L/S Sharpe를 산출해 argmax. 논문 프로토콜(훈련창과 분리된 검증창 + 온라인 추론 상태)과 이중 불일치이며, prereg v5 D3 스펙("검증창 상태 = 온라인 필터 상태", "T+2 lag")과 코드(smoothed, T+1)가 상충.

3. **[PASS·P5/P6] 인과성 전면 실증**: t* 2시점 미래 치환에서 t* 이전 전 산출물 비트-동일(불일치 셀 0/8,598 상태·refit 498건·손익 전 계열), 음성 대조(t* 이후 2,153/469셀 상이)로 프로브 유효성 확인. 단일일 교란 반응 분해 = 교란 전 0 / 당일 기계적 0.139 / 월내 드리프트 1.55e-05 / **익월 결정 5.12e-03 (드리프트 대비 330×)** — "월말 결정→익월 적용" 자기 사양 정확 충족. 6월 구판의 동월 결함이 v5에서 실제로 제거됐음을 행동으로 확인.
