## 1. 왜 lag1 인가 (설계 고정)

동시점 `disp_t` 는 소비 불가다 — 그 달의 횡단면 수익 분산은 그 달 **시작 시점에 관측 불가**(C1/C5).
따라서 전 게이트는 `disp_{t-1}` 만 입력으로 쓴다. 문턱 산출도 **확장창(expanding, t-1 까지)** 분위만 쓴다
(전표본 분위 = full-sample 통계 = C1 위반). 전표본 분위판은 *참고 병기*만 하고 판정에 쓰지 않는다.

## 2. 기전 분해 — 스케일인가 기술인가 (측정 전 고정)

FMB 다변량 회귀에서 z(M26) 계수는 항등적으로
`b_t = ρ_t · disp_t / sd_z_t` (ρ_t = 표준화 부분기울기).
⇒ `b_t` 의 분산 의존은 **두 채널**로 갈린다. 어느 쪽인지가 소비 가능성을 결정한다.

| 채널 | 검정 | 참일 때 |
|---|---|---|
| **S1 스케일** | `b_t ~ g_{t-1}` (g = 표준화 lag1 분산) | 계수가 커지지만 **분산도 같이 커진다** ⇒ 위험조정 이득 0. 게이트는 mean 과 sd 를 함께 키울 뿐 |
| **S2 기술** | `ρ_t (= b_t·sd_z_t/disp_t) ~ g_{t-1}` | 고분산 달에 **상관 자체**가 높다 ⇒ 위험조정 이득 실재 |
| **S3 차등** | `(ρ_t^{M26} − mean_k ρ_t^{k}) ~ g_{t-1}`, k ∈ {C01,C02,C04} | M26 의 **상대** 강도가 분산에 조건부 ⇒ 복합 재가중의 경제적 근거 성립 |

**판정 규칙 (사전 고정)**
- S1 유의 ∧ S2 비유의 ⇒ **순수 스케일**. "분산 의존"은 기계적 항등식의 재진술이며 위험조정 소비 근거 없음.
- S2 유의 ⇒ 기술 조건부. 소비 후보 성립.
- S3 비유의 ⇒ 복합 재가중(선택 소비면)의 **경제적 근거 부재**. 그래도 측정은 하되 "근거 없는 틸트"로 라벨하고 양성 결과를 주장하지 않는다.
- 문턱 |t| ≥ 2.0 (NW lag3). FQ-223/225 승계 — 새로 만들지 않는다.

## 3. 소비면 선택 (측정 전 확정 + 근거)

분산은 **한 달에 하나인 스칼라**(시계열 변수)이지 종목별 변수가 아니다. 이 사실이 소비면을 강제한다.

| 후보 | 구조 판정 | 채택 |
|---|---|---|
| **랭킹 가중 (횡단면)** | 스칼라 단독으론 월 내 순서를 못 바꾼다. 단 **복합신호 내 상대 가중**으로는 순서를 바꾼다 — 알파 범위 안 | **채택** |
| **신호 강도 조절 (단일 팩터 노출 스케일)** | canonical top-25 EW 는 **양의 스칼라에 대해 랭킹 불변** ⇒ 단일 팩터 게이팅은 **구조적 no-op**. 게다가 선형 노출 축소는 실패 계열(라벨 오버레이 선례) | 기각 (단, no-op 임을 실측으로 확인 — §6 무결성 점검) |
| **발화 월 선택 (on/off 타이밍)** | off 달에 벤치/현금으로 대체해야 성립 ⇒ **오버레이 레인**. Σw=1 long-only 단일 sleeve 에서 알파 에이전트 권한 밖(옵티마이저·블렌더 영역) + C5 오버레이 타이밍 별도 규율 | 범위 밖 (FQ 등재로 이관) |

**채택 소비면 = 복합신호 내 M26 상대 가중의 분산 조건부 조절**
- 기저 복합 = EW 4팩터 `z(C01)+z(C02)+z(C04)+z(M26)`
- 게이트판 = `z(C01)+z(C02)+z(C04)+ m̃_t·z(M26)`, 나머지 3종 가중 고정
- 이 형태만이 (i) 크기 정보를 쓰고 (ii) 실제로 횡단면을 바꾸며 (iii) 알파 범위 안에 있다.

**노출 중립화 (사전 고정)**: `m̃_t = m_t / (t−1 까지의 확장창 평균 m)`. 정규화 없이는 "그냥 레버리지를 키운 게이트"가 자동 승리한다.

## 4. 게이트 형태 — 사전등록 4종 (문턱·분위 개수 사후 선택 금지)

전부 `g_{t-1}` = 확장창(≥24개월 burn-in) 기준 lag1 분산의 위치에서 산출. 4종 **전부 보고**.

| ID | 형태 | 정의 (고정) |
|---|---|---|
| **G1** | 이진 (상위 30%) | `m_t = 1` if `disp_{t-1} ≥ expq(0.70)` else `0` |
| **G2** | 이진 (상위 50%) | `m_t = 1` if `disp_{t-1} ≥ expq(0.50)` else `0` |
| **G3** | 연속 선형 | `m_t = clip(1 + 1.0·g_{t-1}, 0, 2)`, `g` = 확장창 z-score of `disp_{t-1}` |
| **G4** | 분위 조건부 강도 | 확장창 사분위 → `m_t ∈ {0.50, 0.85, 1.15, 1.50}` (1 대칭 사다리, 고정) |

λ=1.0 · 사다리 {0.50,0.85,1.15,1.50} · 분위 개수 4 는 **본 문서에서 고정**한다. 사후 조정 금지.
`m_t` 미정의 구간(burn-in)은 `m_t = 1`(중립)로 두고 개월수를 보고한다.
