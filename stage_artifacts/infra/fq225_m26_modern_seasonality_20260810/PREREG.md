## 1. (A) 현대 구간 약화 — 순서 고정

### A0. 검정력 선판정 (착수 게이트, 측정 전 규칙)

`02_Infrastructure/contracts/required_effect_size.R::required_effect(n=115, t_threshold=2.0, sd_monthly=sd(현대 구간 계수계열), design="full")`

- **판정 불가 선언 조건**: 현대 구간 관측 월평균 효과 `|mean_modern|` < `required_monthly`
  → 그 구간의 level 검정으로는 "약화됐다"도 "안 약화됐다"도 말할 수 없다. **이 사실이 결론**이며 억지 판정 금지.
- 이 경우에도 **A1 추세검정은 수행한다** — 분할이 아니라 전표본 연속 상호작용이라 검정력이 다르기 때문(08-08 규약: 분할은 검정력을 파괴한다).
- ★도구 자기진단 의무: `verdict_with_power` 의 `implied_t_threshold` 를 함께 보고한다.
  바가 arm 자신의 se 재진술이면(`bar_restates_t`) 라벨이 "|t|<2.0" 이상의 정보를 담지 않음을 명시한다.
- **외부 기준 바 병기**: `sd_monthly = sd(초기 구간 계수계열)` 로도 계산해
  "초기 구간과 같은 크기의 효과였다면 현대 115개월에서 검출 가능했는가"를 별도로 답한다. 이쪽이 진짜 검정력 질문이다.

### A1. 주판정 — 연속 추세 (분할 금지)

전 283개월 계수계열 `b_t` 에 대해
`b_t = a + c·τ_t + ε_t`, `τ_t` = 표본 중앙을 0으로 한 **연 단위 시간**, NW(lag 3) SE.

- **추세 검출** = `|t_c| >= 2.0`. `c < 0` 이면 약화 방향.
- 문턱 2.0 은 FQ-223 승계(새로 만들지 않음).
- 보조(판정 아님): 로그 시간 `log(1+연차)` 사양, 2차항 사양.

### A2. 귀속 (A1 검출 시에만 수행)

`b_t` 를 시간 + 후보 채널로 회귀(전부 월별, 연속 — 분할 금지). 채널:

| 축 | 대리변수 | 기전 |
|---|---|---|
| 구성 | `N_t` (월 횡단면 종목수), `sd_z_t` (z(M26) 횡단면 sd) | 유니버스·커버리지 확대 |
| 구성/기계 | `disp_t` (Ret_1m 횡단면 sd) | 기울기는 수익 분산에 기계적으로 비례 |
| 국면 | `vol12_t` (직전 12개월 시장수익 sd, **lagged**), `dd_t` (직전 누적 낙폭, lagged) | 국면 조건부 |

- **감쇠(decay)** = 전 채널을 넣어도 시간 계수가 `|t| >= 2.0` **AND** `|c_full| / |c_base| >= 0.5`
- **구성(composition)** = 구성 채널 추가 시 `|t_c| < 2.0` **AND** `|c| / |c_base| < 0.5`
- **국면(regime)** = 국면 채널 추가 시 동일 조건
- 둘 이상 충족 시 **혼합**으로 라벨하고 채널별 잔존율을 수치로 보고. 단일 원인 강변 금지.

### A3. 양성 대조 (같은 실행 안에서)

동일 추세검정을 `C01_SUE` / `C02_EPS_Chg_1m` / `C04_ESBR` / `M01_Mom_12_1`(별도 arm) 계수계열에 적용.

- **대조 유효 조건**: 최소 1개 팩터가 추세 미검출(`|t_c| < 2.0`)일 것.
- 5개 전부 같은 부호로 유의하면 M26 고유 약화가 아니라 **시대 공통 효과**로 라벨한다(측정·시장 구조 변화 포함).
- 0건(계열 산출 실패)은 PASS 아니라 **SKIP** 이며 정지 신호로 처리한다.

### A4. 필요 표본 (판정 불가 시 의무 산출)

`n_required = (t_threshold · nw_inflation · sd_modern / |mean_modern|)^2` 개월 → 연수로 환산해 부활 조건에 넣는다.

## 2. (B) 달력 계절성 — 슬라이딩 창 우선

### B0. 검정력 선판정 (착수 게이트)

`required_effect(n=24, t_threshold=2.0, sd_monthly=sd(해당 달 계수))`.
- 최대 후보월의 관측 효과가 필요치 미만이면 **측정 전 폐기**(그 달에 대한 주장 포기).
- 12개 달을 동시에 보므로 단일-달 문턱은 다중검정 미보정이다 → **주판정은 B1 순열검정**.

### B1. 주판정 — 연내 순열검정 (다중검정 보정)

- 통계량 1: `max_m mean(b_t | month=m)` (어떤 달이든 특별한가)
- 귀무: 각 **연도 안에서** 12개 계수의 월 라벨을 무작위 재배정(B=20,000). 연도 수준 평균·시대 구조 보존, 월 정렬만 파괴.
- **계절성 확립** = `p_max < 0.05`.
- 통계량 2(사전지정 단일 가설): 4월 — FY1 롤오버가 4/1 에 일어난다는 기전이 달을 *사전에* 지목하므로 `p_apr` 도 병기(보정 없음 라벨).

### B2. 슬라이딩 창 (버킷 경계 방어)

원형(12월↔1월 연결) 창 폭 `w ∈ {1,3,5}` 에서 각 창의 평균 계수.
- **고립 봉우리** = w=1 최대월의 초과(창평균 − 전체평균)가 w 증가에 따라 **희석**(w=3 초과 < w=1 초과의 0.7배, w=5 는 더 작음)
- **넓은 고원** = w=3/5 에서 초과가 유지되거나 커짐
- 보조: 하모닉 회귀 `b ~ Σ_{k=1..3} [sin,cos](2πk·m/12)` — 고립 스파이크는 고차 하모닉을 요구, 고원은 k=1 로 설명.

### B3. 이웃 구별

`mean(4월) − mean(3월,5월)` 의 순열 p. `p < 0.05` 여야 "이웃과 구별되는 달".

### B4. 시대 재현 (기술 통계, 검정 아님)

4월 효과를 전반(2003~2014)/후반(2015~2026)으로 나눠 부호·크기 보고. 저검정력이므로 판정에 쓰지 않는다.

### B5. 기전 후보 — **구별 관측을 먼저 고정한다**

| 기전 | 참일 때 관측되어야 하는 것 | 거짓일 때 |
|---|---|---|
| **FY1 롤오버** | 컨센서스-FY1 파생(M26)에만 4월 초과. 가격 모멘텀 M01 은 4월 초과 **없음**. 롤오버-수리 arm(FQ-223 RA)에서 4월 초과 **소멸** | M01 도 4월 초과 → 기각 |
| **결산 집중(연간 재무 3/31 가용)** | 재무 기반(SUE·ESBR·M26)에 4월 초과, 가격 모멘텀엔 없음. 4월 > 5월 | 가격 모멘텀에도 나타나면 기각 |
| **기관 리밸런싱 / 횡단면 분산 확대** | **전 팩터 공통** 4월 초과. 4월 `disp_t`(횡단면 수익 sd) 유의하게 높음. 계수를 `disp_t` 로 정규화하면 4월 초과 **소멸** | 정규화 후에도 초과 유지 → 기각 |
| **배당락** | FMB **절편**(수준)에 4월 이상, **기울기**에는 없음 | 기울기에만 있으면 기각 |

판정: 위 4개는 서로 다른 관측을 지정하므로 관측 패턴이 지지/기각을 결정한다. 어느 것도 지지되지 않으면 "미귀속"으로 남긴다.

### B6. 양성 대조 + 음성 대조 (같은 실행 안에서)

1. **위반 주입**: 4월에 알려진 크기(= B0 필요치의 1.0배)의 인공 효과를 더한 가짜 계열에서 B1 검정이 **검출**해야 한다. 미검출이면 검정 사망 → 중단.
2. **음성 대조**: 순열 null 에서 명목 5% 오탐률이 재현되는가(경험적 1종 오류).
3. **계절성 무관 축**: `M01_Mom_12_1` — 롤오버·결산과 무관한 가격 모멘텀. 여기서 4월 초과가 **나오면** 위 표의 상위 두 기전은 기각되고 시장-공통 기전으로 이동한다.
   ★08-08 기록상 M01 은 4·5월 제외 시 t 1.951→0.613 이므로 **이 대조는 이미 "무관 아님"을 시사** — 그래서 B5 판정의 핵심 축이다.
