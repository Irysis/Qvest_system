## 1. 오염 기전 (b5/b6 확정 — 재조사 불요)

`M26 = (revenue_fy1[최신] - revenue_fy1[<= sig_date-63L]) / |revenue_fy1[<= sig_date-63L]|`

FY1 = "다음 1년 기준 회계연도" 이므로 매년 **4월 첫 영업일**에 기준연도가 교체된다
(동시변경 lift `revenue_fy1` 10.81 · 상향 94.2% · 중앙 +33%).
sig_date - 63L 창이 4/1 을 가로지르는 sig 월 = **04, 05** (b6_s3, lag_days=63).
그 두 달의 M26 은 **개정률이 아니라 (FY_{n+1} 매출전망 / FY_n 매출전망 - 1) ≈ 애널리스트 기대성장률**이다.

★**PIT 위반 아님**: 두 끝점 모두 `Date <= sig_date`. 결함은 미래참조가 아니라
**구성 타당도(construct validity)** — 같은 이름을 쓰는 다른 신호가 2/12 달에 섞여 있다.
이 구분을 보고에서 흐리지 않는다.

### 2-2. 두 반증 방법 (둘 다 수행 · 서로 다른 반증)

### 2-3. 판정 규칙 (사전 고정)

- **철회(RETRACT)**: `t_B < 2.0`. (B 는 표본을 안 줄이므로 검정력 변명 불가.)
- **재확인(REAFFIRM)**: `t_A >= 2.0` **AND** `t_B >= 2.0`.
- **표본손실 교락(UNDERPOWERED_A)**: `t_A < 2.0` 이나 `t_B >= 2.0` 이고
  `t_A >= t_A_expected - 0.30`. 여기서 `t_A_expected = t_full * sqrt(n_A / n_full)`
  (= 4·5월이 평월과 같은 분포일 때의 기대 t). 이 경우 판정은 **재확인**, 라벨은 "A 는 검정력 미결".
- **오염 기여 확정(CONTAMINATED)**: 4·5월 계수 부분계열의 평균이 평월 평균을 **Welch t p < 0.05** 로 초과.
  (t_A/t_B 와 독립인 직접 분해 검정.)

### 2-4. 오염 비중 문턱 (C)

- **월수 share** = n(04,05) / n_full (구조적으로 ≈ 0.1667) — 기준선.
- **기여 share** = `n_AM * mean_coef_AM / (n_full * mean_coef_full)`.
  **물질적 = 기여 share >= 0.30** (월수 share 의 약 2배).
- **값 분포 배수** = median(|M26_raw|)[04,05] / median(|M26_raw|)[그 외].
  **물질적 = 배수 >= 2.0**.

### 2-5. 하류 전파 문턱 (B)
