## 라운드 중 자가 적발 → 결론을 바꾼 것 3건

### C-1. 형태 주장 전에 **부호 규약 정체 확인** (P1 → P2)
P1 이 D03_EWMA spearman **−0.685** 를 뱉었을 때, D03 은 변동성 계열이라 원열이 '높을수록 나쁨'이면
이 음수는 **발견이 아니라 규약**이다. P2 에서 rank-IC 를 직접 재니 **+0.0322(t +3.00)** — 정렬 정상.
W1 원 라운드도 저값 꼬리를 배제했다. ⇒ 음수 기울기는 실측으로 확정.
**이 확인 없이 보고했으면 규약을 발견으로 팔 뻔했다.**

### C-2. 유니버스 차감이 패턴을 만들었을 가능성 (P3 → P4 혐의 1)
gap 정의에 유니버스 평균/중앙값 차감이 들어가 있어 패턴이 차감항의 산물일 수 있었다.
생(raw) 값으로 재산출하니 spearman 3개(−0.685 / +0.503 / −0.988)가 **완전 동일**. 혐의 기각.

### C-3. **내 가설이 틀렸고 그걸 내가 잡았다** (P4 혐의 3)
"D10 평균 −5.12% 는 소수 극단 음수월 지배"라는 내 해석은 **틀렸다**.
D10 양(+)월 비율 **0.472 < 0.5**, 월 중앙값 초과도 음수(−0.00315). 최악 5개월 제외해도 부호 불변(−2.48%).
⇒ 시계열 이상치 이야기 폐기. 괴리는 **순수 횡단면**이다.
★정정이 기전을 **강화**했다 — 잡음이 아니라 구조라는 뜻이므로.

## 남은 약점 — 반증 가능한 형태로

### W-1. E4(시대 조건부)는 검정력과 미분리 (★가장 큰 과장 위험)
M26·M01 이 post2015 decile 에서 MONOTONE_TOP → UNCLASSIFIED 로 바뀐다. 그러나 post2015 는
**138개월 × 10분위**라 분위당 표본이 얇다. class 변화가 형태 변화인지 검정력 부족인지 **분리되지 않았다**.
→ 처분: `verdict.E4.fired = "partial"` + caveat 명시. '형태는 시대 조건부'를 확립으로 쓰지 않는다.
[[project-conditional-splits-destroy-power-20260808]] 규약 정합.

### W-2. 형태 class 가 해상도에 민감 — 규칙 자체의 취약성
M01_PATHQ: 5분위 UNCLASSIFIED vs 10분위 MONOTONE_TOP. Q01_EB: 5분위 UNCLASSIFIED vs 10분위 HUMP.
내 분류 규칙(argmax 위치 + spearman 문턱)이 해상도에 걸린다는 뜻이다.
→ 처분: 형태 인용 시 **해상도·창 병기 의무**를 판정문에 넣었다. 규칙을 규약으로 승격하려면
   해상도-불변 통계(예: 상단 k% 초과의 연속 함수)로 재설계해야 한다 — 미측정.

### W-3. 프레임 통일의 대가를 아직 안 쟀다
동일-행 조인이 W1 패널의 **20.3%** 를 떨어뜨렸다(잔존율 0.797). 따라서 여기의 Q01/D03 프로파일은
원 라운드 값과 다를 수 있고, WT-003 의 5분위 혹 `[−3.81 +1.37 +3.05 +1.78 −2.41]` 과
본 라운드 Q01_neutral post2015 5분위 `[−5.35 +3.49 +3.71 +1.16 −2.92]` 은 **닮았으나 같지 않다**.
→ 처분: '재현'이 아니라 '동일 프레임 재산출'로 라벨. 차이를 프레임 효과로 귀속하려면
   유니버스 축을 따로 통제해야 한다(미측정).

### W-4. 형태 → 소비면 대응은 가설이다
"MONOTONE_TOP 은 상단 랭킹, HUMP 는 중간분위" 는 그럴듯하나 **각 형태에서 실제 소비면 성과를 잰 적이 없다.**
WT-003 이 중간분위를 제안했지만 그것도 미측정이다.
→ 처분: `implication.scope_honesty` 에 가설임을 명시. 규약 제도화 제안은 실측 후로.

### W-5. D03 기전의 일반화 범위
"rank-IC 가 왜도-상관 신호에서 위험" 은 **D03 단독 관측**에서 나왔다(다른 4재료는 부호 갈림 없음).
변동성 계열 1건으로 '계열 전체' 를 주장하면 [[project-data-freshness-impact-depends-on-factor-position-20260808]]
("한 항목의 negative 를 다른 항목에 일반화 금지")의 반대 방향 위반이다.
→ 처분: 판정문에 '변동성 계열에서 특히 위험' 으로 한정. vol/tail 8종(FQ-108d) 전수 확인이 next_probe.

### W-6. 분위 t 값들이 대체로 작다
형태 class 는 **점추정 패턴** 판정이며 각 분위 초과의 유의성 주장이 아니다(D03 D10 t −1.90, M26 D10 t +2.99).
→ 처분: 사전등록 `power_discipline.no_claim_rule` 대로 UNCLASSIFIED = '판별 못함'이지 '형태 없음' 아님.
