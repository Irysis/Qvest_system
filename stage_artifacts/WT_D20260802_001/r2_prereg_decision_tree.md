# FQ-073 R2 — 판정 분기 사전등록 (결과 도착 전 작성)

**작성 시각**: 2026-08-02 05:0x, **R2 결과 도착 전**. Q-Lead.
**목적**: 결과를 보고 나서 해석 틀을 만들면 사후 합리화가 된다. R1 에서 falsification 문턱(t≥2)을 실측 1.969 에도 **이동시키지 않은 것**이 판정의 정직성을 지켰다. 같은 규율을 R2 해석에도 적용한다.

## 핵심 판별 축 (이 라운드가 답하는 단 하나의 질문)
> R1 의 소형주 국소화(보유 **OTHER 88.9~91.9%** / MEGA 5.95% / MID 5.13%)가
> **경제적 실체인가, 크로스워크 아티팩트인가.**

R1 크로스워크는 HS4 산업 수출성장률을 버킷 내 전 기업에 **균등 배분**했다. 그러면 신호 강도가 실제 수출 노출이 아니라 **버킷 변동성**에 지배되고, 고변동 니치 HS4 = 소형주로 몰린다. materiality 재척도가 이 교란을 제거한다.

## 사전 분기 (4갈래 — 어느 쪽이든 정보성)

**A. cap-tier 이동(MEGA+MID 합계 유의 상승) ∧ PORT_t 개선(음수 → 0 이상 또는 유의 상승)**
→ R1 국소화는 **아티팩트**였다. 수출 lane 재개. 다음: 회전율 제약 내에서 forge dossier 승격 여부 검토(단 HARD 3종은 불변 — PORT_t 2.95·oos 0.7·calmar 0.64). **가장 좋은 결과이자 가장 경계할 결과** — 재척도가 사실상 size 팩터를 주입한 것은 아닌지 반드시 확인(materiality 분모가 시총이면 저size 편향을 기계적으로 뒤집는다). size 중립화 후에도 남는지 검증 전에는 승격 금지.

**B. cap-tier 이동 ∧ PORT_t 여전히 음수/무의미**
→ 신호는 대형주에 **도달하나 정보를 싣지 않는다**. R1 의 F5(cap_rank≤100 제한, PORT_t −0.328 p 0.743)와 **독립 경로로 같은 결론**에 도달한 것 = 강한 확증. 수출 nowcast 의 selection 면은 config-scoped negative 확정. 소비면은 monitoring(수출 급감 tripwire)으로 한정. next_probe 는 신호 정의가 아니라 **원천 축**(vintage 크로스워크 / 해외생산 보정)으로 이동.

**C. cap-tier 미이동(OTHER 여전히 80%+)**
→ 소형주 국소화가 **경제적 실체**다. 크로스워크 균등배분 탓이 아니라 **수출 정보 자체가 소형주 현상**(대형 수출주는 이미 커버리지·애널리스트 밀도가 높아 정보가 선반영). 이는 병목 지도 ①재료 계층에 **재료-불변 벽의 새 실측 1건**을 추가한다 — 비-return 원천이라도 cap-tier 국소화를 벗어나지 못한다는 명제 강화. next_probe 는 "수출을 대형주에 실리게 하는 법"이 아니라 **애초에 대형주에만 존재하는 원천**(FQ-084 외국인 활동·FQ-085 옵션 — 후자는 08-02 실측상 데이터 부재)으로 전환.

**D. 회전율 평활 후 신호 소멸(3M/6M 누적에서 PORT_t 악화)**
→ 고빈도 성분이 본체였다는 뜻 = **배포 불가 확정**(제약 1100% 안에서는 신호가 남지 않는다). A~C 와 독립으로 성립하며, D 가 참이면 A 여도 배포 경로가 없다. **D 판정을 A 의 낙관으로 덮지 말 것.**

## 해석 규율 (사후 이동 금지)
- cap-tier "이동"의 기준은 **MEGA+MID 합계가 R1 대비 유의 상승**. 눈대중 금지 — R1 수치(MEGA 5.95 / MID 5.13 / OTHER 88.92)와 직접 대조.
- PORT_t 는 **cap-w 가 권위**, EW-uni 는 dual-basis 병기. EW 가 좋아도 cap-w 가 음수면 B/C 로 읽는다.
- 회전율은 **1100%/yr 이 hard 제약**. 초과분은 부호와 무관하게 측정 자격 없음(R1 이 그랬다).
- `metric_type` 라벨 없는 수치는 판정에 쓰지 않는다.
- 어떤 분기든 **next_probe ≥2** 와 부활 조건을 남긴다.

## 이 문서의 용도
R2 보고 도착 후 이 파일을 먼저 읽고 분기를 고른다. 결과가 A~D 어디에도 안 맞으면 **그 사실 자체를 보고**하고(예상 밖 = 정보), 새 분기를 만들되 **이 문서는 수정하지 않는다**(사전등록 무결성).
