## 라운드 중 자가 적발 → 실제로 결론을 바꾼 것 2건

### C-1. K=6 위상 미검 (P3 → P4) — **결론을 뒤집음**
P3 은 위상 민감도를 K=3 에서만 쟀다(스프레드 0.141). K=6 은 위상이 6개인데 offset=0 하나만 측정된 상태로
"+0.467 개선"을 보고할 뻔했다. P4 에서 전 위상을 재자 스프레드 **1.291**(0.841~2.133), 2/6 위상만 기준선 상회,
위상평균 1.584 ≈ K=1 1.544. **"개선"은 추첨이었다.**
→ 교훈: 위상/시드 자유도가 있는 연산자는 **전 자유도를 돌기 전 어떤 값도 보고하지 않는다.**

### C-2. arm 나열 = 차이 검정 아님 (P4 → P5) — **판정 등급을 낮춤**
P4 까지는 arm 별 PORT_t 를 나란히 놓고 비교했다. 그건 차이의 유의성이 아니다.
P5 paired NW3 검정에서 11셀 전부 |t| < 2.0(최대 0.858), 필요 효과 연 3.01~5.55% vs 관측 −2.70~2.00%.
→ "회전율 레버 있음"이 아니라 **"검출 못함(INCONCLUSIVE_UNDERPOWERED)"** 이 정직한 라벨.

## 남은 약점 — 반증 가능한 형태로

### W-1. 위상 일반화가 과장될 수 있다 (★가장 큰 위험)
"리밸 위상이 PORT_t 를 0.8~1.3 t 흔든다"는 **staleness 연산자(K≥2) 위에서만** 실측됐다.
K=1(현행 월간 리밸)은 위상 자유도가 **원리적으로 없다**. 따라서 이 관측을 "현행 book 측정도 추첨 성분을 포함한다"로
확장하면 **범주 오류**다 — 2026-08-08 capw−EW 오독(벤치-측 상수를 포트폴리오 진술로 읽음)과 같은 계통.
→ 처분: `alpha_validation.json::system_level_finding.scope_honesty` 에 범위 제한을 명시했고, book 일반화는
   **미측정 NP-4** 로만 등재한다. 병목 지도·메모리에 "일반 사실"로 쓰지 않는다.

### W-2. gross 손실 ≈ 비용 절감의 "정확한 상쇄"는 과잉해석 위험
1.17%p vs 1.20%p 는 인상적이나, paired 검정력이 3.01~5.55%/yr 다. 즉 이 창에서는 **±3%p 차이도 구별 못한다.**
"정확히 상쇄"는 점추정의 우연일 수 있다.
→ 처분: 본문에 "거의 정확히"로 쓰되 판정은 INCONCLUSIVE 로 고정. 상쇄를 기전으로 승격하지 않음.

### W-3. CH-B(decile)와 CH-A/C(canonical)의 프레임이 다르다
decile 은 비용 미적용·벤치는 유니버스 EW. canonical 은 비용 15bps·벤치 cap-w.
D10 의 +6.55%(t 2.82)를 canonical PORT_t 와 같은 자로 읽으면 안 된다.
→ 처분: `caveat` 에 명시. 단조성 판정(D2)은 **decile 내부 비교**라 프레임 차이에 영향받지 않는다 — D2 반증은 유효.

### W-4. 벤치-측 상수 0.777 t 는 **수입한 사실**이다
"capw−EW 격차 = arm 무관 벤치-측 상수"는 FQ141_NPA(2026-08-08, 12 arm sd 0.00106)에서 확립됐고
본 라운드가 재확인하지 않았다. M26 에서 이 성분이 정말 상수인지는 **미검**.
→ 처분: ladder 의 해당 step 에 근거를 라벨. M26 고유 검증은 NP 로 등재하지 않음(저가치 — 이미 12 arm 실측).

### W-5. P2 예측이 틀렸는지 여부가 아직 미결
"K 확장은 개선하지 못한다"는 방향으로는 유지되나(paired 평균 t: K3 +0.30 / K6 −0.15),
검정력이 없어 **확정할 수 없다**. 예측이 맞았다고 쓰면 무검정력 null 을 기각으로 오독하는 것이다.
→ 처분: `final_reading` 에 "방향 유지, 확정 불가" 로 기록.

### W-6. lag1 retention 0.233 과의 화해가 아직 이야기 수준
FMB 한계 기울기(통제 3종 하)와 포트폴리오 보유 성과는 다른 추정량이라는 설명은 **그럴듯하나 미측정**이다.
gross 알파가 K=1→6 에서 7.62→6.45%(−15%) 로만 떨어지는 것은 retention 0.23 과 표면상 어긋난다.
→ 처분: 원장에 확립으로 쓰지 않는다. NP-5 로 등재.
