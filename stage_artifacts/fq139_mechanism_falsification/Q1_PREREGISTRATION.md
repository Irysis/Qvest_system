# Q1 사전등록 — 상대적 소형주 비유동성의 알파-강도 조건화

**작성**: 2026-08-08 (측정 **전**). **상태**: 봉인 제안본 — 이 문서 확정 후에만 Q1 측정 착수.
**왜 사전등록인가**: 근거가 된 상관(Spearman −0.3449, p=0.0021)은 **오늘 세션의 다중 비교 맥락**에서
나왔다(9종 신호 실패 · 국면 분해 · 유동성 2단계 등 수십 개 검정 뒤의 단일 상관). 방향도 직관과
반대다. 이 상태로 문턱·정의를 사후 선택하면 사후 발견을 사후 검증하는 동어반복이 된다.
FQ-138 이 정확히 그 이유로 사전등록 재판정 대상이 된 선례를 따른다.

## 1. 가설 (방향 포함, 사전 고정)

**H**: 계약수주 알파의 월별 횡단면 IC 는 **상대적 소형주 비유동성이 높은 달에 더 크다**.
즉 `sl_ratio = median(adv | size 하위 50%) / median(adv | size 상위 50%)` 가 **낮을수록** IC 가 높다
→ 예측 부호 **rho < 0**.

**기전 후보 (사전 서술 — 사후 끼워맞춤 방지)**
- ①정보 확산 지연: 비유동 국면엔 공시 정보의 가격 반영이 느려 신호 수명이 길다 → IC 상승
- ②군집 회피: 유동성 풍부 국면엔 동일 신호 참여자가 많아 알파가 조기 소멸 → IC 하락
- ③(배제됨) size 교락: **Q2 에서 기각** — 대형 반절 rho −0.2717(p=0.0163), 소형 −0.1949(p=0.087)로
  효과가 소형에 몰려 있지 않음

## 2. 사전 고정 사양 (측정 전 확정 — 변경 시 새 사전등록)

| 항목 | 값 |
|---|---|
| 신호 | `panelx_A::w_amt` (0값 0% 로 분위 형성 가능한 유일 신호 — F1 실측) |
| 수익 | `gridx_returns::Ret_1m` (익월, 선행 규약 — G1c 확인) |
| IC | 월별 Spearman(rank(w_amt), rank(Ret_1m)), 월 표본 **≥12** |
| 유동성 | `gridx_liq::adv` 만 사용 (회전율·Amihud 등 대안은 **별도 사전등록**) |
| size 분할 | `gridx_universe_size::Size` 월별 중앙값 |
| 기간 | gridx 전 구간 (2019-11~2026-06, 78~80개월) |
| 통계 | Spearman rho + 블록 부트스트랩(block=6, B=4000) 신뢰구간 |

## 3. 판정 규칙 (봉인 — 결과를 보기 전에 고정)

- **PASS**: 부트스트랩 rho 분포의 **q05 < 0** (즉 95% 하한이 음수) **∧** 점추정 rho ≤ −0.20
- **FAIL**: 위 미충족
- **부분**: q05 < 0 이나 |rho| < 0.20 → 방향만 인정, 크기 미확정 (소비 불가)
- ★**점추정 p-value 단독 판정 금지** — 다중 비교 맥락이므로 분포 하한으로 판정 (FQ-109 규약)
- ★**서브샘플 분할·문턱 탐색으로 PASS 를 만들지 않는다**. 위 사양 외 변형은 전부 새 사전등록

## 4. 소비 경로 (PASS 시에만, 사전 명시)

1. **조건화 게이트**: 계약 재료를 `sl_ratio` 하위 국면에서만 소비 — 단 이건 **재료 자격**이지 자본 편입이 아니다(PORT_t 별도 심사)
2. **미소비 확정**: 오버레이 β 매핑 입력으로는 쓰지 않는다 — overlay 층은 오늘 네 자유도가 닫혔고(I1/K2/L2) 새 입력을 넣을 자리가 없다
3. FAIL 시: `sl_ratio` 조건화는 config-scoped negative 로 기록하고, 잔여 기전 후보 ①②는 다른 관측면으로 이동

## 5. 부활 조건 (INV-7)

FAIL 이어도 다음에서 재도전: ①유동성 정의를 회전율·Amihud·호가스프레드로 교체 시 ②기간을 gridx 밖
(2019 이전)으로 확장할 수 있게 되면 ③기전 후보 ①②를 **직접** 관측할 수단(신호 수명·참여자 수 대리변수)이
생기면 — 그때는 IC 상관이 아니라 기전 자체를 재는 라운드로 설계한다.
