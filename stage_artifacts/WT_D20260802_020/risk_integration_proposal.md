# Risk Integration Proposal — 단기창 꼬리-변동성 축 (WT-D20260802_020, FQ-112)

**성격**: 설계 제안 문서만 — 실배선·Σ 수정·risk_package 변경 없음 (역할 경계, request 명시).
**수신**: Q-Lead → risk-research agent (채택 시 별도 라운드로 실배선).

## 0. 한 줄 결론

위험모델에 필요한 것은 **MAX5 그 자체가 아니라 단기창(63d) 꼬리-변동성 축**이다.
MAX5의 crash 발생률 증분(FM t +13.15)은 252d 표준 축 대비로만 실재하고, 동일 63d 창
vol63+dsd63 통제 시 소멸(t +0.95). 따라서 제안은 "MAX5 팩터 추가"가 아니라
"단기창 변동성 정보의 위험 축 편입"이며, 그 구현체 선택은 아래 우선순위를 따른다.

## 1. 실측 근거 (본 라운드, 256개월, n=76,080)

| 항목 | 값 | 함의 |
|---|---|---|
| top-decile crash 발생률 | 21.4% vs base 10.1% (2.11배, t +17.7) | crash-name 사전 식별력 실재 |
| 십분위 발생률 | 3.9% → 21.6% 단조 | 문턱 설계 자유도 높음 |
| 전 국면 성립 | b_max5 t: RISK_ON 13.4 / NEUTRAL 2.5 / CAUTION 3.5 / CRISIS 2.3 | 위험지표는 위기에도 유효 (배제 필터와 다름) |
| cap-tier | MEGA t 2.5 / MID t 3.4 / OTHER t 17.0 | 배포 유니버스에서도 유효 |
| 평균수익 스프레드 | t −0.12 | ★수익 랭킹/스케일링 소비 금지 |
| 포트 노출 → tail | 사전 노출 +0.273 vs −0.077 (Wilcoxon p 0.001), 선형 OLS 무유의 | 문턱형 tripwire 적합 |

## 2. 구현체 우선순위 (채택 라운드의 사전등록 대상)

1. **DB-native 재사용 (최우선 검토)**: `D34_RealVol_21d` / `D42_EWMA_Vol` 이 이미 factor DB에
   존재 — 이들이 max5의 crash 증분을 흡수하는지 FM 재시험(next_probe 1). 흡수 시 신규 팩터
   불요, risk_package 진단에 기존 팩터 배선만.
2. **동일창 직산**: vol63/dsd63 (ot_w1_lib 계열 코드 경로 재사용) — max5보다 싼 등가물 실측 확인.
3. **max5 직접**: 위 둘이 실패할 때만 (현재 근거상 예상 낮음).

## 3. 소비 지점 설계 (risk_package 스키마 — 제안만)

- **A. crash-name 진단 필드**: `risk_package.diagnostics.short_window_tail` =
  {ticker별 단기창 꼬리 z, top-decile 플래그, 예상 발생률(십분위 매핑)}. Σ 추정과 독립인
  *진단 사이드카* — 공분산 수정 아님. stress 시나리오의 name-level 후보 목록 입력.
- **B. monitoring tripwire**: 포트 가중 단기꼬리-z 노출 > 문턱(후보 +0.25, 사전등록으로 고정)
  시 알림. 근거: 하위 5% active 월 이전 노출 유의 상승(p 0.001). 연속 스케일링 금지(선형 무유의).
- **C. 국면 결합 주의**: 배제/축소 등 *평균수익* 소비를 이 축에 결합하는 것은 스트레스 국면에서
  역효과(CAUTION ret_spread +1.76%/월 t +2.08) — 발생률 소비(진단·예산·알림)로 한정할 것.

## 4. 명시적 비제안 (경계)

- 공분산행렬 Σ 추정·수정 제안 아님 (Risk Agent 자율 영역).
- weight/배제 규칙 제안 아님 (Optimizer 영역 — WT-014 필터는 별도 실측 완료 자산).
- 본 문서의 어떤 항목도 실배선되지 않음 — 채택 시 risk-research 라운드에서 사전등록 후 실측.

## 5. 부활/폐기 조건

- NP-1(DB-native 통제)에서 D34/D42가 증분을 흡수 못 하면 → 63d 창 특이성 실증 → 2안 채택.
- 흡수하면 → 기존 팩터 배선으로 종결(신규 축 불요) — 이 문서의 1안으로 수렴.
