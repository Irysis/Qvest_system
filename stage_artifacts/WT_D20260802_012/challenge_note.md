## C1. ★내가 거의 잘못 보고할 뻔한 것 — "창-정합 통제가 보조축의 개선을 입증한다"

**최초 읽기(오독)**: 전체월 기준으로 A′ SUSTAIN-vs-OFF 가 A 대비 약해 보였다(REST t +3.52 → +2.07). 창-정합(A 발화월로 월집합 고정) 통제를 돌리니 **역전** — A′ 가 오히려 강했다(REST +3.52 → **+4.11**, MID +3.90 → **+4.14**, ALL +3.29 → +3.71). 채널 분리에서 커버리지 채널은 Δt **정확히 +0.00**, 보조 flag 채널이 개선 전량. 여기서 멈췄다면 "보조축은 기존 월에서 신호를 강화한다"고 보고했을 것이다.

**적대 질문**: 그 개선을 만든 관측치가 몇 개인가?

**실측 반박** (`r43_mechanism.json`): 창-정합 126개월에서 라벨이 바뀐 name-month 는 **총 269개**(전체 커버 ~9,500 중 2.8%)뿐이고, A′ SUSTAIN 2,906개 = 기존 2,769 + **신규편입 137**. 슬라이스별 신규편입은 MID **n=20**, REST n=80. 이행 셀별 무신호 대비 paired-t 는 전부 2 미만:
- `ENTRY→SUSTAIN` n=49, t=**+1.56** (가장 좋은 셀이지만 유의 미달)
- `OFF→EXIT` n=56, t=+0.03 / `OFF→SUSTAIN` n=72, t=**−0.17** / `OFF→ENTRY` n=64, t=**−0.56**

게다가 신규편입 SUSTAIN 은 기존 SUSTAIN 보다 **하방·급락이 더 나쁘다**(하방 −7.40% vs −7.14%, 급락 5.84% vs 5.02%).

**결론**: 창-정합 Δt(+0.24 MID / +0.59 REST)는 20~80개 관측치가 만든 수치이며 개별 유의성 없음. **증분 증거로 쓸 수 없다.** 보고서에서 "창-정합이 개선을 보였다"는 서술은 폐기하고, "창-정합은 겉보기 희석이 오염이 아님을 보였을 뿐, 개선을 입증하지 못한다"로 교정했다. 판정(UNDERPOWERED / 배선 기각)은 변경 없음.

## C2. "현 북 4종목 발화 변화"는 부풀린 숫자다

스크립트가 낸 `n_changed=4` 중 3건(CASH / A420770 / A082920)은 **라벨 이름만** 다르다(`NO_INS02` → `NO_INS_DATA`) — 두 축 모두 데이터가 없는 종목이라 실질 상태 변화가 아니다. **실질 발화 변화는 1건**(A005930, 비중 3.64%: NEUTRAL → NET_BUY_SAFE). 보고 본문에서 1건으로 정정.

## C3. 동질성 판정(HOMOGENEOUS_WITH_A_SAFE)을 "동등하다"로 읽으면 안 된다

사전등록 규칙이 기계적으로 `|t|<2 → HOMOGENEOUS` 를 냈다(t=−0.31). 그러나 MID 에서 두 그룹이 **같은 달에 동시에 존재하는 월이 97개월 중 21개월(21.6%)뿐**이다(`r43_followup.json` F2). 보조축은 주축이 **침묵한 달**에 주로 발화하므로 paired 동질성 검정은 구조적으로 저전력. 사전등록에 D4 검정력 하한을 넣지 않은 것이 설계 미비였다 — **no-flip 원칙상 규칙은 바꾸지 않고**, 판정을 "동등의 증거 아님 · 검정력 제약(21개월)"으로 라벨링해 보고한다.

## C4. worst-case 대입이 아무것도 안 바꿨다 — 검사 사망 아닌가

D7 에서 진성폐지 −100% 대입 전후 수치가 **완전히 동일**했다. "빈 결과 = 합격" 계통 의심. 양성 대조(IT-4)를 추가로 주입: 합성 폐지 3건을 넣자 급락 0.0633 → 0.0807, 하방 −0.0730 → −0.1106 으로 **반응**. ⇒ 대입 경로는 살아있고, no-op 은 해당 base 에 진성폐지가 실제로 0건(R40 동일 실측)이기 때문. 검사 사망 아님.

## C5. 두 축이 z=1.0 에서 같은 선별강도가 아니다 (구조적 비대칭)

문턱을 A축(INS_NB_THR=1.0)과 대칭으로 고정한 것은 자의 배제 목적이었으나, **INS02 는 유계 비율**((매수건−매도건)/(총건), 상한 +1 에 질량 집중)이고 **MAGQ3 는 무계 signed-cr 합**이다. 결과적으로 같은 z=1.0 이 전혀 다른 선별을 한다:
- INS02: **253개월 중 126개월(49.8%) 에서 최대 z 가 1.0 에 도달조차 못 함**(침묵월 max z 최대 0.99968)
- MAGQ3: 17,836행 중 1,502행(8.4%) 통과, 현 홀딩월 max z = 4.42

즉 본 라운드의 "A vs A′" 비교는 **선별강도가 정합되지 않은 비교**다. 이는 판정을 뒤집지 않지만(보조축은 더 관대한 쪽인데도 증분 미달), 다음 라운드의 1순위 설계 결함으로 기록한다 → NP-1.
