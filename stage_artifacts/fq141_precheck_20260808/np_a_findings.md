# NP-A 결과 — capw−EW 격차는 **벤치-측 상수**다 (2026-08-08)

**라운드**: FQ-141 NP-A (도훈 선택). **판정: H0 채택 — 격차에 포트폴리오 정보 없음.**
**metric_type**: `canonical_screen_diag` (벤치 basis 진단. 자본 게이트 비바인딩)
**하네스**: WT-D20260803_007 동일 vintage (`RAWDATA` + `build_monthly_forward_returns`), 비교는 계약 함수 `build_benchmark_compare` 경유
**산출**: `np_a_bench_decomposition.R` · `np_a_bench_diff.csv` · `np_a_results.rds`

## 1. 사전 서술한 판별식 (측정 전 고정)

```
active_capw_t = ret_net_t − BM_capw_t
active_ew_t   = ret_net_t − BM_ew_t
⇒ active_capw_t − active_ew_t = BM_ew_t − BM_capw_t ≡ −d_t     (ret_net 소거)
```
H0(벤치-측): `d` 가 arm 무관 상수 · H1(arm-측): `d` 가 arm 마다 달라 격차에 구성 정보가 실림.

## 2. 실측 — H0

비교가능 집합 = OOS 창 동일한 **n=167 arm 12개** (`SS_*` 3개는 n=96 별창이라 분리):

| 축 | 값 |
|---|---|
| `d_alpha_ann` 평균 | **+3.82%/yr** |
| `d_alpha_ann` **sd** | **0.00106** (0.106%p) |
| `d_alpha_ann` 범위 | [0.03559, 0.03917] — 스프레드 **0.359%p** |
| `capw_mean` 고유값 개수 | **1** (0.009541984 — 동일 벤치, 정의상) |
| `ew_mean` 범위 | [0.006775, 0.007030] (arm별 패널 커버리지 차 = 미미) |
| 월 격차 | **0.269%/month** |

즉 **cap-w 유니버스 벤치가 EW 유니버스 벤치보다 연 3.82% 더 벌었다**(2012-08~2026-06).
top-25 EW 포트폴리오는 구성과 무관하게 cap-w basis 에서 이 **동일한 핸디캡**을 지불한다.

⚠ 정직: `d` 자체의 `d_t_nw3` ≈ 0.75~0.80 (p≈0.43) — 월간 변동이 커서 **격차가 0과 유의하게
구분되지는 않는다**. NP-A 가 확정한 것은 "격차가 크다"가 아니라 **"격차가 arm 무관"** 이다
(H0/H1 판별축이 그것이므로 판정에 필요충분).

## 3. 독립 정합 축 — 창을 바꾸면 둘이 같이 움직인다

`SS_*` arm 3개는 다른 창(n=96)에서 측정됐다:

| | `d_alpha_ann` | 평균 \|gap\| |
|---|---|---|
| n=167 (12 arm) | 0.03820 | 0.903 |
| n=96 (SS_ 3 arm) | 0.09387 | 2.134 |
| **비** | **2.46배** | **2.36배** |

격차가 포트폴리오 구성에서 왔다면 창을 바꿨을 때 벤치 수익차와 **같은 비율로** 움직일 이유가 없다.
2.46 vs 2.36 은 벤치-측 가설의 예측과 정합한다. (WT-007 이 `SS_*` 를 가장 나쁜 gap(−1.95~−2.27)으로
보고한 것도 이 창의 `d` 가 컸기 때문이다 — 구성 탓이 아니다.)

## 5. 종합 판정

1. capw−EW 격차 = **벤치 수익차(연 3.82%) 이며 arm 무관**. 포트폴리오-측 개입으로 격차 자체는 못 줄인다.
2. 포트폴리오가 바꿀 수 있는 것은 `mean(ret_net)` 과 active 변동성(PORT_t 분모)이지 `d` 가 아니다.
3. cap-w 에서 이기려면 사이즈 노출을 **제거**하는 게 아니라 cap-w 벤치를 끌어올린 이름을 **담아야** 한다
   — 그건 비중-측 cap-tilt 이고 R4 가 2.100 에서 천장을 봤다.
4. ∴ FQ-141 원안(선별-측 사이즈 중립)은 EV 최하위로 재배치. **"EW basis 2.86 을 옮긴다"는 서술 자체가
   회수 불가능한 양을 지칭**한다.
