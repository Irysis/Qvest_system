## 1. 이 라운드의 실제 문제는 sizing 이 아니었다

수신 사양(alpha 생산 = 근접도 top-25 등가중)의 **연 양방향 회전 = 15.31** 이다.
`constraint_defaults.json::turnover_hard_fail_annual = 11.0`(round-trip) 을 **이미 위반한 상태**로 넘어왔다.

그래서 사전 선언 단계에서 회전을 **선택 취향이 아니라 hard 실격 게이트(G5)** 로 박았다.
이건 "회전 축이 자연스러워 보여서" 고른 게 아니라 제약이 이미 깨져 있었기 때문이다.

## 3. 왜 MVO 가 졌나 — 회전은 selection 에서 나온다

- **M4 (MVO + 명시 회전 페널티 φ=40.5bps)** 는 회전을 15.149 → **14.125 밖에** 못 줄였다(−6.8%).
  candidate set 이 매달 새 top-25 로 강제 교체되므로 **sizing 페널티가 볼 수 있는 것은 집합 내부 churn 뿐**이다. 매달 15.8종이 통째로 갈리는 것은 목적함수에 보이지 않는다.
- 반면 **buffer 는 selection 을 붙잡아** 신규 편입을 15.76 → 10.46종/월로 줄인다. 회전 −32.6%.
- 그리고 MVO sizing 은 net_IR 을 **0.2598 → 0.0628** 로 파괴했다. HHI 0.040 → 0.053, 최대비중 4% → 15.8%.
  **DeMiguel-Garlappi-Uppal (2009) 의 1/N 우위 + Grinold breadth 를 이 데이터에서 재확인**했다.
  25종 broad-alpha 에서 집중은 net 성과를 깎는다 — Cycle 2 L-code posterior 그대로다.

## 6. β 를 위험 대리로 쓰지 않았다는 실증

- 목적함수 `max w'(c∘α̂) − (λ/2)w'Σw − ψΣw²(1−c)² − φΣ|Δw|` 에 β 항 없음.
- 게이트 G1~G6(종목수·부호·합·유니버스·회전·schedule) 전부 β 무관.
- 선택축 = net_IR 단일. β 는 진단 컬럼으로만 기록.
- **판별 증거**: β 를 위험 대리로 썼다면 최저 β arm(M4, β 0.596)이 선택됐어야 한다. 그 arm 은 net_IR 로 탈락했다.
  선택 method 의 β 0.722 는 baseline 0.727 과 사실상 동일하다 — **β 를 움직이려 하지도 않았다.**
- 위험 축은 **EVT** 로 병기: GPD ξ 0.144 · ES99(월) **0.2123** (baseline 0.2170). 정규 CVaR 미사용(Hill α 2.93).
  ★ baseline ES99 0.2170 은 risk `tail_risk.json` 의 0.216905 를 **독립 재현**한다.
  ★ COVID 구간 실현 β 0.66 · 하방 TDC 0.545 — 저-β 는 여전히 위험 축소가 아니다.

## 7. D floor 편향 진단 (최소분산 계열 사용분)

25종 book 안에서 p10 바닥이 월평균 **3종**의 특이분산을 **6.06%** 끌어올린다. 그 3종은 체계적으로:

| | floor 대상 3종 | 보유 25종 평균 |
|---|---|---|
| SIZE 노출 | **+1.502** | +0.385 |
| VOL 노출 | **−0.794** | −0.104 |

→ 바닥은 **대형·저변동 종목의 D 를 인위적으로 올린다**. 최소분산형 목적함수는 정확히 그 종목들을 덜 선호하게 된다.
risk 의 경고를 시계열로 정량 확인했다. 추가로 `corr(D_raw, VOL 노출)` 시간평균 **+0.574**(risk as-of +0.768 과 동부호) —
**D 를 독립 잡음으로 보면 변동성 집중이 안 보인다**는 진술의 시계열 확증이다.
★ **선택된 M2 는 Σ 를 쓰지 않으므로 발행 비중에 대한 이 편향의 영향은 0 이다.**

노출 bound 를 제약으로 걸지 **않았다** — 사전 선언 게이트에 없었고 사후 추가는 사전등록 파기이기 때문이다. next_probe 로 넘긴다.
