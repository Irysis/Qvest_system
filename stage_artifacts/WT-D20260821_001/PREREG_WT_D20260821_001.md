## 2. 바꾸는 것 = 학습기뿐 (3-arm, 파라미터 사전 고정 · HPO 금지)

| arm | 표적 범함수 | 추정기 (표준 구현만) |
|---|---|---|
| `L_mean` | 조건부 평균 | OLS 최소제곱 — R `.lm.fit()` |
| `L_q50` | 조건부 중앙값 τ=0.50 | `quantreg::rq.fit(tau=0.50, method="fn")` (Koenker Frisch-Newton) |
| `L_q90` | 조건부 상방분위 τ=0.90 | `quantreg::rq.fit(tau=0.90, method="fn")` |

**정칙화 = 없음 (challenge_flags 6항의 선택지 (ii) "무정칙 + 조건수 기록").** 단 무정칙이 성립하려면
설계행렬이 full rank 여야 하므로 아래 **조건화 규약**을 함께 고정한다.

### 2.1 조건화 규약 (측정 전 고정 · 3 arm 공통 · 탐색 없음)

각 예측월 m 에서, **학습창(`sig_date < m`) 만으로**:
1. 열 표준화 — 학습창의 평균/표준편차로 z 화(sd<1e-12 이면 1 로 대체). 검정월은 **학습창 통계**로 변환.
2. 랭크-노출 QR — `qr(Z, tol = 1e-8)$pivot[1:rank]` 로 full-rank 열 부분집합 `K_m` 선택.
   버려지는 열 = **정확 alias(수치적 영행공간)**. R `lm`/`rq` 의 내부 aliasing 처리와 동일한 조치다.
3. `K_m` 은 그 달의 **세 arm 이 공유** — 세 arm 사이의 유일한 차이가 손실함수(표적 범함수)로 유지된다.
4. 절편 포함. 예측 = 학습창 통계로 표준화된 검정월 설계행렬 × 계수.

**이 선택을 한 근거 (성과 아님 — 수치 타당성 실측, 사전등록 시점):**
- 표준화 설계행렬의 조건수 = **1.81e17**, 수치 rank = **309/324** (전 패널) · **306/324** (최초 학습창).
  rank 는 상대 tol 1e-6 / 1e-8 / 1e-10 / 1e-12 에서 **전부 309** — 특잇값 간극이 명확해 tol 민감도 없음
  (∴ tol 1e-8 은 조율 파라미터가 아니다). 파이썬 pivoted-QR 과 R `qr()` 이 **동일하게 309** 를 보고.
- alias 15종 제거 후 조건수 **7.72e4** 로 정상화.
- 비-제거 설계에서 `statsmodels.QuantReg`(IRLS)는 τ=0.9 에서 **반복 상한 1000 도달(미수렴)**.
  alias 제거 후에도 IRLS 는 τ=0.9 미수렴 → **IRLS 대신 LP 정본 구현(`quantreg::rq` Frisch-Newton)** 채택.
  `rq.fit(method="fn")` 은 τ=0.5 / 0.9 모두 정상 수렴(전 패널 51.5s / 59.7s 실측).
- **성과 수치는 이 시점에 하나도 산출되지 않았다.** 위 실측은 조건수·rank·수렴/시간뿐이다.

기록 의무: 월별 `n_kept`, 학습창 조건수, 수렴 실패 월 수, drop 된 열 이름의 안정성.

| 쌍 | ML 측 | 선형 측 |

| 결과 | 판정 |
|---|---|
| \|t\| < 2.0 (3쌍 전부) | 용량 효과 미검출 → **P1 지지 후보** (§4.1 검정력 자격 필요) |

| 어느 쌍이든 t ≤ −2.0 | 선형 우위 = GBM 과적합의 실측 증거로 기록 |

### 4.1 검정력 자격 (미결 / 종결 라벨 분리 — 측정 전 고정)

각 쌍의 paired 차분 계열로 `02_Infrastructure/contracts/required_effect_size.R::required_effect(
n = <짝지은 개월>, t_threshold = 2.0, sd_monthly = sd(d), design = "full", series = d)` 를 호출해
**MDE(연환산)** 를 산출·병기한다(`nw_inflation` 은 계열 실측 우선, 실패 시 낙하 사실을 source 에 신고).

- |관측 연효과| **< MDE** → 그 쌍은 **미결(UNDERPOWERED)**. "효과 없음"으로 쓰지 않는다.
- |관측 연효과| **≥ MDE** 인데 |t| < 2.0 → **종결(POWERED_NULL)**.
- P1 "지지" 는 3쌍 전부 |t|<2.0 **이면서** 3쌍 전부 POWERED_NULL 일 때만 선언한다.
  하나라도 UNDERPOWERED 면 P1 은 **부분 미결**로 라벨하고 종결 선언을 금지한다.
- ★`armC_power_addendum.json` 선례: top-25 이산 선별의 paired diff sd 는 월 4.34% → MDE 연 9.25%p.
  이 해상도에서 P1 의 자동 충족이 예상되므로 **P1 단독으로 라운드를 닫지 않는다**(§6 F1~F3 필수).

## 6. F1~F3 — 비-성과 기전 관측 (문턱 전부 여기서 수치 고정)

보유집합 재구성 = `canonical_screen_bt` 와 **동일 규칙**: `setorder(S, Date, -score)` 후 월별 `min(25, .N)`
선두. `liq_dt` 미전달이므로 유동성 재필터 없음(계약과 동일). 계약 산출 수익과의 parity 검증 후 사용.

### F1 — 선택집합이 모델 축이 아니라 표적 축으로 군집하는가
- 월별 Jaccard `J_t(i,j) = |H_i ∩ H_j| / |H_i ∪ H_j|`.
- **T (동일-표적 · 교차-모델, 3쌍)**: (armA, L_mean) · (armB_q50, L_q50) · (armB_q90, L_q90)
- **M (동일-모델 · 교차-표적, 6쌍)**: (armA, armB_q50) · (armA, armB_q90) · (armB_q50, armB_q90) ·
  (L_mean, L_q50) · (L_mean, L_q90) · (L_q50, L_q90)
- `J̄_T`, `J̄_M` = 월 × 쌍 평균. 월별 차분 계열 `Δ_t = mean_T(J_t) − mean_M(J_t)`.
- **F1 PASS iff (J̄_T − J̄_M) ≥ +0.05 AND NW lag-3 t(Δ_t) ≥ +2.0.** (둘 다 측정 전 고정)
- ★핵심 기각 규칙(가설 §reject_if 승계): **P1 성립 ∧ F1 위배 = 표적-소비 기하 결정론 기각**
  ("다른 종목을 사서 같은 성과") → `미해명 등가` 라벨 + 선택집합 수준 재진단 next_probe.

### F2 — 꼬리 식별 등가
- 월 t 횡단면 = 그 달 스코어된 유니버스(3 arm 공통). `q90_t` = 그 횡단면 실현 `Ret_1m` 의 90 분위.
- `hit_t(arm)` = 보유 25종 중 `Ret_1m > q90_t` 비율.
- 동일-표적 3쌍의 `hit` 차분(ML − linear) NW3 t.
- **F2 등가 PASS iff 3쌍 전부 |t| < 2.0** (특히 q90 쌍). MDE 병기 — 미결/종결 라벨 §4.1 규약 동일.
- F2 위배(ML 의 꼬리 적중 우위) = 꼬리 국소 비선형 가정 실재 → 기하 가설 **부분 기각** +
  C2(EVT) 부활 신호로 기록(부활 시 `required_effect_size.R` + `cluster_power.R` 선통과 의무).

### F3 — 왜도-연결의 모델 불변성
- `skew_t` = 월 t 횡단면 실현 `Ret_1m` 의 왜도 (`PerformanceAnalytics::skewness`, 표준 함수).
- `gap_t^fam` = ret_net(q50 arm) − ret_net(mean arm), fam ∈ {LINEAR, ML}.
- `rho_fam` = Pearson cor(skew_t, gap_t^fam) (Spearman 병기).
- **F3 PASS iff sign(rho_LIN) == sign(rho_ML) AND |rho_LIN − rho_ML| ≤ 0.25.**
- F3 위배 = R32 의 연결(cor(왜도기울기, 중앙값−평균 gap) = −0.728)이 데이터 성질이 아니라
  GBM 특유 산물 → 기하 가설의 함의 1건 기각 + R32 기전 해석 재진단 요구.
