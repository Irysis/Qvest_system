## 4. 선별이 바뀌는가 — ★공통 지지집합 통제 후에도 자카드 0.43

⚠ 1차 측정은 교정이 결측 10.6% 를 만들어 후보 풀 자체를 바꿨다(결손≠차이).

## 6. ★미측정 (주장하지 않음)

- **PG2 북의 합성 알파가 이 51개 중 무엇을 실제로 소비하는지 모른다.**
  `forward_weights*.R` 텍스트 검색은 0건이었으나 이는 **잘못된 계측** — 생산은 사전계산
  합성 알파 패널을 쓰지 팩터코드를 직접 참조하지 않는다. 북 영향은 **미측정**.
- 자카드 0.43 은 `<항목>/Size` 단항 비율 기준이다. 다항 합성 점수에서는 상쇄될 수도,
  증폭될 수도 있다 — 합성 단계에서 재측정해야 한다.
- 교정 후 알파가 **좋아지는지**는 재지 않았다. 본 라운드 주장은 "현행이 스케일 혼합"까지다.

## 7. ★부수 검거 — `\b` 단어경계가 조용히 실패한다 (신규 이식성 결함)

레지스터리 스캐너가 **"유량 의존 팩터 0건"을 두 번** 반환했다. 거짓이었다.

```r
b <- paste(unlist(reg[["V08_PSR"]]), collapse=" | ")   # "MarketCap / Revenue ..." + 한글 주석
grepl("Revenue", b, fixed = TRUE)      # TRUE
grepl("\\bRevenue\\b", b)              # FALSE   ← TRE
grepl("\\bRevenue\\b", b, perl = TRUE) # FALSE   ← PCRE 도 마찬가지
```

**기전**: blob 에 한글이 섞이면 두 엔진 모두 매치에 실패하는데 **오류를 내지 않는다**.
`r-portability.md` 금칙⑥(TRE UTF-16 오프셋)의 이웃이나 **다른 축** — ⑥은 위치가 밀리는
"정상값 모양의 오답", 이건 **결손을 정상값(0건)으로 내려앉힘**.

★ 이 한 줄이 없었으면 FQ-099 는 "소비자 없음 → 무해" 로 닫혔다.
**규약**: 한글이 섞일 수 있는 텍스트 스캔은 `fixed=TRUE` 또는 위반 주입으로 검사기를 먼저 검증.
